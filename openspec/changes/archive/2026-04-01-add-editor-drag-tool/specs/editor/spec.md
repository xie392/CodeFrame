## 新增需求

### 需求：Editor 拖动工具

Editor 左侧工具栏必须提供拖动工具，允许用户选择后自由拖动画布内容。

#### 场景：拖动工具入口

- **当** 用户查看左侧工具栏
- **那么** 必须包含拖动工具（Move 图标），位于选择工具之后

#### 场景：拖动工具选中状态

- **当** 用户点击拖动工具
- **那么** 拖动工具必须显示为激活状态
- **且** 画布光标必须变为 grab 样式
- **且** 其他工具（箭头、矩形、文字、马赛克、裁剪）必须处于非激活状态

#### 场景：拖动工具使用

- **当** 拖动工具处于激活状态且用户按住鼠标左键拖拽
- **那么** 画布内容必须跟随鼠标移动方向平移
- **且** 拖动功能必须在任何缩放比例下都可使用（包括 1x）
- **且** 拖动时画布光标必须变为 grabbing 样式

#### 场景：非拖动工具时禁止拖动

- **当** 当前选中的工具不是拖动工具
- **那么** 拖拽画布不得产生平移效果

## 修改需求

### 需求：Editor 画布平移

Editor 画布在拖动工具激活后必须支持拖拽平移，用户可以拖动查看图片的不同区域。

#### 场景：拖动工具激活后拖拽平移

- **当** 拖动工具处于激活状态且用户按住鼠标左键拖拽
- **那么** 画布内容必须跟随鼠标移动方向平移
- **且** 平移必须使用 CSS transform（translate + scale）

#### 场景：非拖动工具时禁止平移

- **当** 当前选中的工具不是拖动工具
- **那么** 拖拽操作不得产生平移效果

### 需求：Editor 缩放控制条

Editor 画布底部必须显示一个浮动缩放控制条，提供缩放操作的 UI 入口。

#### 场景：控制条外观

- **当** 用户查看画布区域
- **那么** 缩放控制条必须固定在画布底部中央
- **且** 控制条必须具有毛玻璃效果（background-color: rgba(255,255,255,0.85)，backdrop-filter: blur(8px)）
- **且** 控制条圆角必须为 8px

#### 场景：控制条内容

- **当** 用户查看缩放控制条
- **那么** 必须包含以下元素（从左到右）：
  - 缩小按钮（- 图标）
  - 当前缩放百分比文本（如 "100%"）
  - 缩放滑块（range input，步长 0.01，范围 25%–400%）
  - 放大按钮（+ 图标）
  - 分隔线
  - 重置按钮（重置图标）

#### 场景：重置视图

- **当** 用户点击重置按钮
- **那么** 画布必须恢复到 1x 缩放比例
- **且** 画布位置必须归零（居中显示）
