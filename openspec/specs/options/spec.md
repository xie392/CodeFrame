## 需求
### 需求：设置页面布局

系统**必须**提供设置页面入口，用户可通过 Chrome 扩展管理页面或扩展图标右键菜单访问设置页面。

#### 场景：用户访问设置页面

- **当** 用户打开扩展设置页面
- **那么** 显示亮色玻璃拟态风格的设置界面，包含 Header、通用设置、快捷键、关于信息三个区块

---

### 需求：通用设置配置

系统**必须**提供通用设置配置功能，允许用户自定义默认行为。

#### 场景：切换默认导出格式

- **当** 用户点击"默认导出格式"下拉选择器
- **那么** 显示可选格式列表（PNG / JPG / WEBP）
- **且** 选择后自动保存到 `chrome.storage.local`

#### 场景：使用默认导出格式导出图片（编辑器）

- **当** 用户在编辑器点击导出按钮
- **那么** 系统读取 `defaultFormat` 设置
- **且** 使用对应格式（PNG / JPG / WEBP）导出图片
- **且** 导出文件扩展名与格式匹配

#### 场景：使用默认导出格式导出图片（代码生成器）

- **当** 用户在代码生成器点击导出按钮
- **那么** 系统读取 `defaultFormat` 设置
- **且** 使用对应格式（PNG / JPG / WEBP）导出图片
- **且** 导出文件扩展名与格式匹配

#### 场景：JPG 格式背景处理

- **当** 用户选择 JPG 格式导出
- **那么** 系统自动添加白色背景（JPG 不支持透明）

#### 场景：切换截图质量

- **当** 用户点击"截图质量"下拉选择器
- **那么** 显示可选质量列表（标准 / 高清 / 超高清）
- **且** 选择后自动保存到 `chrome.storage.local`

#### 场景：截图质量等级定义

- **当** 用户选择"标准"质量
- **那么** DPR 缩放倍数必须为 1x
- **且** 输出图片尺寸与屏幕显示尺寸一致
- **当** 用户选择"高清"质量
- **那么** DPR 缩放倍数必须为 2x
- **且** 输出图片尺寸为屏幕显示尺寸的 2 倍
- **当** 用户选择"超高清"质量
- **那么** DPR 缩放倍数必须为 3x
- **且** 输出图片尺寸为屏幕显示尺寸的 3 倍

#### 场景：截图质量生效范围

- **当** 用户修改截图质量设置
- **那么** 设置必须同时影响以下场景：
  - 可视区域截图捕获
  - 区域选择截图捕获
  - 整页截图捕获
  - Editor 导出图片
  - CodeGen 导出图片

#### 场景：切换语言

- **当** 用户点击"界面语言"下拉选择器
- **那么** 显示可选语言列表（简体中文 / English）
- **且** 选择后自动保存到 `chrome.storage.local`

### 需求：操作历史持久化设置

系统**必须**提供"保存操作历史"开关，控制是否记录用户的操作配置。

#### 场景：开启保存操作历史

- **当** 用户开启"保存操作历史"开关
- **那么** 系统记录用户在各页面的操作配置（编辑器标注设置、代码生成样式等）
- **且** 下次进入对应页面时，自动恢复上次用户设置的配置

#### 场景：关闭保存操作历史

- **当** 用户关闭"保存操作历史"开关
- **那么** 系统不再记录用户操作配置
- **且** 下次进入页面时，使用默认配置

#### 场景：切换保存操作历史

- **当** 用户切换"保存操作历史"开关状态
- **那么** 设置立即保存到 `chrome.storage.local`

#### 场景：Editor 配置恢复

- **当** 用户开启"保存操作历史"并重新进入编辑器页面
- **那么** 系统自动恢复以下配置：
  - 上次使用的工具 (`activeTool`)
  - Frame 设置（背景色、边框、阴影、水印等）
  - 折叠面板展开状态 (`collapsedSections`)

#### 场景：CodeGen 配置恢复

- **当** 用户开启"保存操作历史"并重新进入代码生成器页面
- **那么** 系统自动恢复以下配置：
  - 代码主题 (`selectedTheme`)
  - 背景样式 (`selectedBg`)
  - 字体类型 (`selectedFont`)
  - 字体大小 (`fontSize`)
  - 行号显示 (`showLineNumbers`)
  - 内边距 (`padding`)
  - 圆角设置 (`borderRadius`)
  - 阴影开关 (`shadowEnabled`)
  - 阴影强度 (`shadowIntensity`)
  - 标题栏显示 (`showHeader`)
  - 文件名 (`fileName`)
  - 水印开关 (`watermarkEnabled`)
  - 水印文字 (`watermarkText`)
  - 水印透明度 (`watermarkOpacity`)

### 需求：清除操作历史

系统**必须**提供清除操作历史功能，允许用户一键清除所有已保存的操作配置。

#### 场景：清除操作历史

- **当** 用户在设置页面点击「清除历史」按钮
- **那么** 显示确认弹窗，提示用户确认操作
- **且** 用户确认后，`operationHistory` 数据被清空
- **且** 清空后 Editor 和 CodeGen 页面将使用默认配置

#### 场景：取消清除操作

- **当** 用户在确认弹窗中点击取消
- **那么** 操作历史数据保持不变
- **且** 弹窗关闭

#### 场景：清除后恢复默认配置

- **当** 用户清除操作历史后重新进入 Editor 或 CodeGen 页面
- **那么** 系统使用默认配置，而非之前保存的配置

### 需求：截图设置配置

系统**必须**提供截图相关设置配置功能。

#### 场景：设置默认延迟时间

- **当** 用户点击"延迟截图时间"下拉选择器
- **那么** 显示可选延迟时间列表（3秒 / 5秒 / 10秒）
- **且** 选择后自动保存到 `chrome.storage.local`

---

### 需求：快捷键展示

系统**必须**展示扩展快捷键配置，帮助用户了解快捷操作方式。

#### 场景：查看快捷键配置

- **当** 用户查看快捷键区块
- **那么** 显示「全局快捷键」区块（展示 Chrome 原生命令：Alt+Shift+S/R/F/D）
- **且** 显示「页面快捷键」区块（可编辑的自定义快捷键）
- **且** 快捷键以视觉化按键形式展示

#### 场景：快捷键配置入口

- **当** 用户点击「全局快捷键」区块的「跳转配置」按钮
- **那么** 在新标签页打开 `chrome://extensions/shortcuts`
- **且** 自动定位到 CodeFrame 扩展

#### 场景：快捷键不可修改提示

- **当** 用户查看「全局快捷键」区块
- **那么** 显示提示「全局快捷键需在 Chrome 扩展管理页面修改」
- **且** 提供「跳转配置」按钮

---

### 需求：关于信息展示

系统**必须**展示扩展基本信息，包括版本号、作者和仓库链接。

#### 场景：查看版本和作者信息

- **当** 用户查看关于区块
- **那么** 显示扩展版本号、作者名称

#### 场景：访问仓库链接

- **当** 用户点击仓库链接
- **那么** 在新标签页打开 GitHub 仓库页面

---

### 需求：设置持久化

系统**必须**持久化保存用户设置，确保设置在浏览器重启后保留。

#### 场景：设置自动保存

- **当** 用户修改任意设置项
- **那么** 设置立即保存到 `chrome.storage.local`
- **且** 无需手动点击保存按钮

#### 场景：设置恢复

- **当** 用户重新打开设置页面
- **那么** 自动加载并显示已保存的设置值

### 需求：快捷键配置功能

系统**必须**提供快捷键配置功能，允许用户自定义页面内快捷键。

#### 场景：查看快捷键配置

- **当** 用户查看快捷键设置区块
- **那么** 显示「全局快捷键」区块（只读，展示 Chrome 原生命令）
- **且** 显示「页面快捷键」区块（可编辑）
- **且** 每个快捷键项显示命令名称和当前快捷键组合

#### 场景：区分全局和页面快捷键

- **当** 用户查看快捷键设置
- **那么** 「全局快捷键」区块显示 Chrome 原生命令（Alt+Shift+S/R/F/D）
- **且** 显示「跳转配置」按钮，点击后跳转至 `chrome://extensions/shortcuts`
- **且** 「页面快捷键」区块显示可自定义的快捷键配置

### 需求：快捷键录制功能

系统**必须**提供快捷键录制功能，允许用户通过按键设置新的快捷键组合。

#### 场景：进入快捷键录制模式

- **当** 用户点击某个快捷键的编辑按钮
- **那么** 该快捷键项进入录制模式
- **且** 显示「请按下新的快捷键组合...」提示
- **且** 原快捷键显示区域变为输入框样式

#### 场景：录制有效快捷键

- **当** 用户处于录制模式并按下有效快捷键组合（如 `Ctrl+S`）
- **那么** 系统解析并显示该快捷键组合
- **且** 自动保存到 `chrome.storage.local`
- **且** 退出录制模式

#### 场景：取消录制

- **当** 用户在录制模式下按下 `Escape` 键
- **那么** 取消录制，恢复原快捷键显示
- **且** 不保存任何更改

#### 场景：清除快捷键

- **当** 用户点击快捷键的「清除」按钮
- **那么** 该快捷键设置为空（禁用该快捷键）
- **且** 显示「未设置」占位符

#### 场景：恢复默认快捷键

- **当** 用户点击快捷键的「恢复默认」按钮
- **那么** 该快捷键恢复为默认值
- **且** 自动保存到 `chrome.storage.local`

### 需求：快捷键冲突检测

系统**必须**检测快捷键冲突，阻止设置冲突的快捷键。

#### 场景：检测系统快捷键冲突

- **当** 用户尝试设置系统保留快捷键（如 `Ctrl+T`、`F5`）
- **那么** 阻止设置并显示警告提示「该快捷键与系统快捷键冲突」
- **且** 保持原快捷键不变

#### 场景：检测已配置快捷键冲突

- **当** 用户尝试设置已被其他命令使用的快捷键
- **那么** 阻止设置并显示警告提示「该快捷键已被 [命令名] 使用」
- **且** 保持原快捷键不变

#### 场景：显示冲突提示

- **当** 检测到快捷键冲突
- **那么** 显示冲突提示弹窗
- **且** 提供替代快捷键建议（如 `Alt+S` 替代 `Ctrl+S`）

### 需求：页面快捷键开关

系统**必须**提供页面快捷键开关，允许用户启用或禁用自定义快捷键。

#### 场景：启用页面快捷键

- **当** 用户开启「启用页面快捷键」开关
- **那么** 页面快捷键功能在 Popup/Editor/CodeGen 页面生效
- **且** 设置自动保存到 `chrome.storage.local`

#### 场景：禁用页面快捷键

- **当** 用户关闭「启用页面快捷键」开关
- **那么** 页面快捷键功能在所有页面失效
- **且** 设置自动保存到 `chrome.storage.local`
- **且** 全局快捷键（Chrome 原生命令）不受影响

### 需求：页面快捷键执行

系统**必须**在支持的页面内执行自定义快捷键命令。

#### 场景：Popup 页面快捷键触发

- **当** 用户在 Popup 页面按下已配置的自定义快捷键
- **那么** 执行对应的命令（可视区域截图、区域截图等）
- **且** 关闭 Popup 弹窗

#### 场景：Editor 页面快捷键触发

- **当** 用户在 Editor 页面按下已配置的自定义快捷键
- **那么** 执行对应的命令

#### 场景：CodeGen 页面快捷键触发

- **当** 用户在 CodeGen 页面按下已配置的自定义快捷键
- **那么** 执行对应的命令

#### 场景：输入框聚焦时不触发快捷键

- **当** 用户在输入框或文本区域中按下快捷键
- **那么** 不触发快捷键命令
- **且** 正常输入文字
