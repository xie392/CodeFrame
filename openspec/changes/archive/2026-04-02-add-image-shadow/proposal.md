# 变更：添加图片独立阴影设置功能

## 为什么

当前 Editor 的阴影功能仅支持容器级别阴影，无法为图片本身设置独立的阴影效果。用户希望能够：
1. 为图片单独设置阴影，与容器阴影独立控制
2. 实现更丰富的视觉效果组合（如容器无阴影 + 图片有阴影，或两者都有阴影）

## 变更内容

- 在 Editor 右侧属性面板中新增「图片阴影」设置区块
- 支持独立设置图片阴影的启用/禁用、颜色、模糊度、偏移量
- 提供图片阴影预设选项（无、轻微、中等、强烈）
- 图片阴影与容器阴影独立生效，互不影响

## 影响

- 受影响规范：`editor`（新增需求）
- 受影响代码：
  - `src/editor/types.ts` - 添加图片阴影类型定义
  - `src/editor/App.tsx` - 添加图片阴影 UI 控件和渲染逻辑
