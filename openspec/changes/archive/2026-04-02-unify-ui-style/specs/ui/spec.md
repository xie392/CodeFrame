## 新增需求

### 需求：共享 Input 输入框组件

系统必须提供可复用的 Input 输入框组件，支持标准和小型两种尺寸，供 CodeGen 和 Editor 页面共同使用。

#### 场景：标准输入框

- **当** 使用 Input 组件且未指定 size
- **那么** 输入框高度必须为 32px
- **且** 圆角必须为 8px
- **且** 背景必须使用 `var(--color-field-bg)` 变量
- **且** 边框必须使用 `var(--color-field-border)` 变量

#### 场景：小型输入框

- **当** 使用 Input 组件且指定 size="sm"
- **那么** 输入框高度必须为 28px
- **且** 圆角必须为 6px
- **且** 其他样式属性与标准输入框一致

#### 场景：焦点状态

- **当** 输入框获得焦点
- **那么** 必须显示 `var(--color-accent)` 的 ring 样式

### 需求：共享 Select 下拉选择器组件

系统必须提供可复用的 Select 下拉选择器组件，支持标准和小型两种尺寸，供 CodeGen 和 Editor 页面共同使用。

#### 场景：标准下拉选择器

- **当** 使用 Select 组件且未指定 size
- **那么** 选择器高度必须为 32px
- **且** 圆角必须为 8px
- **且** 内边距必须为 8px

#### 场景：小型下拉选择器

- **当** 使用 Select 组件且指定 size="sm"
- **那么** 选择器高度必须为 28px
- **且** 圆角必须为 6px

### 需求：共享 Slider 滑块组件

系统必须提供可复用的 Slider 滑块组件，包含标签、滑块轨道和数值显示，供 CodeGen 和 Editor 页面共同使用。

#### 场景：滑块轨道样式

- **当** 使用 Slider 组件
- **那么** 滑块轨道高度必须为 4px
- **且** 强调色必须使用 emerald-500（#10B981）
- **且** 滑块必须支持拖动操作

#### 场景：带标签和数值显示

- **当** 使用 Slider 组件并指定 label
- **那么** 必须在左侧显示标签文字
- **且** 必须在右侧显示当前数值
- **且** 数值必须右对齐并使用 tabular-nums 特性

### 需求：共享 Switch 开关组件

系统必须提供可复用的 Switch 开关组件，供 CodeGen 和 Editor 页面共同使用。

#### 场景：开关尺寸

- **当** 使用 Switch 组件
- **那么** 开关尺寸必须为 36x20px
- **且** 滑块（圆形把手）尺寸必须为 16x16px

#### 场景：开启状态样式

- **当** 开关处于开启状态（checked=true）
- **那么** 背景色必须使用 `var(--color-accent)` 变量
- **且** 滑块颜色必须为白色（#FFFFFF）
- **且** 滑块必须位于右侧

#### 场景：关闭状态样式

- **当** 开关处于关闭状态（checked=false）
- **那么** 背景色必须为浅灰色（#D1D5DB）
- **且** 滑块颜色必须为白色（#FFFFFF）
- **且** 滑块必须位于左侧

### 需求：共享 ColorPicker 颜色选择器组件

系统必须提供可复用的 ColorPicker 颜色选择器组件，使用圆形色块样式，供 CodeGen 和 Editor 页面共同使用。

#### 场景：圆形色块样式

- **当** 使用 ColorPicker 组件
- **那么** 色块必须为正圆形（border-radius: 50%）
- **且** 色块尺寸必须为 24x24px
- **且** 色块之间必须有 4px 间距

#### 场景：选中状态指示

- **当** 用户选中某个颜色
- **那么** 选中的色块必须显示 2px 实线边框
- **且** 边框颜色必须使用 `var(--color-accent)` 变量

#### 场景：自定义颜色入口

- **当** ColorPicker 支持自定义颜色
- **那么** 必须提供自定义颜色输入入口
- **且** 自定义入口必须显示调色板图标或渐变色块

### 需求：CodeGen 左侧操作栏白色背景

CodeGen 页面左侧操作栏必须使用纯白色背景，替代原有的半透明毛玻璃效果。

#### 场景：操作栏背景样式

- **当** CodeGen 页面渲染左侧操作栏
- **那么** 背景色必须为纯白色（#FFFFFF）
- **且** 操作栏宽度必须保持 240px
- **且** 内边距必须保持 16px
- **且** 元素间距必须保持 12px
