## 需求
### 需求：Editor 画布布局

Editor 中央画布区域必须采用"固定尺寸 + 居中"模式显示图片，图片默认以中等大小呈现在画布中央，不得占满整个屏幕。

#### 场景：图片默认居中显示

- **当** 用户在 Editor 中加载一张图片
- **那么** 图片容器最大宽度必须为 800px、最大高度为 600px
- **且** 图片容器必须在画布区域中水平垂直居中
- **且** 图片必须保持原始宽高比（object-contain）
- **且** 当图片实际尺寸小于容器时，容器尺寸必须适配图片实际尺寸

#### 场景：图片小于容器尺寸

- **当** 用户加载的图片尺寸小于 800x600px
- **那么** 容器尺寸必须适配图片实际尺寸，不产生多余空白区域

#### 场景：画布布局结构

- **当** Editor 页面渲染
- **那么** 中央画布（main）必须使用 relative 定位
- **且** 图片容器必须使用 absolute 定位 + calc(50% - w/2) 居中
- **且** 三栏布局结构不变（工具栏 56px + 画布 flex-1 + 属性面板 350px）

### 需求：Editor 画布缩放

Editor 画布必须支持缩放功能，用户可以通过鼠标滚轮或控制按钮对图片进行缩放查看。

#### 场景：鼠标滚轮缩放

- **当** 用户在画布区域滚动鼠标滚轮
- **那么** 向上滚动必须放大（系数 1.08），向下滚动必须缩小（系数 0.92）
- **且** 缩放必须以画布中心点为锚点
- **且** 缩放范围必须限制在 0.25x 到 4x 之间

#### 场景：缩放按钮控制

- **当** 用户点击缩放控制条中的放大按钮
- **那么** 画布必须以当前视图中心为锚点放大（系数 1.2）
- **当** 用户点击缩小按钮
- **那么** 画布必须以当前视图中心为锚点缩小（系数 1/1.2）

#### 场景：重置缩放

- **当** 用户点击缩放控制条中的重置按钮
- **那么** 画布必须恢复到 1x 缩放比例且偏移归零

### 需求：Editor 画布平移

Editor 画布在拖动工具激活后必须支持拖拽平移，用户可以拖动查看图片的不同区域。

#### 场景：拖动工具激活后拖拽平移

- **当** 拖动工具处于激活状态且用户按住鼠标左键拖拽
- **那么** 画布内容必须跟随鼠标移动方向平移
- **且** 平移必须使用 CSS transform（translate + scale）

#### 场景：非拖动工具时禁止平移

- **当** 当前选中的工具不是拖动工具
- **那么** 拖拽操作不得产生平移效果

### 需求：Editor 缩放控制条

Editor 画布底部必须显示一个浮动缩放控制条，提供缩放操作的 UI 入口。

#### 场景：控制条外观

- **当** 用户查看画布区域
- **那么** 缩放控制条必须固定在画布底部中央
- **且** 控制条必须具有毛玻璃效果（background-color: rgba(255,255,255,0.85)，backdrop-filter: blur(8px)）
- **且** 控制条圆角必须为 8px

#### 场景：控制条内容

- **当** 用户查看缩放控制条
- **那么** 必须包含以下元素（从左到右）：
  - 缩小按钮（- 图标）
  - 当前缩放百分比文本（如 "100%"）
  - 缩放滑块（range input，步长 0.01，范围 25%–400%）
  - 放大按钮（+ 图标）
  - 分隔线
  - 重置按钮（重置图标）

#### 场景：重置视图

- **当** 用户点击重置按钮
- **那么** 画布必须恢复到 1x 缩放比例
- **且** 画布位置必须归零（居中显示）

### 需求：Editor 拖动工具

Editor 左侧工具栏必须提供拖动工具，允许用户选择后自由拖动画布内容。

#### 场景：拖动工具入口

- **当** 用户查看左侧工具栏
- **那么** 必须包含拖动工具（Move 图标），位于选择工具之后

#### 场景：拖动工具选中状态

- **当** 用户点击拖动工具
- **那么** 拖动工具必须显示为激活状态
- **且** 画布光标必须变为 grab 样式
- **且** 其他工具（箭头、矩形、文字、马赛克、裁剪）必须处于非激活状态

#### 场景：拖动工具使用

- **当** 拖动工具处于激活状态且用户按住鼠标左键拖拽
- **那么** 画布内容必须跟随鼠标移动方向平移
- **且** 拖动功能必须在任何缩放比例下都可使用（包括 1x）
- **且** 拖动时画布光标必须变为 grabbing 样式

#### 场景：非拖动工具时禁止拖动

- **当** 当前选中的工具不是拖动工具
- **那么** 拖拽画布不得产生平移效果

### 需求：Editor 矩形标注绘制

Editor 必须提供矩形标注工具，允许用户在图片上绘制矩形区域进行标注。

#### 场景：矩形工具入口

- **当** 用户查看左侧工具栏
- **那么** 必须包含矩形工具（Square 图标），位于箭头工具之后

#### 场景：矩形工具选中状态

- **当** 用户点击矩形工具
- **那么** 矩形工具必须显示为激活状态
- **且** 画布光标必须变为 crosshair 样式
- **且** 其他工具必须处于非激活状态

#### 场景：绘制矩形

- **当** 矩形工具处于激活状态且用户按住鼠标左键拖拽
- **那么** 必须从按下位置开始绘制矩形
- **且** 矩形必须跟随鼠标移动实时更新尺寸
- **当** 用户释放鼠标左键
- **那么** 如果矩形宽度或高度大于等于 5px，必须创建矩形标注对象
- **且** 工具必须自动切换到选择工具

#### 场景：绘制过小矩形取消

- **当** 用户绘制的矩形宽度或高度小于 5px
- **那么** 必须取消创建，不产生矩形标注对象

### 需求：Editor 矩形标注选择

Editor 必须支持选择已创建的矩形标注，以便进行编辑或删除操作。

#### 场景：点击选择矩形

- **当** 选择工具处于激活状态且用户点击矩形边框或内部区域
- **那么** 该矩形必须被选中
- **且** 矩形必须显示选中高亮状态（蓝色边框）
- **且** 矩形必须显示 8 个控制点（四个角 + 四条边中点）

#### 场景：点击空白区域取消选择

- **当** 选择工具处于激活状态且用户点击矩形外部空白区域
- **那么** 当前选中的矩形必须取消选中状态

### 需求：Editor 矩形标注移动

Editor 必须支持拖拽移动已创建的矩形标注。

#### 场景：拖拽移动矩形

- **当** 用户选中矩形后在矩形内部区域按住鼠标左键拖拽
- **那么** 矩形必须跟随鼠标移动
- **且** 矩形尺寸必须保持不变
- **且** 移动必须考虑当前缩放比例

### 需求：Editor 矩形标注调整大小

Editor 必须支持通过控制点调整矩形标注的尺寸。

#### 场景：拖拽角控制点调整大小

- **当** 用户选中矩形后拖拽四个角的控制点
- **那么** 必须同时改变矩形的宽度和高度
- **且** 对角位置必须保持不变

#### 场景：拖拽边中点控制点调整大小

- **当** 用户选中矩形后拖拽四条边中点的控制点
- **那么** 必须改变矩形在该方向的尺寸
- **且** 对边位置必须保持不变

#### 场景：调整大小时光标变化

- **当** 用户将鼠标悬停在控制点上
- **那么** 光标必须变为对应的调整大小样式（nwse-resize、nesw-resize、ns-resize、ew-resize）

### 需求：Editor 矩形标注删除

Editor 必须支持删除已选中的矩形标注。

#### 场景：键盘删除矩形

- **当** 矩形被选中且用户按下 Delete 或 Backspace 键
- **那么** 选中的矩形必须被删除
- **且** 选择状态必须清除
- **且** 如果焦点在输入框中，禁止触发删除

### 需求：Editor 矩形标注样式配置

Editor 必须提供矩形标注的样式配置选项，允许用户自定义矩形外观。

#### 场景：颜色配置

- **当** 用户选中矩形后查看右侧属性面板
- **那么** 必须显示颜色选择器
- **且** 必须提供预设颜色选项
- **且** 必须支持自定义颜色输入

#### 场景：线宽配置

- **当** 用户选中矩形后查看右侧属性面板
- **那么** 必须显示线宽滑块控件
- **且** 线宽范围必须为 1-10px
- **且** 默认线宽必须为 2px

#### 场景：填充透明度配置

- **当** 用户选中矩形后查看右侧属性面板
- **那么** 必须显示填充透明度滑块控件
- **且** 透明度范围必须为 0-100%
- **且** 默认透明度必须为 0%（完全透明）

#### 场景：边框样式配置

- **当** 用户选中矩形后查看右侧属性面板
- **那么** 必须显示边框样式切换控件
- **且** 必须支持实线和虚线两种样式
- **且** 默认样式必须为实线

#### 场景：样式实时预览

- **当** 用户修改矩形样式配置
- **那么** 选中的矩形必须实时更新显示效果

### 需求：Editor 马赛克标注绘制

Editor 必须提供马赛克标注工具，允许用户在图片上绘制马赛克区域进行隐私保护。

- **那么** 选中的马赛克必须实时更新显示效果

### 需求：Editor 裁剪工具入口

Editor 左侧工具栏必须提供裁剪工具，允许用户进入裁剪模式对图片进行裁剪。

#### 场景：裁剪工具入口

- **当** 用户查看左侧工具栏
- **那么** 必须包含裁剪工具（Crop 图标），位于马赛克工具之后

#### 场景：裁剪工具选中状态

- **当** 用户点击裁剪工具
- **那么** 裁剪工具必须显示为激活状态
- **且** 画布必须显示覆盖全图的默认裁剪框
- **且** 其他工具必须处于非激活状态
- **且** 画布光标必须变为 crosshair 样式

#### 场景：裁剪框初始状态

- **当** 用户激活裁剪工具
- **那么** 裁剪框必须默认覆盖整个图片区域
- **且** 裁剪框必须显示为虚线边框
- **且** 裁剪框外的区域必须显示半透明暗色遮罩

### 需求：Editor 裁剪框交互

Editor 必须支持通过拖拽调整裁剪框的位置和大小。

#### 场景：拖拽创建新裁剪框

- **当** 裁剪工具激活且用户在裁剪框外按下鼠标左键拖拽
- **那么** 必须从按下位置开始创建新的裁剪框
- **且** 裁剪框必须跟随鼠标移动实时更新尺寸

#### 场景：拖拽移动裁剪框

- **当** 用户在裁剪框内部区域按下鼠标左键拖拽
- **那么** 裁剪框必须跟随鼠标移动
- **且** 裁剪框尺寸必须保持不变
- **且** 裁剪框不得超出图片边界

#### 场景：拖拽角控制点调整大小

- **当** 用户拖拽裁剪框四个角的控制点
- **那么** 必须同时改变裁剪框的宽度和高度
- **且** 对角位置必须保持不变
- **且** 裁剪框不得超出图片边界

#### 场景：拖拽边中点控制点调整大小

- **当** 用户拖拽裁剪框四条边中点的控制点
- **那么** 必须改变裁剪框在该方向的尺寸
- **且** 对边位置必须保持不变
- **且** 裁剪框不得超出图片边界

#### 场景：调整大小时光标变化

- **当** 用户将鼠标悬停在裁剪框控制点上
- **那么** 光标必须变为对应的调整大小样式（nwse-resize、nesw-resize、ns-resize、ew-resize）
- **当** 用户将鼠标悬停在裁剪框内部
- **那么** 光标必须变为 move 样式

#### 场景：最小裁剪尺寸限制

- **当** 用户调整裁剪框大小
- **那么** 裁剪框宽度和高度不得小于 10px

### 需求：Editor 裁剪确认与取消

Editor 必须提供明确的裁剪确认与取消机制。

#### 场景：键盘确认裁剪

- **当** 用户按下 Enter 键
- **那么** 必须执行裁剪操作
- **且** 图片必须更新为裁剪框内的区域
- **且** 所有标注必须被清除
- **且** 工具必须自动切换到选择工具
- **且** 视图必须重置为默认状态（缩放 1x，居中显示）

#### 场景：双击确认裁剪

- **当** 用户双击裁剪框内部区域
- **那么** 必须执行裁剪操作
- **且** 图片必须更新为裁剪框内的区域
- **且** 所有标注必须被清除
- **且** 工具必须自动切换到选择工具
- **且** 视图必须重置为默认状态

#### 场景：键盘取消裁剪

- **当** 用户按下 Escape 键
- **那么** 必须取消裁剪操作
- **且** 裁剪框必须消失
- **且** 工具必须自动切换到选择工具
- **且** 图片和标注必须保持不变

#### 场景：切换工具取消裁剪

- **当** 用户点击其他工具按钮
- **那么** 必须取消裁剪操作
- **且** 裁剪框必须消失
- **且** 图片和标注必须保持不变

- **那么** 必须使用 Canvas API 从原图截取指定区域

#### 场景：清除标注数据

- **且** 所有矩形标注必须被清除

- **且** 所有马赛克标注必须被清除

#### 场景：重置视图状态

- **当** 裁剪操作执行
- **那么** 缩放比例必须重置为 1x
- **且** 平移偏移必须重置为零
- **且** 新图片必须在画布中央显示

### 需求：Editor 撤销功能

Editor 必须提供撤销功能，允许用户撤销最近的操作，恢复到上一个历史状态。

#### 场景：工具栏撤销按钮

- **当** 用户查看左侧工具栏
- **那么** 必须显示撤销按钮（Undo2 图标）
- **且** 当存在可撤销的历史记录时，按钮必须可点击
- **且** 当不存在可撤销的历史记录时，按钮必须禁用且显示半透明

#### 场景：点击撤销按钮

- **当** 用户点击撤销按钮
- **那么** Editor 必须恢复到上一个历史状态
- **且** 当前状态必须被保存到未来状态栈
- **且** 所有标注和视图必须更新为历史状态

#### 场景：键盘快捷键撤销

- **当** 用户按下 `Ctrl+Z`（Windows）或 `Cmd+Z`（macOS）
- **那么** 必须执行撤销操作
- **且** 如果焦点在输入框中，禁止触发撤销

#### 场景：撤销创建标注

- **当** 用户创建箭头、矩形、文字或马赛克标注后执行撤销
- **那么** 新创建的标注必须被移除
- **且** 选择状态必须清除

#### 场景：撤销修改标注

- **当** 用户修改标注的位置、尺寸或样式后执行撤销
- **那么** 标注必须恢复到修改前的状态

#### 场景：撤销删除标注

- **当** 用户删除标注后执行撤销
- **那么** 被删除的标注必须恢复到画布上
- **且** 标注的所有属性必须保持删除前的状态

#### 场景：撤销裁剪操作

- **当** 用户执行裁剪操作后执行撤销
- **那么** 图片必须恢复到裁剪前的原始图片
- **且** 所有标注必须恢复到裁剪前的状态
- **且** 视图状态必须恢复

### 需求：Editor 恢复功能

Editor 必须提供恢复功能，允许用户恢复已被撤销的操作。

#### 场景：工具栏重做按钮

- **当** 用户查看左侧工具栏
- **那么** 必须显示重做按钮（Redo2 图标），位于撤销按钮之后
- **且** 当存在可恢复的未来状态时，按钮必须可点击
- **且** 当不存在可恢复的未来状态时，按钮必须禁用且显示半透明

#### 场景：点击重做按钮

- **当** 用户点击重做按钮
- **那么** Editor 必须恢复到下一个未来状态
- **且** 当前状态必须被保存到历史记录栈
- **且** 所有标注和视图必须更新为未来状态

#### 场景：键盘快捷键重做

- **当** 用户按下 `Ctrl+Shift+Z`（Windows）或 `Cmd+Shift+Z`（macOS）
- **那么** 必须执行重做操作
- **且** 如果焦点在输入框中，禁止触发重做
- **当** 用户按下 `Ctrl+Y`（Windows）或 `Cmd+Y`（macOS）
- **那么** 必须执行重做操作（兼容快捷键）

#### 场景：新操作清除未来状态

- **当** 用户在撤销后执行新的操作
- **那么** 所有未来状态必须被清除
- **且** 新操作必须被记录到历史记录栈

### 需求：Editor 历史记录管理

Editor 必须管理历史记录栈，确保撤销/恢复功能正确工作。

#### 场景：历史记录上限

- **当** 历史记录数量超过 50 条
- **那么** 最早的历史记录必须被丢弃
- **且** 保持最近 50 条历史记录

#### 场景：状态快照内容

- **当** 创建历史记录快照
- **那么** 必须包含所有标注数据（箭头、矩形、文字、马赛克）
- **且** 必须包含图片数据（imageData）
- **且** 必须包含视图状态（scale、offset）

#### 场景：连续快速操作

- **当** 用户连续快速执行多个操作
- **那么** 每个操作必须独立记录到历史记录栈
- **且** 撤销时必须逐个恢复

## Requirements
### Requirement: Editor 选择工具入口

Editor 左侧工具栏 MUST 提供选择工具，允许用户选择画布上的标注对象进行编辑操作。

#### Scenario: 选择工具入口

- **当** 用户查看左侧工具栏
- **那么** 必须包含选择工具（MousePointer2 图标），位于工具栏最顶部
- **且** 选择工具必须是默认激活的工具

#### Scenario: 选择工具选中状态

- **当** 用户点击选择工具
- **那么** 选择工具必须显示为激活状态
- **且** 画布光标必须变为 default 样式
- **且** 其他工具（拖动、箭头、矩形、文字、马赛克、裁剪）必须处于非激活状态

#### Scenario: 绘制完成后自动切换

- **当** 用户使用其他工具（箭头、矩形、文字、马赛克）完成绘制
- **那么** 工具必须自动切换到选择工具

### Requirement: Editor 多选功能

Editor 选择工具 MUST 支持多选功能，允许用户同时选中多个标注对象进行批量操作。

#### Scenario: 点击单选

- **当** 选择工具处于激活状态且用户点击某个标注对象
- **那么** 该对象必须被选中
- **且** 之前选中的所有对象必须取消选中
- **且** 如果用户按住 Shift 键点击，则保留之前的选择并添加新选择

#### Scenario: 框选多个对象

- **当** 选择工具处于激活状态且用户在空白区域按下鼠标左键并拖拽
- **那么** 必须显示一个半透明的选区矩形框
- **且** 选区矩形框必须跟随鼠标移动实时更新尺寸
- **当** 用户释放鼠标左键
- **那么** 完全被选区矩形框包围的所有标注对象必须被选中
- **且** 如果用户按住 Shift 键进行框选，则将新选中的对象添加到已有选择中

#### Scenario: 全选快捷键

- **当** 用户按下 `Ctrl+A`（Windows）或 `Cmd+A`（macOS）
- **那么** 画布上所有标注对象（箭头、矩形、文字、马赛克）必须被选中
- **且** 如果焦点在输入框中，禁止触发全选

#### Scenario: 取消全选

- **当** 用户点击画布空白区域
- **那么** 所有选中的对象必须取消选中

#### Scenario: Escape 取消选择

- **当** 用户按下 Escape 键
- **那么** 所有选中的对象必须取消选中
- **且** 如果正在进行框选，必须取消框选操作

### Requirement: Editor 多选批量移动

Editor MUST 支持批量移动多个选中的标注对象。

#### Scenario: 拖拽移动多个对象

- **当** 多个对象被选中且用户在任意选中对象的内部区域按住鼠标左键拖拽
- **那么** 所有选中的对象必须同时跟随鼠标移动
- **且** 各对象之间的相对位置必须保持不变
- **且** 移动必须考虑当前缩放比例

#### Scenario: 单选对象移动

- **当** 只有一个对象被选中且用户拖拽该对象
- **那么** 必须保持原有行为（可移动、可调整大小）

### Requirement: Editor 多选批量删除

Editor MUST 支持批量删除多个选中的标注对象。

#### Scenario: 键盘批量删除

- **当** 一个或多个对象被选中且用户按下 Delete 或 Backspace 键
- **那么** 所有选中的对象必须被删除
- **且** 选择状态必须清除
- **且** 如果焦点在输入框中，禁止触发删除

### Requirement: Editor 多选视觉反馈

Editor MUST 为多选状态提供清晰的视觉反馈。

#### Scenario: 多选高亮显示

- **当** 多个对象被选中
- **那么** 所有选中的对象必须同时显示选中高亮状态（蓝色边框）
- **且** 所有选中的对象必须同时显示控制点

#### Scenario: 框选矩形样式

- **当** 用户正在框选
- **那么** 选区矩形框必须显示为蓝色半透明边框（rgba(59, 130, 246, 0.5)）
- **且** 选区矩形框内部必须显示浅蓝色半透明填充（rgba(59, 130, 246, 0.1)）

### Requirement: Editor 箭头标注选择

Editor MUST 支持选择已创建的箭头标注，以便进行编辑或删除操作。

#### Scenario: 点击选择箭头

- **当** 选择工具处于激活状态且用户点击箭头线条或箭头头部区域
- **那么** 该箭头必须被选中
- **且** 箭头必须显示选中高亮状态（蓝色边框）
- **且** 箭头必须显示控制点（起点、终点，以及中点——当箭头长度足够时）

#### Scenario: 中点控制点显示条件

- **当** 箭头被选中且箭头长度大于等于控制点半径的 4 倍（约 24px）
- **那么** 必须显示中点控制点
- **当** 箭头长度小于该阈值
- **那么** 不显示中点控制点，避免与起点/终点控制点重叠

### Requirement: Editor 文字标注选择

Editor MUST 支持选择已创建的文字标注，以便进行编辑或删除操作。

#### Scenario: 点击选择文字

- **当** 选择工具处于激活状态且用户点击文字区域
- **那么** 该文字必须被选中
- **且** 文字必须显示选中高亮状态（蓝色边框）
- **且** 文字必须显示控制点

#### Scenario: 双击进入编辑模式

- **当** 选择工具处于激活状态且用户双击文字
- **那么** 必须进入文字编辑模式
- **且** 必须显示文本输入框
- **且** 输入框必须自动聚焦并选中全部文字
- **且** 如果有多个对象被选中，只编辑被双击的那个文字

### Requirement: Editor 选择工具光标反馈

Editor MUST 在用户使用选择工具时提供正确的光标反馈，帮助用户理解当前操作状态。

#### Scenario: 选择工具默认光标

- **当** 选择工具处于激活状态且鼠标位于画布空白区域
- **那么** 光标必须显示为 default 样式

#### Scenario: 悬停在选中对象上光标

- **当** 选择工具处于激活状态且鼠标悬停在已选中的对象上
- **那么** 光标必须变为 move 样式

#### Scenario: 悬停在未选中对象上光标

- **当** 选择工具处于激活状态且鼠标悬停在未选中的对象上
- **那么** 光标必须变为 pointer 样式

#### Scenario: 悬停在控制点上光标

- **当** 选择工具处于激活状态且鼠标悬停在选中对象的控制点上
- **那么** 光标必须根据控制点类型显示对应样式（move、nwse-resize、nesw-resize、ns-resize、ew-resize）

#### Scenario: 框选时光标

- **当** 用户正在进行框选操作
- **那么** 光标必须显示为 crosshair 样式
