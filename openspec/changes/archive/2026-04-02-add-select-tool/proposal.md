# 变更：实现 Editor 选择工具功能

## 为什么

Editor 左侧工具栏已存在选择工具图标，但缺乏完整的功能实现。当前选择工具只能单选，缺少核心的多选功能（框选、Shift+点击多选、全选），无法满足用户批量操作的需求。

## 变更内容

- 新增「Editor 选择工具入口」需求：定义工具栏入口、激活状态、光标样式
- 新增「Editor 多选功能」需求：框选、Shift+点击多选、全选
- 新增「Editor 多选批量操作」需求：批量移动、批量删除
- 新增「Editor 箭头标注选择」需求：支持点击选中箭头、显示控制点
- 新增「Editor 文字标注选择」需求：支持点击选中文字、显示控制点
- 新增「Editor 选择工具光标反馈」需求：激活时光标、悬停控制点时光标变化

## 影响

- **受影响规范**：`editor`
- **受影响代码**：`src/editor/App.tsx`（选中状态数据结构、鼠标事件处理、光标样式）
- **重大变更**：选中状态从单个 ID (`selectedArrowId`) 改为数组 (`selectedArrowIds: string[]`)
