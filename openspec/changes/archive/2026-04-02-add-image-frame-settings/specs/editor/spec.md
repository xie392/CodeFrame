## 新增需求

### 需求：Editor 图片容器设置 UI 入口

Editor 必须在属性面板中提供图片容器设置的 UI 入口。

#### 场景：属性面板显示容器设置

- **当** 用户在 Editor 中加载图片且未选中任何标注
- **那么** 右侧属性面板必须显示「[frame]」区域
- **且** 「[frame]」区域必须位于「[position]」区域之后

#### 场景：选中标注时隐藏容器设置

- **当** 用户选中了任意标注（箭头、矩形、文字、马赛克）
- **那么** 「[frame]」区域可以收起或隐藏
- **且** 属性面板优先显示选中标注的属性

### 需求：Editor 背景设置 UI

Editor 必须提供背景设置的 UI 控件。

#### 场景：背景类型选择

- **当** 用户查看「[frame]」区域
- **那么** 必须显示背景类型下拉选择器
- **且** 必须包含三个选项：纯色、线性渐变、径向渐变

#### 场景：纯色背景设置 UI

- **当** 用户选择纯色背景类型
- **那么** 必须显示颜色选择器
- **且** 颜色选择器必须支持预设颜色和自定义颜色

#### 场景：渐变背景设置 UI

- **当** 用户选择线性渐变背景类型
- **那么** 必须显示两个颜色选择器（起始色和结束色）
- **且** 必须显示渐变角度滑块（0-360 度）

#### 场景：背景预设 UI

- **当** 用户查看背景设置区域
- **那么** 必须显示预设背景模板按钮组
- **且** 点击预设模板必须更新背景设置

### 需求：Editor 边距设置 UI

Editor 必须提供边距设置的 UI 控件。

#### 场景：边距输入框

- **当** 用户查看「[frame]」区域
- **那么** 必须显示四个边距输入框（上、右、下、左）
- **且** 输入框必须显示对应的标签（t、r、b、l）

#### 场景：边距联动切换

- **当** 用户查看边距设置区域
- **那么** 必须显示联动/独立模式切换按钮
- **且** 联动模式下修改任一值必须同步更新所有值

### 需求：Editor 圆角设置 UI

Editor 必须提供圆角设置的 UI 控件。

#### 场景：圆角滑块

- **当** 用户查看「[frame]」区域
- **那么** 必须显示圆角滑块控件
- **且** 滑块范围必须为 0-100px

#### 场景：圆角联动切换

- **当** 用户查看圆角设置区域
- **那么** 必须显示联动/独立模式切换按钮
- **且** 默认必须为联动模式

### 需求：Editor 阴影设置 UI

Editor 必须提供阴影设置的 UI 控件。

#### 场景：阴影开关

- **当** 用户查看「[frame]」区域
- **那么** 必须显示阴影开关控件
- **且** 默认必须为关闭状态

#### 场景：阴影参数设置 UI

- **当** 用户开启阴影
- **那么** 必须显示阴影颜色选择器
- **且** 必须显示模糊度滑块（范围 0-100px）
- **且** 必须显示 X/Y 偏移量输入框

#### 场景：阴影预设 UI

- **当** 用户查看阴影设置区域且阴影已开启
- **那么** 必须显示预设阴影样式按钮组

### 需求：Editor 比例设置 UI

Editor 必须提供比例设置的 UI 控件。

#### 场景：比例选择器

- **当** 用户查看「[frame]」区域
- **那么** 必须显示比例下拉选择器
- **且** 默认必须为「原始比例」

#### 场景：比例预设选项

- **当** 用户展开比例选择器
- **那么** 必须包含以下预设选项：
  - 原始比例
  - 1:1
  - 4:3
  - 16:9
  - 16:10
  - iPhone (9:19.5)
  - iPad (3:4)

### 需求：Editor 窗口控件设置 UI

Editor 必须提供窗口控件设置的 UI 控件。

#### 场景：窗口控件开关

- **当** 用户查看「[frame]」区域
- **那么** 必须显示窗口控件开关
- **且** 默认必须为关闭状态

#### 场景：窗口控件样式选择

- **当** 用户开启窗口控件
- **那么** 必须显示样式选择器
- **且** 必须包含 macOS 和 Windows 两个选项

### 需求：Editor 水印设置 UI

Editor 必须提供水印设置的 UI 控件。

#### 场景：水印开关

- **当** 用户查看「[frame]」区域
- **那么** 必须显示水印开关控件
- **且** 默认必须为关闭状态

#### 场景：水印文字输入

- **当** 用户开启水印
- **那么** 必须显示水印文字输入框
- **且** 输入框必须支持任意文字

#### 场景：水印参数设置 UI

- **当** 用户开启水印
- **那么** 必须显示位置选择器（五个位置选项）
- **且** 必须显示透明度滑块（范围 0-100%）
- **且** 必须显示字体大小滑块（范围 8-48px）
