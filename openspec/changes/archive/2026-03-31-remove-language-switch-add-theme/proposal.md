# 变更：移除语言切换功能，实现代码展示区域多主题

## 为什么

当前 CodeGen 页面的 LeftPanel 中包含一个「language」语言选择器（仅静态 UI，无交互逻辑），但实际代码中语言始终硬编码为 JavaScript。语言选择器占用面板空间且无实际功能。与此同时，页面已有的「theme」主题选择器虽有 UI，但右侧代码展示区域（窗口背景、标题栏、代码高亮）始终固定为 VS Code Dark+ 风格，切换不生效。

将语言切换功能移除，让主题选择器真正控制右侧代码展示区域的整体视觉风格（包括窗口壳样式和 Shiki 语法高亮配色）。

## 变更内容

- 移除 LeftPanel 中的「language」语言选择器 UI
- 实现代码展示区域多主题：点击主题色块后，右侧整个代码窗口（背景色、标题栏色、代码高亮配色）统一切换
- 每个 Shiki 主题对应一套代码窗口视觉参数（窗口背景色、标题栏背景色、标题栏圆点颜色）
- Shiki 初始化时预加载 4 个主题（对应现有 THEMES 数组）
- `useEffect` 高亮依赖增加 `selectedTheme`，使切换触发重新渲染
- 更新受影响的规范需求

## 影响

- 受影响规范：`codegen`
- 受影响代码：`src/codegen/App.tsx`
