## 新增需求

### 需求：Editor 图片容器圆角设置

Editor 右侧属性面板必须提供图片容器的圆角设置功能，允许用户自定义容器的圆角样式。

#### 场景：圆角设置入口

- **当** 用户查看右侧属性面板的图片容器设置区域
- **那么** 必须显示圆角折叠面板，标题为"容器圆角"
- **且** 面板默认展开

#### 场景：统一圆角模式

- **当** 用户处于统一圆角模式（linked = true）
- **那么** 必须显示单一滑块控件控制所有四个角
- **且** 修改滑块值时四个角的圆角值必须同步更新
- **且** 必须显示联动开关图标，点击可切换到独立模式

#### 场景：独立圆角模式

- **当** 用户切换到独立圆角模式（linked = false）
- **那么** 必须显示四个独立的数值输入框，分别控制左上、右上、右下、左下角
- **且** 每个输入框的范围必须为 0-100px（或 0-50%）
- **且** 修改任一角值时其他角保持不变

#### 场景：圆角单位切换

- **当** 用户查看圆角设置
- **那么** 必须提供单位切换控件，支持像素(px)和百分比(%)
- **且** 切换单位时当前值必须保持不变
- **且** 百分比模式下，值必须相对于容器尺寸计算

#### 场景：圆角预设选择

- **当** 用户查看圆角设置
- **那么** 必须提供圆角预设快速选择器
- **且** 预设必须包含：无圆角(0)、小圆角(8px)、中等圆角(16px)、大圆角(24px)、胶囊形(9999px)
- **且** 选择预设后必须自动切换到统一模式
- **且** 预设选择后单位必须为像素

#### 场景：圆角实时预览

- **当** 用户修改圆角设置
- **那么** 图片容器必须实时更新圆角显示效果
- **且** 四角独立模式时必须显示对应的圆角效果

#### 场景：默认圆角值

- **当** 用户打开 Editor 加载图片
- **那么** 容器默认圆角值必须为 12px
- **且** 默认必须为统一圆角模式
- **且** 默认单位必须为像素(px)

### 需求：Editor 图片圆角设置

Editor 右侧属性面板必须提供图片本身的圆角设置功能，允许用户独立设置图片的圆角样式。

#### 场景：图片圆角设置入口

- **当** 用户查看右侧属性面板的图片容器设置区域
- **那么** 必须显示图片圆角折叠面板，标题为"图片圆角"

- **且** 修改滑块值时图片四个角的圆角值必须同步更新
- **且** 必须显示联动开关图标，点击可切换到独立模式

#### 场景：图片独立圆角模式

- **当** 用户切换到独立圆角模式（linked = false）
- **那么** 必须显示四个独立的数值输入框，分别控制图片的左上、右上、右下、左下角
- **且** 每个输入框的范围必须为 0-100px（或 0-50%）
- **且** 修改任一角值时其他角保持不变

#### 场景：图片圆角单位切换

- **当** 用户查看图片圆角设置
- **那么** 必须提供单位切换控件，支持像素(px)和百分比(%)

#### 场景：图片圆角预设选择

- **当** 用户查看图片圆角设置
- **那么** 必须提供圆角预设快速选择器
- **且** 预设必须包含：无圆角(0)、小圆角(8px)、中等圆角(16px)、大圆角(24px)、胶囊形(9999px)

- **且** 默认必须为统一圆角模式
- **且** 默认单位必须为像素(px)

#### 场景：图片圆角与容器圆角独立

- **当** 用户设置图片圆角和容器圆角
- **那么** 图片圆角和容器圆角必须独立生效
- **且** 图片圆角在容器背景之上显示
- **且** 容器圆角裁剪整个容器区域（包括背景和图片）
