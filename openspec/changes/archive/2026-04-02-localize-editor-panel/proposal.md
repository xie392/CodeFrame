# 变更：Editor 右侧面板中文化

## 为什么

Editor 右侧属性面板当前使用英文文本和终端风格符号（`[`, `]`, `$`, `//`），这与产品的目标用户群体（中文开发者）使用习惯不符，且终端风格符号增加了阅读认知负担。

## 变更内容

- 将属性面板所有英文文本改为中文
- 移除终端风格符号 `[`、`]`、`$`
- 移除注释风格标题 `// properties`
- 预设名称中文化（背景、阴影、比例、水印位置等）

## 影响

- 受影响规范：editor
- 受影响代码：`src/editor/App.tsx`（PropertiesPanel 组件、FrameSettings 组件）
