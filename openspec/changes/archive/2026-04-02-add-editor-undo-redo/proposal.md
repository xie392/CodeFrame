# 变更：Editor 页面撤销/恢复功能

## 为什么

用户在进行图片标注操作时，经常需要撤销错误的操作或恢复误删的标注。当前 Editor 页面虽然工具栏已有撤销/重做按钮，但处于禁用状态，缺乏历史记录机制，用户无法撤销或恢复任何操作，严重影响编辑体验。

## 变更内容

- 创建统一的 Editor 状态管理结构
- 实现历史记录栈（支持撤销/恢复）
- 启用工具栏撤销/重做按钮
- 添加键盘快捷键支持（Ctrl+Z / Ctrl+Shift+Z）
- 支持所有标注操作的撤销/恢复（创建、修改、删除、移动、调整大小）
- 支持裁剪操作的撤销（裁剪后可恢复原图）

## 影响

- 受影响规范：editor
- 受影响代码：
  - `src/editor/App.tsx` - 状态管理重构、历史记录集成
  - `src/editor/hooks/useEditorHistory.ts` - 新建历史记录 Hook
  - `src/editor/types.ts` - 新建统一状态类型定义
- 受影响 UI：工具栏撤销/重做按钮交互
