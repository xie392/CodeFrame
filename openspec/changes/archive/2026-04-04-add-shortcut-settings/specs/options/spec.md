## 新增需求

### 需求：快捷键配置功能

系统**必须**提供快捷键配置功能，允许用户自定义页面内快捷键。

#### 场景：查看快捷键配置

- **当** 用户查看快捷键设置区块
- **那么** 显示「全局快捷键」区块（只读，展示 Chrome 原生命令）
- **且** 显示「页面快捷键」区块（可编辑）
- **且** 每个快捷键项显示命令名称和当前快捷键组合

#### 场景：区分全局和页面快捷键

- **当** 用户查看快捷键设置
- **那么** 「全局快捷键」区块显示 Chrome 原生命令（Alt+Shift+S/R/F/D）
- **且** 显示「跳转配置」按钮，点击后跳转至 `chrome://extensions/shortcuts`
- **且** 「页面快捷键」区块显示可自定义的快捷键配置

### 需求：快捷键录制功能

系统**必须**提供快捷键录制功能，允许用户通过按键设置新的快捷键组合。

#### 场景：进入快捷键录制模式

- **当** 用户点击某个快捷键的编辑按钮
- **那么** 该快捷键项进入录制模式
- **且** 显示「请按下新的快捷键组合...」提示
- **且** 原快捷键显示区域变为输入框样式

#### 场景：录制有效快捷键

- **当** 用户处于录制模式并按下有效快捷键组合（如 `Ctrl+S`）
- **那么** 系统解析并显示该快捷键组合
- **且** 自动保存到 `chrome.storage.local`
- **且** 退出录制模式

#### 场景：取消录制

- **当** 用户在录制模式下按下 `Escape` 键
- **那么** 取消录制，恢复原快捷键显示
- **且** 不保存任何更改

#### 场景：清除快捷键

- **当** 用户点击快捷键的「清除」按钮
- **那么** 该快捷键设置为空（禁用该快捷键）
- **且** 显示「未设置」占位符

#### 场景：恢复默认快捷键

- **当** 用户点击快捷键的「恢复默认」按钮
- **那么** 该快捷键恢复为默认值
- **且** 自动保存到 `chrome.storage.local`

### 需求：快捷键冲突检测

系统**必须**检测快捷键冲突，阻止设置冲突的快捷键。

#### 场景：检测系统快捷键冲突

- **当** 用户尝试设置系统保留快捷键（如 `Ctrl+T`、`F5`）
- **那么** 阻止设置并显示警告提示「该快捷键与系统快捷键冲突」
- **且** 保持原快捷键不变

#### 场景：检测已配置快捷键冲突

- **当** 用户尝试设置已被其他命令使用的快捷键
- **那么** 阻止设置并显示警告提示「该快捷键已被 [命令名] 使用」
- **且** 保持原快捷键不变

#### 场景：显示冲突提示

- **当** 检测到快捷键冲突
- **那么** 显示冲突提示弹窗
- **且** 提供替代快捷键建议（如 `Alt+S` 替代 `Ctrl+S`）

### 需求：页面快捷键开关

系统**必须**提供页面快捷键开关，允许用户启用或禁用自定义快捷键。

#### 场景：启用页面快捷键

- **当** 用户开启「启用页面快捷键」开关
- **那么** 页面快捷键功能在 Popup/Editor/CodeGen 页面生效
- **且** 设置自动保存到 `chrome.storage.local`

#### 场景：禁用页面快捷键

- **当** 用户关闭「启用页面快捷键」开关
- **那么** 页面快捷键功能在所有页面失效
- **且** 设置自动保存到 `chrome.storage.local`
- **且** 全局快捷键（Chrome 原生命令）不受影响

### 需求：页面快捷键执行

系统**必须**在支持的页面内执行自定义快捷键命令。

#### 场景：Popup 页面快捷键触发

- **当** 用户在 Popup 页面按下已配置的自定义快捷键
- **那么** 执行对应的命令（可视区域截图、区域截图等）
- **且** 关闭 Popup 弹窗

#### 场景：Editor 页面快捷键触发

- **当** 用户在 Editor 页面按下已配置的自定义快捷键
- **那么** 执行对应的命令

#### 场景：CodeGen 页面快捷键触发

- **当** 用户在 CodeGen 页面按下已配置的自定义快捷键
- **那么** 执行对应的命令

#### 场景：输入框聚焦时不触发快捷键

- **当** 用户在输入框或文本区域中按下快捷键
- **那么** 不触发快捷键命令
- **且** 正常输入文字

## 修改需求

### 需求：快捷键展示

系统**必须**展示扩展快捷键配置，帮助用户了解快捷操作方式。

#### 场景：查看快捷键配置

- **当** 用户查看快捷键区块
- **那么** 显示「全局快捷键」区块（展示 Chrome 原生命令：Alt+Shift+S/R/F/D）
- **且** 显示「页面快捷键」区块（可编辑的自定义快捷键）
- **且** 快捷键以视觉化按键形式展示

#### 场景：快捷键配置入口

- **当** 用户点击「全局快捷键」区块的「跳转配置」按钮
- **那么** 在新标签页打开 `chrome://extensions/shortcuts`
- **且** 自动定位到 CodeFrame 扩展

#### 场景：快捷键不可修改提示

- **当** 用户查看「全局快捷键」区块
- **那么** 显示提示「全局快捷键需在 Chrome 扩展管理页面修改」
- **且** 提供「跳转配置」按钮
