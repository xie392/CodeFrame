# 变更：实现文字标注功能

## 为什么

Editor 已实现箭头和矩形标注，但缺少文字标注功能。文字标注是图片标注工具的核心功能之一，用户需要在图片上添加文字说明、注释或标签，以增强标注的表达能力。

## 变更内容

- 新增文字标注工具入口（Type 图标，已存在于工具栏）
- 支持点击画布创建文字标注对象
- 支持选中文字标注进行移动和编辑
- 支持双击文字标注进入编辑模式
- 支持拖拽四角控制点调整字号
- 支持删除选中的文字标注（Delete/Backspace 键）
- 支持文字标注样式配置（颜色、字号、粗体、斜体）
- 支持文字标注在属性面板中显示和修改属性

## 影响

- 受影响规范：editor
- 受影响代码：
  - `src/editor/App.tsx` - 添加文字标注状态管理、绘制逻辑、事件处理
  - `src/editor/App.tsx` - 更新属性面板支持文字样式配置
