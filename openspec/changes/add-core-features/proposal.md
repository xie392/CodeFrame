# 变更：添加 CodeFrame 核心功能

## 为什么

CodeFrame 作为 Chrome 扩展，需要为开发者和内容创作者提供代码转图片和截图美化两大核心功能。当前项目处于初始阶段，需要建立完整的功能规范以指导后续开发。

## 变更内容

### 核心模块

- **代码转图片模块**
  - 代码输入与语法高亮
  - 语言自动检测
  - 主题选择（5个免费 + 15个 Pro）
  - 背景设置（纯色/渐变/自定义）
  - 窗口样式（macOS/Windows/无边框）
  - 显示行号、字体大小调整

- **截图美化模块**
  - 捕获当前标签页
  - 上传本地图片
  - 设备边框（MacBook/Browser/iPhone/iPad）
  - 背景渐变与自定义上传
  - 圆角/阴影调整
  - 社交平台尺寸预设

- **导出模块**
  - PNG/WebP/SVG 格式导出
  - 复制到剪贴板
  - 多分辨率导出（Pro）
  - 无水印导出（Pro）

- **付费系统**
  - License 激活与验证
  - Pro 功能解锁
  - 配置预设保存（Pro）

### 免费版与 Pro 版差异

| 功能 | 免费版 | Pro 版 |
|------|--------|--------|
| 代码主题 | 5 个 | 20+ |
| 背景选择 | 3 种 | 全部 |
| 设备边框 | MacBook/Browser/无边框 | 全部设备 |
| 水印 | 有 | 无 |
| 最大分辨率 | 1920x1080 | 4K |
| 截图美化次数 | 3 次/天 | 无限 |
| 自定义背景 | 否 | 是 |

## 影响

- 受影响规范：无（新建项目）
- 新增规范：
  - `code-to-image` - 代码转图片功能
  - `screenshot-beautify` - 截图美化功能
  - `payment-system` - 付费系统
- 受影响代码：全新代码库
