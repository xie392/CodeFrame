# CodeFrame 页面设计文档

> 本文档用于喂给 AI 生成 UI 设计稿
> 项目：CodeFrame - Chrome 扩展（代码转图片 + 截图美化）
> 技术栈：WXT + SolidJS + Tailwind CSS

## 页面一：Popup 功能选择面板

### 页面用途
浏览器扩展点击图标后弹出的功能选择界面，提供快速截图入口和快捷操作。

### 整体布局

- **尺寸**：固定宽度 320px，高度自适应
- **背景**：浅灰白色渐变 (#F9FAFB → #FFFFFF)
- **内边距**：16px
- **圆角**：16px（作为浏览器弹窗）

### 头部区域

**Logo 区域**
- 位置：顶部居中
- 内容：渐变品牌图标（蓝紫渐变 ▶ 形状）+ "CodeFrame" 文字
- 字体：Inter Bold，18px
- 图标尺寸：24x24px

**副标题**
- 文字："轻巧好用的**截图**工具"
- "截图"二字：紫色高亮 (#7C3AED) + 下划线 + 手绘风格箭头指向
- 箭头：紫色曲线箭头，从右侧指向"截图"
- 字体：14px，颜色 #6B7280

### 主要功能区（三列网格）

三列等宽按钮网格，间距 12px：

| 按钮 | 图标背景色 | 图标内容 | 文字 |
|------|-----------|---------|------|
| 左 | 紫色渐变 (#9333EA → #C084FC) | 显示器/窗口图标 | 可视区域 |
| 中 | 绿色渐变 (#22C55E → #86EFAC) | 裁剪选择框图标 | 选择区域 |
| 右 | 蓝色渐变 (#3B82F6 → #60A5FA) | 手机/竖屏图标 | 整个页面 |

**按钮样式：**
- 圆形图标容器：56x56px，渐变背景，微阴影
- 图标：24x24px，白色线条风格
- 文字：12px，#374151，按钮下方居中
- 悬停效果：图标上浮 + 阴影加深

### 扩展选项列表

列表样式，每项左侧图标 + 右侧文字/箭头：

```
┌─────────────────────────────────┐
│ ⏱  延时截取可视区域      3s   > │
│ 🖥  桌面窗口                   > │
│ 🖼  编辑本地或粘贴板图片       > │
└─────────────────────────────────┘
```

**样式细节：**
- 行高：48px
- 图标：20x20px，灰色 (#6B7280)
- 文字：14px，#374151
- 右侧：时间/箭头图标
- 分隔线：底部 1px #E5E7EB
- 悬停：背景 #F3F4F6

### 底部

- 文字："使用帮助 - 功能反馈"
- 样式：12px，#9CA3AF，居中
- 链接样式，悬停下划线

## 页面二：Options 截图结果展示页

### 页面用途
点击 popup 的"可视区域"后跳转的页面，展示截图结果并提供进入编辑器的入口。

### 整体布局

- **全屏布局**：100vw × 100vh
- **顶部导航栏**：固定高度 56px，白色背景，底部阴影
- **主体区域**：浅灰色网格背景 (#F9FAFB + 点状网格)

### 顶部导航栏

**三区域布局：**

```
┌──────────┬──────────────────────┬──────────┐
│   Logo   │   编辑美化截图按钮    │  工具组  │
└──────────┴──────────────────────┴──────────┘
```

**左侧 - Logo**
- 渐变色图标 (24x24) + "CodeFrame" 文字
- 图标：蓝紫渐变三角形组合
- 字体：Inter SemiBold，16px

**中间 - 核心按钮**
- 文字："编辑美化截图"
- 左侧带编辑/画笔图标
- 样式：白色背景，1px #E5E7EB 边框，圆角 8px
- 内边距：8px 16px
- 悬停：背景 #F9FAFB

**右侧 - 工具按钮组**
- 下载按钮：深色背景 (#111827)，白色文字，圆角 6px
  - 图标：下载箭头 + "下载" 文字
- 复制按钮：图标按钮，24x24px
- 删除按钮：红色垃圾桶图标 (24x24px)

### 主体画布区域

**背景：**
- 浅灰白色 (#F9FAFB)
- 点状网格图案（间距 20px，点大小 2px，颜色 #E5E7EB）

**截图预览卡片：**
- 居中展示，最大宽度 80%
- 白色卡片背景
- 圆角 12px
- 阴影：0 4px 6px -1px rgba(0,0,0,0.1)

**截图内容示例（ShotEasy Landing Page）：**
- 顶部：CodeFrame Logo + 导航菜单
- 主标题："编辑、调整大小和美化任何照片"（紫蓝渐变文字）
- 副标题："无需注册。更快捷的在线编辑照片方式 免费 ✨"
- CTA 按钮：深色圆角按钮 "免费获取 ShotEasy 扩展程序"
- 功能标签：三个白色圆角标签
- 上传区域：虚线边框拖放区
- 底部：截图编辑器预览（含风景图片）

## 页面四：右侧属性面板（详细设计）

### 面板尺寸

- 宽度：280px
- 背景：白色
- 内边距：16px
- 右侧固定定位

### 面板内容（从上到下）

**1. 尺寸选择**
```
┌─────────────────────────────┐
│ ☐ Auto                      │
│ 2044 x 951 px          [▼]  │
└─────────────────────────────┘
```

**2. Quick 快捷操作**
四个图标按钮横向排列：
- 裁剪图标
- 翻转/旋转图标
- 特效图标
- 网格布局图标

样式：24x24px，灰色，悬停蓝色

**3. Scale 缩放滑块**
```
Scale
[━━━━━━━●━━━━━━━━━━]  默认值约 50%
```
- 滑条：蓝色进度条 (#3B82F6)
- 轨道：浅灰色 (#E5E7EB)
- 滑块：白色圆点，带阴影

**4. Padding 内边距滑块**
同上样式，可设置为 0

**5. Rounded 圆角滑块**
同上样式，控制截图卡片圆角

**6. Shadow 阴影滑块**
同上样式，控制阴影强度

**7. Frame 边框样式**
```
Frame                                    More >
┌────┐┌────┐┌────┐┌────┐┌────┐
│ ⬜  ││ ⬜  ││ ⬜  ││ ⬜  ││ ⬜  │
└────┘└────┘└────┘└────┘└────┘
```
- 5 种预设边框样式
- 小卡片预览
- 选中状态：蓝色边框

**8. Background 背景选择**
```
Background                             More >
●  ●  ●  ●  ●  ●  ●
```
- 7 个渐变色圆形按钮
- 颜色序列：
  1. 紫蓝渐变 (#8B5CF6 → #3B82F6)
  2. 粉紫渐变 (#EC4899 → #8B5CF6)
  3. 红紫渐变 (#EF4444 → #7C3AED)
  4. 橙红渐变 (#F97316 → #EF4444)
  5. 青蓝渐变 (#06B6D4 → #3B82F6)
  6. 蓝紫渐变 (#3B82F6 → #8B5CF6)
  7. 粉紫渐变 (#F472B6 → #A855F7)
- 圆形尺寸：32x32px
- 选中状态：白色边框 + 阴影

**9. Watermark 水印开关**
```
Watermark                          [Toggle]
```
- 文字左侧
- 开关右侧（iOS 风格）

**10. 底部下载区**
```
┌─────────────────────────────────────┐
│ [⬇] Download              [📋] [⚙] │
│     1x as PNG                       │
└─────────────────────────────────────┘
```
- 主按钮：深色背景，圆角 8px
- 右侧两个图标按钮

## 页面五：Options 空白编辑器（初始状态）

### 页面用途
点击 popup 的"编辑本地或粘贴板图片"后跳转的页面，等待用户导入图片。

### 整体布局

与页面三相同的三栏布局：
- 顶部工具栏
- 中央画布区域
- 右侧属性面板

### 顶部工具栏

同页面三，但右侧尺寸显示为 "Auto Adaptive screenshot size"

### 中央画布区域

**拖放区域：**
```
┌─────────────────────────────────────┐
│                                     │
│           ┌─────────┐               │
│           │  🖼️+   │               │
│           │         │               │
│           │  Click or Drag          │
│           │  image to this area     │
│           │  or Paste image         │
│           └─────────┘               │
│                                     │
│   [📷]  [T]  [</>]  [🏷️]            │
│                                     │
└─────────────────────────────────────┘
```

**拖放区域样式：**
- 虚线边框：2px dashed #D1D5DB
- 圆角：12px
- 尺寸：约 300x200px
- 背景：透明
- 图标：图片 + 加号，灰色
- 文字：14px，#6B7280

**底部浮动按钮组：**
- 从左到右：截图、文字、代码、二维码
- 样式：圆形图标按钮，40x40px
- 背景：白色，阴影，悬停上浮

### 右侧属性面板

与页面四相同，但滑块均为初始值：
- Scale：约 50%
- Padding：0
- Rounded：0
- Shadow：0

### 底部工具栏

同页面三，显示 Download 按钮。

## 设计系统规范

### 颜色系统

**主色：**
- 品牌紫：#7C3AED
- 品牌蓝：#3B82F6
- 渐变色：linear-gradient(135deg, #6366F1 0%, #EC4899 100%)

**中性色：**
- 背景白：#FFFFFF
- 背景灰：#F9FAFB
- 边框灰：#E5E7EB
- 文字主：#111827
- 文字次：#6B7280
- 文字弱：#9CA3AF

**功能色：**
- 成功绿：#22C55E
- 危险红：#EF4444
- 警告黄：#F59E0B

### 字体系统

- 字体族：Inter, -apple-system, sans-serif
- 标题：18px SemiBold
- 正文：14px Regular
- 小字：12px Regular
- 按钮：14px Medium

### 圆角系统

- 小：4px（按钮、标签）
- 中：8px（卡片、输入框）
- 大：12px（面板、弹窗）
- 全：9999px（圆形按钮）

### 阴影系统

- 小：0 1px 2px rgba(0,0,0,0.05)
- 中：0 4px 6px rgba(0,0,0,0.1)
- 大：0 10px 15px rgba(0,0,0,0.1)

## 页面路由关系

```
Popup (页面一)
    │
    ├── 点击"可视区域" ──→ Options 截图结果页 (页面二)
    │                              │
    │                              └── 点击"编辑美化截图" ──→ Options 编辑器 (页面三)
    │
    └── 点击"编辑本地或粘贴板图片" ──→ Options 空白编辑器 (页面五)
                                          │
                                          └── 拖入图片后 ──→ 同页面三效果
```
