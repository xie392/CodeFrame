# 变更：实现矩形标注功能

## 为什么

Editor 图片编辑器已实现箭头标注功能，但矩形标注工具虽然存在于工具栏中，实际功能尚未实现。矩形标注是图片标注的核心功能之一，用于标记图片中的特定区域，是 P0 优先级功能。

## 变更内容

- 新增矩形标注数据模型 `RectShape`，定义矩形的位置、尺寸、样式属性
- 新增矩形绘制功能，支持鼠标拖拽绘制矩形
- 新增矩形选择、移动、调整大小功能
- 新增矩形属性面板，支持颜色、线宽、填充透明度、边框样式配置
- 复用现有箭头标注的交互模式和 UI 组件模式

## 影响

- 受影响规范：`editor`
- 受影响代码：`src/editor/App.tsx`
