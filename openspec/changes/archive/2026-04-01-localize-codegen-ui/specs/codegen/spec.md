# CodeGen UI 文本中文化

## 修改需求

### 需求：侧边栏标签必须中文化

CodeGen 页面左侧面板**必须**将所有英文标签替换为中文。

#### 场景：SectionLabel 区块标题显示中文

- 给定用户打开 CodeGen 页面
- 当查看左侧面板各设置区块时
- 那么所有区块标题**必须**显示为中文：主题、背景、内边距、窗口、圆角、字体、水印

#### 场景：Toggle 开关标签显示中文

- 给定用户打开 CodeGen 页面
- 当查看标题栏、阴影、行号等开关时
- 那么开关旁的标签**必须**显示为中文：标题栏、阴影、行号

#### 场景：Popover 弹窗标签显示中文

- 给定用户打开圆角设置弹窗
- 当查看外圆角和内圆角选项时
- 那么标签**必须**显示为「外圆角」和「内圆角」

### 需求：按钮和输入框文案必须中文化

导出按钮和水印输入框的文案**必须**使用中文显示。

#### 场景：水印输入框显示中文占位符

- 给定用户开启水印功能
- 当查看水印输入框时
- 那么占位符**必须**显示为「水印文字...」

#### 场景：导出按钮显示中文文案

- 给定用户点击导出按钮
- 当导出进行中时，按钮**必须**显示「导出中...」
- 当导出未进行时，按钮**必须**显示「$ 导出图片」

### 需求：必须移除旧 code_input 标题

侧边栏顶部遗留的 `code_input` 旧标题**必须**移除。

#### 场景：侧边栏顶部无旧标题

- 给定用户打开 CodeGen 页面
- 当查看左侧面板顶部时
- 那么**禁止**显示 `code_input` 文本
- 且面板布局**必须**保持正常
