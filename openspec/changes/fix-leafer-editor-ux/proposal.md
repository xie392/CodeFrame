## 为什么

Leafer 路径编辑器存在多项 UX 缺陷：绘制时无实时预览路径、箭头渲染有重叠瑕疵、文字编辑时画面偏移、马赛克拖拽卡顿、裁剪无内容预览且可超出图片范围、默认样式不符合用户期望、属性不记忆上次设置。这些问题严重影响编辑体验，需要系统性修复。

## 变更内容

1. **箭头样式改为开放箭头**：将当前三角形+直线（有明显重叠）改为 `——>` 开放箭头样式（line + 末端 V 形标记，无填充三角形）
2. **修复文字编辑偏移**：文字编辑时整体画面偏移，编辑结束后恢复；需修复文字编辑的坐标变换逻辑
3. **优化马赛克拖拽性能**：马赛克拖拽卡顿，需优化马赛克区域图片重生成逻辑（缓存/增量更新/防抖）
4. **裁剪增强**：裁剪拖拽时显示区域内容预览；裁剪区域钳制到图片范围，不可超出
5. **选择工具增加框选区域**：select 工具下可拖拽绘制选取框进行批量选择
6. **默认属性调整**：箭头/矩形默认线宽 4px、颜色红色；文字默认 30px、红色；马赛克块大小 30px、透明度 100%
7. **绘制实时预览路径**：绘制箭头/矩形/马赛克时，鼠标移动过程中实时显示从起点到当前位置的预览图形
8. **属性记忆**：上次设置的工具属性（颜色、线宽、字号等）应在下次使用时保持，配合"保存操作历史"设置持久化

## 功能 (Capabilities)

### 新增功能
- `drawing-preview`: 绘制过程中实时预览路径（箭头/矩形/马赛克拖拽时显示半透明预览）
- `marquee-selection`: 选择工具的框选区域功能（拖拽绘制选取框批量选择图形）
- `crop-preview`: 裁剪区域内容预览（半透明遮罩+裁剪区域透明显示内容）

### 修改功能
- `arrow-style`: 箭头渲染样式从三角形+直线改为开放 V 形箭头
- `text-editing`: 修复文字编辑时的画面偏移问题
- `mosaic-performance`: 优化马赛克拖拽性能
- `crop-bounds`: 裁剪区域钳制到图片范围
- `default-styles`: 调整默认属性值（线宽、颜色、字号、马赛克参数）
- `property-memory`: 工具属性记忆（上次设置持久化到下次使用）
