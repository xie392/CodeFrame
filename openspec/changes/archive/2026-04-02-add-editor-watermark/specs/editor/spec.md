## 新增需求

### 需求：Editor 文字水印渲染

Editor 必须在图片容器上渲染文字水印，水印支持自定义文字、位置、透明度和字体大小。

#### 场景：开启文字水印

- **当** 用户开启水印开关且输入了水印文字
- **那么** 图片容器上必须显示文字水印
- **且** 水印必须根据位置设置显示在指定角落
- **且** 水印必须根据透明度设置显示对应的透明效果

#### 场景：水印位置选择

- **当** 用户选择水印位置
- **那么** 水印必须显示在对应位置：
  - `top-left`：左上角
  - `top-right`：右上角
  - `bottom-left`：左下角
  - `bottom-right`：右下角（默认）

#### 场景：水印透明度调节

- **当** 用户调节水印透明度滑块
- **那么** 水印透明度必须在 0-100% 范围内变化
- **且** 默认透明度必须为 50%

#### 场景：水印字体大小调节

- **当** 用户调节水印大小滑块
- **那么** 水印字体大小必须在 8-48px 范围内变化
- **且** 默认字体大小必须为 14px

#### 场景：水印颜色自动适配

- **当** 背景为深色（亮度 < 128）
- **那么** 水印颜色必须为白色
- **当** 背景为浅色（亮度 >= 128）
- **那么** 水印颜色必须为黑色

#### 场景：默认水印状态

- **当** 用户首次打开 Editor 加载图片
- **那么** 水印必须默认关闭
- **且** 默认位置为右下角
- **且** 默认透明度为 50%
- **且** 默认字体大小为 14px
- **且** 默认文字为空

### 需求：Editor 图片水印渲染

Editor 必须支持使用图片作为水印，允许用户上传 Logo 图片作为水印。

#### 场景：上传图片水印

- **当** 用户点击上传图片水印按钮
- **那么** 必须弹出文件选择对话框
- **且** 仅支持 PNG、JPG、WEBP 格式
- **且** 上传成功后必须显示图片预览

#### 场景：图片水印显示

- **当** 用户上传了图片水印且水印开关开启
- **那么** 图片必须显示在指定位置
- **且** 图片大小必须根据设置调整

#### 场景：图片水印大小调节

- **当** 用户调节图片水印大小滑块
- **那么** 图片水印大小必须在 32-200px 范围内变化
- **且** 默认大小必须为 64px

#### 场景：图片水印与文字水印互斥

- **当** 用户上传了图片水印
- **那么** 必须显示图片水印，隐藏文字水印
- **当** 用户清空图片水印
- **那么** 必须恢复显示文字水印（如有设置）

#### 场景：拖拽上传图片水印

- **当** 用户将图片文件拖拽到水印上传区域
- **那么** 必须接受拖拽上传
- **且** 显示拖拽悬停状态反馈

### 需求：Editor 水印导出

Editor 导出图片时必须支持选择是否包含水印。

#### 场景：导出包含水印

- **当** 用户导出图片且勾选「包含水印」选项
- **那么** 导出的图片必须包含水印效果

#### 场景：导出不包含水印

- **当** 用户导出图片且取消勾选「包含水印」选项
- **那么** 导出的图片必须不包含水印

#### 场景：导出时默认包含水印

- **当** 用户导出图片
- **那么** 「包含水印」选项必须默认勾选

### 需求：Editor 水印 UI 控件

Editor 必须提供完整的水印设置 UI 控件。

#### 场景：水印开关

- **当** 用户查看「水印」折叠面板
- **那么** 必须显示水印开关控件
- **且** 默认必须为关闭状态

#### 场景：水印位置选择器

- **当** 用户开启水印
- **那么** 必须显示位置选择器
- **且** 必须包含四个选项：左上、右上、左下、右下
- **且** 默认必须为右下

#### 场景：图片水印上传区域

- **当** 用户开启水印
- **那么** 必须显示图片上传区域
- **且** 上传区域必须支持点击上传和拖拽上传
- **且** 上传成功后必须显示图片预览和删除按钮

#### 场景：图片水印大小控制

- **当** 用户上传了图片水印
- **那么** 必须显示图片大小滑块
- **且** 滑块范围必须为 32-200px
- **且** 默认值必须为 64px
