# 变更：移除 Editor 属性面板中的位置区域和图片容器标题

## 为什么

Editor 属性面板中的"位置"区域存在以下问题：
1. 当无选中元素时，显示硬编码的"X: 0, Y: 0, 宽: 0, 高: 0"，无实际作用
2. 当选中标注元素时，位置编辑功能使用频率低，用户主要通过拖拽调整位置

"图片容器"标题也存在冗余问题：
- 现在属性面板中保留的设置都是图片容器相关设置，没有必要单独区分标题
- 标题占用空间，增加视觉复杂度

## 变更内容

- 移除属性面板顶部的"位置"区域（包括无选中时的默认显示和选中元素时的坐标编辑）
- 移除 FrameSettings 组件中的"图片容器"标题

## 影响

- 受影响规范：`editor`
- 受影响代码：`src/editor/App.tsx`
  - 移除 `PropertiesPanel` 组件中的"位置"区域 JSX（第 2703-2819 行）
  - 移除 `FrameSettings` 组件中的"图片容器"标题（第 1763-1769 行）
