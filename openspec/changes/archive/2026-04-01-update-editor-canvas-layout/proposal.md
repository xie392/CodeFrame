# 变更：调整 Editor 图片显示区域布局并添加缩放功能

## 为什么

Editor 页面的图片显示区域当前使用 `flex-1` 布局占满整个画布空间，图片通过 `max-w-full max-h-full object-contain` 自适应拉伸到最大尺寸，视觉效果过于庞大。用户希望图片区域类似 CodeGen 页面中代码窗口的呈现方式——固定中等尺寸、居中显示、不占满屏幕——同时支持缩放交互。

## 变更内容

- 将 Editor 中央画布区域的图片渲染从"全屏自适应"改为"固定尺寸 + 画布内居中"模式
- 图片默认尺寸限制为中等大小（初始宽度约 60% 画布可用空间，上限 800px），类似 CodeGen 的代码窗口
- 新增画布缩放功能（支持鼠标滚轮缩放、缩放按钮控制、缩放百分比显示与重置），复用 CodeGen 已有的 `zoomAt` 缩放算法模式
- 新增画布平移功能，缩放后可通过拖拽平移查看图片不同区域
- 新增底部浮动缩放控制条 UI

## 影响

- 受影响规范：editor（新增规范）
- 受影响代码：
  - `src/editor/App.tsx` — 主布局和缩放逻辑
  - `src/editor/components/CanvasImage.tsx` — 图片渲染尺寸约束
  - `src/styles/globals.css` — editor 画布相关样式
