# Drawing Tools Spec - 绘制工具功能规格

## 一、工具栏结构

工具栏左侧垂直排列，分为两个区域：

**绘制工具区（互斥活跃工具）**
- 选择工具（默认）
- 箭头工具
- 矩形工具
- 文字工具
- 马赛克工具

**操作区**
- 裁剪按钮（点击进入裁剪模式，非工具切换）
- 分隔线
- 撤销
- 重做

## 二、鼠标事件优先级（核心交互规则）

任何绘制工具下，mousedown 时按以下顺序判定：

1. **命中已有图形？** → 选中该图形，进入拖动/缩放交互
2. **当前是绘制工具？** → 开始拖拽绘制新图形
3. **当前是选择工具？** → 开始框选

补充规则：
- 点击空白区域 → 取消选中 + 如果是绘制工具则开始绘制
- 按 Esc → 取消选中，回到绘制就绪状态

## 三、各工具交互规格

### 3.1 选择工具

| 操作 | 触发 | 行为 |
|------|------|------|
| 选中单个图形 | 点击图形 | 高亮选中，显示控制点 |
| 框选多个图形 | 空白区域拖拽 | 选中框内所有图形 |
| 移动图形 | 拖动已选中图形 body | 平移 |
| 缩放图形 | 拖动控制点 | 按各图形类型缩放 |
| 取消选中 | 点击空白 / Esc | 清除选中 |
| 全选 | Ctrl+A | 选中所有图形 |

### 3.2 箭头工具

**绘制过程**
1. mousedown 空白 → 记录起点
2. mousemove → 实时预览从起点到鼠标位置的箭头
3. mouseup → 确认创建箭头图形

**选中后交互**
| 操作 | 触发 | 行为 |
|------|------|------|
| 移动 | 拖动线段中点 | 两端点同步平移 |
| 调整起点 | 拖动起点圆点 | 移动起点位置 |
| 调整终点 | 拖动终点圆点 | 移动终点位置 |

**选中态视觉**：起点和终点各显示一个可拖动圆点

**属性面板**：颜色、线宽、箭头大小、单箭头/双箭头

### 3.3 矩形工具

**绘制过程**
1. mousedown 空白 → 记录起点
2. mousemove → 实时预览矩形
3. mouseup → 确认创建矩形图形

**选中后交互**
| 操作 | 触发 | 行为 |
|------|------|------|
| 移动 | 拖动 body | 平移矩形 |
| 缩放 | 拖动 8 控制点 | 自由缩放（无比例约束） |

**选中态视觉**：8 个方形控制点（四角 + 四边中点）

**属性面板**：边框颜色、线宽、填充透明度、边框样式(实线/虚线)

### 3.4 文字工具

**创建过程**
1. 点击空白位置 → 创建文字框，自动进入编辑模式
2. 输入文字 → 实时更新内容
3. 失焦 / Enter → 确认编辑，退出编辑模式

**选中后交互**
| 操作 | 触发 | 行为 |
|------|------|------|
| 移动 | 拖动 body | 平移文字 |
| 缩放 | 拖动 4 角控制点 | 等比缩放（映射为改变字号） |
| 编辑 | 双击 | 进入文字编辑模式 |

**缩放映射规则**：字号 = 原字号 * 缩放比例，离散化到整数 px

**选中态视觉**：4 个角控制点 + 虚线边框

**属性面板**：文字颜色、字号、粗体、斜体

### 3.5 马赛克工具

**绘制过程**
1. mousedown 空白 → 记录起点
2. mousemove → 实时预览马赛克矩形区域
3. mouseup → 确认创建马赛克图形

**渲染策略**：作为独立图形叠加层，对覆盖区域做像素模糊处理，导出时合并到图片像素

**选中后交互**
| 操作 | 触发 | 行为 |
|------|------|------|
| 移动 | 拖动 body | 平移马赛克区域 |
| 缩放 | 拖动 8 控制点 | 自由缩放 |

**选中态视觉**：8 个方形控制点

**属性面板**：方块大小、透明度

### 3.6 裁剪模式

裁剪是**独立模态操作**，不是工具栏中的工具切换。

**生命周期**
1. 点击裁剪按钮 → 进入裁剪模式
2. 拖拽绘制裁剪区域 → 非选中区域暗化
3. 拖动 8 控制点 → 调整裁剪范围
4. 确认 → 执行裁剪（修改画布、调整所有图形坐标）
5. 取消 / Esc → 退出裁剪模式，恢复原状

**裁剪确认后的处理**
1. 修改图片区域（只保留裁剪框内的部分）
2. 所有图形坐标偏移（减去裁剪框左上角）
3. 部分在框内的图形保留，完全在框外的删除

## 四、统一图形模型

所有图形共享基础属性：

```
interface BaseShape {
  id: string;
  type: 'arrow' | 'rect' | 'text' | 'mosaic';
  zIndex: number;      // 图层层级
}
```

**图层规则**
- 选中判定：从 zIndex 高到低检测命中（最上层优先）
- 图层排序：属性面板中上移/下移按钮
- 新创建图形自动获得最高 zIndex

## 五、选中图形视觉规范

| 图形类型 | 控制点 | 拖动行为 |
|----------|--------|----------|
| 箭头 | 起点/终点 2 个圆点 | 中点拖动=平移，端点拖动=调整 |
| 矩形 | 8 个方形控制点 | body=平移，控制点=自由缩放 |
| 马赛克 | 8 个方形控制点 | body=平移，控制点=自由缩放 |
| 文字 | 4 个角控制点 + 虚线边框 | body=平移，角控制点=等比缩放 |

**多选态**：虚线包围盒覆盖所有选中图形，可整体移动，不可缩放

## 六、右侧属性面板

**无选中时**：显示帧设置（背景、边距、圆角、阴影、水印等）

**选中图形时**：
- 显示该类型的特有属性（颜色、线宽等）
- 通用操作：图层上移/下移、删除

**多选不同类型时**：仅显示通用操作（图层 + 删除）

## 七、键盘快捷键

| 快捷键 | 行为 |
|--------|------|
| V / Escape | 切换到选择工具 |
| A | 箭头工具 |
| R | 矩形工具 |
| T | 文字工具 |
| M | 马赛克工具 |
| Delete / Backspace | 删除选中图形 |
| Ctrl+A | 全选 |
| Ctrl+Z | 撤销 |
| Ctrl+Shift+Z | 重做 |
| Esc | 取消选中 / 退出裁剪模式 |

## 八、功能优先级

**P0 - 核心**
- 选择工具（点选、框选、拖动）
- 箭头工具（绘制、端点调整、属性）
- 矩形工具（绘制、缩放、属性）
- 文字工具（创建、编辑、移动）
- 右侧属性面板

**P1 - 重要**
- 马赛克工具
- 裁剪模式
- 删除（Delete 键 + 右键菜单）
- 撤销/重做

**P2 - 增强**
- 多选框选
- 图层排序
- 快捷键
- 属性记忆（记住上次使用的样式）
