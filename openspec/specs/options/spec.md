## 需求
### 需求：设置页面布局

系统**必须**提供设置页面入口，用户可通过 Chrome 扩展管理页面或扩展图标右键菜单访问设置页面。

#### 场景：用户访问设置页面

- **当** 用户打开扩展设置页面
- **那么** 显示亮色玻璃拟态风格的设置界面，包含 Header、通用设置、快捷键、关于信息三个区块

---

### 需求：通用设置配置

系统**必须**提供通用设置配置功能，允许用户自定义默认行为。

#### 场景：切换默认导出格式

- **当** 用户点击"默认导出格式"下拉选择器
- **那么** 显示可选格式列表（PNG / JPG / WEBP / SVG）
- **且** 选择后自动保存到 `chrome.storage.local`

#### 场景：切换截图质量

- **当** 用户点击"截图质量"下拉选择器
- **那么** 显示可选质量列表（标准 / 高清 / 超高清）
- **且** 选择后自动保存到 `chrome.storage.local`

#### 场景：切换语言

- **当** 用户点击"界面语言"下拉选择器
- **那么** 显示可选语言列表（简体中文 / English）
- **且** 选择后自动保存到 `chrome.storage.local`

### 需求：操作历史持久化设置

系统**必须**提供"保存操作历史"开关，控制是否记录用户的操作配置。

#### 场景：开启保存操作历史

- **当** 用户开启"保存操作历史"开关
- **那么** 系统记录用户在各页面的操作配置（编辑器标注设置、代码生成样式等）
- **且** 下次进入对应页面时，自动恢复上次用户设置的配置

#### 场景：关闭保存操作历史

- **当** 用户关闭"保存操作历史"开关
- **那么** 系统不再记录用户操作配置
- **且** 下次进入页面时，使用默认配置

#### 场景：切换保存操作历史

- **当** 用户切换"保存操作历史"开关状态
- **那么** 设置立即保存到 `chrome.storage.local`

---

#### 场景：设置默认延迟时间

- **且** 选择后自动保存到 `chrome.storage.local`

#### 场景：设置历史记录保留天数

- **当** 用户点击"历史保留天数"下拉选择器
- **那么** 显示可选天数列表（7天 / 30天 / 90天 / 永久保存）
- **且** 选择后自动保存到 `chrome.storage.local`

---

### 需求：水印设置配置

系统**必须**提供水印相关设置配置功能。

#### 场景：开启默认水印

- **当** 用户开启"默认添加水印"开关
- **那么** 截图时自动添加水印

#### 场景：设置默认水印文字

- **当** 用户在"水印文字"输入框输入内容
- **那么** 文字自动保存作为默认水印内容

#### 场景：设置水印透明度

- **当** 用户调整"水印透明度"滑块
- **那么** 透明度值自动保存

### 需求：代码美化设置配置

系统**必须**提供代码美化相关设置配置功能。

#### 场景：设置默认代码主题

- **当** 用户点击"代码主题"下拉选择器
- **那么** 显示可选主题列表（GitHub 暗色 / One Dark / Nord 等）
- **且** 选择后自动保存到 `chrome.storage.local`

#### 场景：设置默认字体大小

- **当** 用户调整"字体大小"滑块
- **那么** 字体大小自动保存

#### 场景：设置默认显示行号

- **当** 用户切换"显示行号"开关
- **那么** 设置自动保存

### 需求：快捷键展示

系统**必须**展示扩展快捷键配置，帮助用户了解快捷操作方式。

#### 场景：查看快捷键配置

- **当** 用户查看快捷键区块
- **那么** 显示截图快捷键（Alt+Shift+S）和代码编辑器快捷键（Alt+Shift+C）
- **且** 快捷键以视觉化按键形式展示

#### 场景：快捷键不可修改提示

- **当** 用户点击快捷键区域
- **那么** 提示用户前往 Chrome 扩展管理页面修改快捷键

---

### 需求：关于信息展示

系统**必须**展示扩展基本信息，包括版本号、作者和仓库链接。

#### 场景：查看版本和作者信息

- **当** 用户查看关于区块
- **那么** 显示扩展版本号、作者名称

#### 场景：访问仓库链接

- **当** 用户点击仓库链接
- **那么** 在新标签页打开 GitHub 仓库页面

---

### 需求：设置持久化

系统**必须**持久化保存用户设置，确保设置在浏览器重启后保留。

#### 场景：设置自动保存

- **当** 用户修改任意设置项
- **那么** 设置立即保存到 `chrome.storage.local`
- **且** 无需手动点击保存按钮

#### 场景：设置恢复

- **当** 用户重新打开设置页面
- **那么** 自动加载并显示已保存的设置值
