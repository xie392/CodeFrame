## 需求
### 需求：设置页面布局

系统**必须**提供设置页面入口，用户可通过 Chrome 扩展管理页面或扩展图标右键菜单访问设置页面。

#### 场景：用户访问设置页面

- **当** 用户打开扩展设置页面
- **那么** 显示亮色玻璃拟态风格的设置界面，包含 Header、通用设置、快捷键、关于信息三个区块

---

### 需求：通用设置配置

系统**必须**提供通用设置配置功能，允许用户自定义默认行为。

#### 场景：切换默认导出格式

- **当** 用户点击"默认导出格式"下拉选择器
- **那么** 显示可选格式列表（PNG / JPG / WEBP）
- **且** 选择后自动保存到 `chrome.storage.local`

#### 场景：使用默认导出格式导出图片（编辑器）

- **当** 用户在编辑器点击导出按钮
- **那么** 系统读取 `defaultFormat` 设置
- **且** 使用对应格式（PNG / JPG / WEBP）导出图片
- **且** 导出文件扩展名与格式匹配

#### 场景：使用默认导出格式导出图片（代码生成器）

- **当** 用户在代码生成器点击导出按钮
- **那么** 系统读取 `defaultFormat` 设置
- **且** 使用对应格式（PNG / JPG / WEBP）导出图片
- **且** 导出文件扩展名与格式匹配

#### 场景：JPG 格式背景处理

- **当** 用户选择 JPG 格式导出
- **那么** 系统自动添加白色背景（JPG 不支持透明）

#### 场景：切换截图质量

- **当** 用户点击"截图质量"下拉选择器
- **那么** 显示可选质量列表（标准 / 高清 / 超高清）
- **且** 选择后自动保存到 `chrome.storage.local`

#### 场景：截图质量等级定义

- **当** 用户选择"标准"质量
- **那么** DPR 缩放倍数必须为 1x
- **且** 输出图片尺寸与屏幕显示尺寸一致
- **当** 用户选择"高清"质量
- **那么** DPR 缩放倍数必须为 2x
- **且** 输出图片尺寸为屏幕显示尺寸的 2 倍
- **当** 用户选择"超高清"质量
- **那么** DPR 缩放倍数必须为 3x
- **且** 输出图片尺寸为屏幕显示尺寸的 3 倍

#### 场景：截图质量生效范围

- **当** 用户修改截图质量设置
- **那么** 设置必须同时影响以下场景：
  - 可视区域截图捕获
  - 区域选择截图捕获
  - 整页截图捕获
  - Editor 导出图片
  - CodeGen 导出图片

#### 场景：切换语言

- **当** 用户点击"界面语言"下拉选择器
- **那么** 显示可选语言列表（简体中文 / English）
- **且** 选择后自动保存到 `chrome.storage.local`

### 需求：操作历史持久化设置

系统**必须**提供"保存操作历史"开关，控制是否记录用户的操作配置。

#### 场景：开启保存操作历史

- **当** 用户开启"保存操作历史"开关
- **那么** 系统记录用户在各页面的操作配置（编辑器标注设置、代码生成样式等）
- **且** 下次进入对应页面时，自动恢复上次用户设置的配置

#### 场景：关闭保存操作历史

- **当** 用户关闭"保存操作历史"开关
- **那么** 系统不再记录用户操作配置
- **且** 下次进入页面时，使用默认配置

#### 场景：切换保存操作历史

- **当** 用户切换"保存操作历史"开关状态
- **那么** 设置立即保存到 `chrome.storage.local`

#### 场景：Editor 配置恢复

- **当** 用户开启"保存操作历史"并重新进入编辑器页面
- **那么** 系统自动恢复以下配置：
  - 上次使用的工具 (`activeTool`)
  - Frame 设置（背景色、边框、阴影、水印等）
  - 折叠面板展开状态 (`collapsedSections`)

#### 场景：CodeGen 配置恢复

- **当** 用户开启"保存操作历史"并重新进入代码生成器页面
- **那么** 系统自动恢复以下配置：
  - 代码主题 (`selectedTheme`)
  - 背景样式 (`selectedBg`)
  - 字体类型 (`selectedFont`)
  - 字体大小 (`fontSize`)
  - 行号显示 (`showLineNumbers`)
  - 内边距 (`padding`)
  - 圆角设置 (`borderRadius`)
  - 阴影开关 (`shadowEnabled`)
  - 阴影强度 (`shadowIntensity`)
  - 标题栏显示 (`showHeader`)
  - 文件名 (`fileName`)
  - 水印开关 (`watermarkEnabled`)
  - 水印文字 (`watermarkText`)
  - 水印透明度 (`watermarkOpacity`)

### 需求：清除操作历史

系统**必须**提供清除操作历史功能，允许用户一键清除所有已保存的操作配置。

#### 场景：清除操作历史

- **当** 用户在设置页面点击「清除历史」按钮
- **那么** 显示确认弹窗，提示用户确认操作
- **且** 用户确认后，`operationHistory` 数据被清空
- **且** 清空后 Editor 和 CodeGen 页面将使用默认配置

#### 场景：取消清除操作

- **当** 用户在确认弹窗中点击取消
- **那么** 操作历史数据保持不变
- **且** 弹窗关闭

#### 场景：清除后恢复默认配置

- **当** 用户清除操作历史后重新进入 Editor 或 CodeGen 页面
- **那么** 系统使用默认配置，而非之前保存的配置

### 需求：截图设置配置

系统**必须**提供截图相关设置配置功能。

#### 场景：设置默认延迟时间

- **当** 用户点击"延迟截图时间"下拉选择器
- **那么** 显示可选延迟时间列表（3秒 / 5秒 / 10秒）
- **且** 选择后自动保存到 `chrome.storage.local`

#### 场景：设置历史记录保留天数

- **当** 用户点击"历史保留天数"下拉选择器
- **那么** 显示可选天数列表（7天 / 30天 / 90天 / 永久保存）
- **且** 选择后自动保存到 `chrome.storage.local`

系统**必须**提供水印相关设置配置功能。

#### 场景：开启默认水印

- **当** 用户开启"默认添加水印"开关
- **那么** 截图时自动添加水印

#### 场景：设置默认水印文字

- **当** 用户在"水印文字"输入框输入内容
- **那么** 文字自动保存作为默认水印内容

#### 场景：设置水印透明度

- **当** 用户调整"水印透明度"滑块
- **那么** 透明度值自动保存

系统**必须**提供代码美化相关设置配置功能。

#### 场景：设置默认代码主题

- **当** 用户点击"代码主题"下拉选择器
- **那么** 显示可选主题列表（GitHub 暗色 / One Dark / Nord 等）
- **且** 选择后自动保存到 `chrome.storage.local`

#### 场景：设置默认字体大小

- **当** 用户调整"字体大小"滑块
- **那么** 字体大小自动保存

#### 场景：设置默认显示行号

- **当** 用户切换"显示行号"开关
- **那么** 设置自动保存

### 需求：快捷键展示

系统**必须**展示扩展快捷键配置，帮助用户了解快捷操作方式。

#### 场景：查看快捷键配置

- **当** 用户查看快捷键区块
- **那么** 显示截图快捷键（Alt+Shift+S）和代码编辑器快捷键（Alt+Shift+C）
- **且** 快捷键以视觉化按键形式展示

#### 场景：快捷键不可修改提示

- **当** 用户点击快捷键区域
- **那么** 提示用户前往 Chrome 扩展管理页面修改快捷键

---

### 需求：关于信息展示

系统**必须**展示扩展基本信息，包括版本号、作者和仓库链接。

#### 场景：查看版本和作者信息

- **当** 用户查看关于区块
- **那么** 显示扩展版本号、作者名称

#### 场景：访问仓库链接

- **当** 用户点击仓库链接
- **那么** 在新标签页打开 GitHub 仓库页面

---

### 需求：设置持久化

系统**必须**持久化保存用户设置，确保设置在浏览器重启后保留。

#### 场景：设置自动保存

- **当** 用户修改任意设置项
- **那么** 设置立即保存到 `chrome.storage.local`
- **且** 无需手动点击保存按钮

#### 场景：设置恢复

- **当** 用户重新打开设置页面
- **那么** 自动加载并显示已保存的设置值
