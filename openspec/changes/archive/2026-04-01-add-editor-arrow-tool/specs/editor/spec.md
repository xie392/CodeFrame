## 新增需求

### 需求：Editor 箭头工具绘制

Editor 画布必须支持箭头标注绘制功能，用户选择箭头工具后可以通过拖拽创建箭头形状。

#### 场景：激活箭头工具

- **当** 用户点击左侧工具栏中的箭头工具按钮
- **那么** 箭头工具必须显示为激活状态
- **且** 画布光标必须变为十字准星样式
- **且** 其他工具必须处于非激活状态

#### 场景：绘制箭头

- **当** 箭头工具处于激活状态且用户按下鼠标左键
- **那么** 必须记录箭头起点位置
- **当** 用户拖动鼠标
- **那么** 必须实时显示从起点到当前鼠标位置的临时箭头预览
- **当** 用户释放鼠标
- **那么** 必须创建箭头并添加到标注列表

#### 场景：箭头绘制与画布缩放协同

- **当** 用户在画布缩放状态下绘制箭头
- **那么** 箭头坐标必须正确转换为图片坐标系
- **且** 箭头必须随画布缩放和平移正确显示

### 需求：Editor 箭头颜色选择

Editor 必须提供箭头颜色选择功能，支持预设颜色和自定义颜色。

#### 场景：预设颜色选择

- **当** 用户查看右侧属性面板的样式区域
- **那么** 必须显示 6-8 种预设颜色按钮
- **且** 预设颜色必须包含红、橙、黄、绿、蓝、紫、白、黑

#### 场景：自定义颜色选择

- **当** 用户点击颜色选择器
- **那么** 必须弹出系统颜色选择器
- **且** 用户选择的颜色必须应用到当前箭头（已选中）或作为新建箭头的默认颜色

#### 场景：颜色实时预览

- **当** 用户选中一个箭头后更改颜色
- **那么** 箭头颜色必须立即更新
- **且** 属性面板中的颜色显示必须同步更新

### 需求：Editor 箭头大小控制

Editor 必须提供箭头大小控制功能，包括线条粗细和箭头头部大小两个维度。

#### 场景：线条粗细控制

- **当** 用户查看右侧属性面板的样式区域
- **那么** 必须显示线条粗细控制控件（滑块或输入框）
- **且** 线条粗细范围必须为 1px 到 10px
- **且** 默认线条粗细必须为 2px

#### 场景：箭头头部大小控制

- **当** 用户查看右侧属性面板的样式区域
- **那么** 必须显示箭头头部大小控制控件
- **且** 头部大小范围必须为 5px 到 30px
- **且** 默认头部大小必须为 12px

#### 场景：大小变更实时更新

- **当** 用户修改选中箭头的线条粗细或头部大小
- **那么** 箭头外观必须立即更新
- **且** 属性面板中的数值显示必须同步更新

### 需求：Editor 箭头样式切换

Editor 必须支持单箭头和双箭头两种样式。

#### 场景：单箭头样式

- **当** 用户选择单箭头样式
- **那么** 箭头头部必须仅显示在箭头终点位置

#### 场景：双箭头样式

- **当** 用户选择双箭头样式
- **那么** 箭头头部必须同时显示在起点和终点位置

#### 场景：样式切换控件

- **当** 用户查看右侧属性面板的样式区域
- **那么** 必须显示箭头样式切换按钮组（单箭头/双箭头）
- **且** 默认样式必须为单箭头

### 需求：Editor 箭头选择与编辑

Editor 必须支持选中已绘制的箭头并通过属性面板修改其属性。

#### 场景：选中箭头

- **当** 用户使用选择工具点击画布上的箭头
- **那么** 该箭头必须显示为选中状态（高亮边框或控制点）
- **且** 右侧属性面板必须显示该箭头的当前属性

#### 场景：修改选中箭头属性

- **当** 用户选中一个箭头后修改属性面板中的任意属性
- **那么** 该箭头必须立即更新为新属性值

#### 场景：取消选择

- **当** 用户点击画布空白区域
- **那么** 当前选中的箭头必须取消选中状态
- **且** 属性面板必须恢复显示默认绘制属性
