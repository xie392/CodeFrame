# Proposal: 重绘绘制工具系统

## 状态：draft

## 问题

Editor 编辑页面左侧绘制功能存在系统性问题：拖动、选中、箭头、矩形、文字、马赛克、裁剪等工具的交互逻辑混乱，体验不一致。需要从零重新设计功能需求。

## 方案

重新设计绘制工具系统，核心思路：

1. **统一交互优先级**：任何工具下点击已有图形自动选中，无需切回选择工具
2. **裁剪独立为模态操作**：不是工具栏切换，而是进入裁剪模式
3. **马赛克作为独立图形叠加层**：导出时合并像素，可撤销
4. **统一图层管理**：所有图形支持 zIndex 排序
5. **统一缩放模型**：自由缩放；箭头缩放=移动端点；文字缩放=改变字号

## 范围

### 包含

- 选择工具（点选、框选、拖动）
- 箭头工具（拖拽绘制、端点调整、属性编辑）
- 矩形工具（拖拽绘制、8控制点缩放、属性编辑）
- 文字工具（点击创建、双击编辑、缩放=改变字号）
- 马赛克工具（拖拽绘制、叠加层渲染、属性编辑）
- 裁剪模式（独立模态、框选、确认/取消）
- 右侧属性面板（按类型切换、图层操作、删除）
- 键盘快捷键
- 撤销/重做

### 不包含

- 新增图形类型（椭圆、线条等）
- 协同编辑
- 图形分组
- 图形旋转

## 关键设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 工具选中逻辑 | 任何工具下点击图形自动选中 | 更流畅，减少工具切换 |
| 裁剪定位 | 独立模态操作 | 裁剪是破坏性操作，语义上不是"绘制工具" |
| 马赛克渲染 | 独立图形叠加层 | 可撤销、可调整、导出时合并 |
| 图层管理 | 支持 zIndex 排序 | 多图形重叠时需要控制遮挡关系 |
| 缩放约束 | 自由缩放 | 灵活性优先；箭头/文字有各自映射 |
| 多选属性面板 | 仅显示通用操作(图层+删除) | 简单实用，避免复杂的跨类型属性编辑 |

## 风险

- 裁剪确认后坐标调整逻辑复杂（图形可能部分在框外）
- 马赛克叠加层在缩放/平移时需要实时重算像素模糊，性能需关注
- 统一图层模型与现有 store 结构差异较大，迁移需谨慎
