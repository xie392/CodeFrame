## 上下文

Editor 模块需要实现箭头标注功能，这是图片编辑器核心标注能力之一。当前已有基础 Canvas
架构（缩放、平移），但缺少标注绘制层。箭头功能需要与现有画布变换（缩放/平移）协同工作。

**约束**：
- 使用原生 Canvas API 绘制（项目计划使用 Konva.js，但当前未引入）
- 所有状态管理使用 React useState（或后续迁移到 Zustand）
- 样式需符合 Terminal Minimal Dashboard 设计系统

## 目标 / 非目标

**目标**：
- 实现完整的箭头绘制和编辑功能
- 提供颜色和大小自定义能力
- 支持单箭头和双箭头样式

**非目标**：
- 本变更不实现撤销/重做功能
- 本变更不实现其他标注工具（矩形、文字、马赛克）
- 本变更不引入 Konva.js（保持简单实现）

## 决策

### 箭头数据结构

```typescript
interface ArrowShape {
  id: string;
  startX: number;
  startY: number;
  endX: number;
  endY: number;
  color: string;        // 十六进制颜色
  strokeWidth: number;  // 线条粗细 (1-10px)
  headSize: number;     // 箭头头部大小 (5-30px)
  style: 'single' | 'double'; // 单箭头/双箭头
}
```

**理由**：简洁且完整的数据结构，易于存储和渲染。

### 颜色选择方案

采用「预设颜色 + 自定义颜色选择器」组合方案：
- 预设颜色：6-8 种常用标注颜色（红、橙、黄、绿、蓝、紫、白、黑）
- 自定义：使用原生 `<input type="color">` 颜色选择器

**理由**：预设颜色满足大部分场景，自定义选择器提供灵活性。

### 箭头头部绘制算法

使用经典箭头绘制算法：
1. 计算箭头方向向量
2. 计算 30° 角的两个分支线
3. 根据头大小参数缩放分支线长度

### Canvas 层级设计

```
┌─────────────────────────────────┐
│     Transform Layer             │ ← 缩放/平移变换
│  ┌───────────────────────────┐  │
│  │   Image Layer             │  │ ← 底图
│  └───────────────────────────┘  │
│  ┌───────────────────────────┐  │
│  │   Annotation Layer        │  │ ← 箭头等标注
│  │   (Canvas Element)        │  │
│  └───────────────────────────┘  │
└─────────────────────────────────┘
```

**理由**：标注层与底图分离，便于独立管理和更新。

## 风险 / 权衡

| 风险 | 缓解措施 |
|------|----------|
| Canvas 重绘性能 | 使用脏矩形优化，仅在标注变化时重绘 |
| 缩放后点击检测 | 坐标转换时考虑当前缩放比例和偏移 |
| 颜色选择器样式 | 原生选择器样式有限，接受功能性优先 |
