## MODIFIED Requirements

### Requirement: 截图操作按钮

内容区域 MUST 包含 3 个主要操作按钮和 1 个功能列表。第一行 MUST 为 3 个操作按钮网格，下方 MUST 为功能列表。

#### Scenario: 操作按钮布局

- **当** 用户查看 Screenshot Tab 内容区域
- **那么** 第一行 MUST 显示 3 个操作按钮（可视截图、选择区域、整页截图）
- **且** 按钮尺寸 MUST 为 96x80px
- **且** 按钮之间间距 MUST 为 12px

#### Scenario: 操作按钮样式

- **当** 用户查看任意操作按钮
- **那么** 按钮 MUST 使用液态玻璃卡片样式
- **且** MUST 包含图标和文字标签
- **且** 悬停时 MUST 有 scale(1.02) 和背景亮度过渡

#### Scenario: 功能列表

- **当** 用户查看操作按钮下方
- **那么** MUST 显示功能列表
- **且** 列表 MUST 包含 4 项：延时截取可视区域、全屏截图、编辑本地或粘贴图片、代码编辑器
- **且** 每项 MUST 使用玻璃卡片行样式
- **且** 每项 MUST 包含图标、文字和快捷键提示（如有）

#### Scenario: 功能列表交互

- **当** 用户点击功能列表项
- **那么** MUST 触发对应功能
- **且** 悬停时 MUST 有背景亮度过渡
