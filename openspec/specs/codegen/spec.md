## 需求
### 需求：CodeGen 页面整体布局

CodeGen 页面必须按照 ui.pen 设计稿还原，尺寸为 1440×900 全屏，采用 Liquid Glass 暗色主题渐变背景，包含 LeftPanel 和 PreviewArea 两个主要区域。

#### 场景：页面初始化

- **当** 用户打开 CodeGen 页面
- **那么** 页面必须为全屏布局（100vw × 100vh）
- **且** 背景必须为线性渐变（180° 旋转），从 #1E1E30 到 #151525（50% 位置）再到 #0D0D18
- **且** 页面必须包含左侧 LeftPanel 和右侧 PreviewArea 两个区域

### 需求：LeftPanel 面板

LeftPanel 必须为宽 360px 的毛玻璃效果面板，包含代码输入区域、主题选择、背景色选择和导出按钮。

#### 场景：面板外观

- **当** 用户查看 LeftPanel
- **那么** 面板宽度必须为 360px，高度为 fill_container
- **且** 面板必须具有毛玻璃效果（background-blur: 20px）
- **且** 面板背景必须为半透明渐变（#FFFFFF18 到 #FFFFFF0C）
- **且** 面板必须有 1px #FFFFFF12 边框
- **且** 面板内边距必须为 20px，元素间距为 16px

#### 场景：面板标题

- **当** 用户查看 LeftPanel 顶部
- **那么** 必须显示 `>` 提示符（颜色 #00D4AA，字号 16px，font-weight 700）和 `code_input` 标题（颜色 #FFFFFF，字号 14px）

### 需求：代码输入区域

CodeWindow 编辑模式必须使用 `@uiw/react-codemirror`（CodeMirror 6）提供代码编辑体验，编辑器必须具有语法高亮、行号、括号匹配和自动缩进功能。

#### 场景：编辑器主题同步

- **当** 用户在编辑模式下且选中了某个主题
- **那么** 编辑器必须使用对应的 CodeMirror 原生主题：
  - VS Code Dark+ → `@uiw/codemirror-theme-vscode` 的 `vscodeDark`
  - One Dark → `@uiw/codemirror-theme-one-dark` 的 `oneDark`
  - Dracula → `@uiw/codemirror-theme-dracula` 的 `draculaInit` 或对应导出
  - Nord → `@uiw/codemirror-theme-nord` 的对应导出
  - 其他主题 → 对应的 `@uiw/codemirror-theme-*` 包导出
- **且** 切换主题时编辑器必须立即更新
- **且** gutter 背景色必须与编辑器内容区背景色保持一致，不得出现色差

### 需求：主题选择区域

ThemeSection 必须提供代码展示区域主题选择功能，用户通过下拉选择器选择主题后，右侧代码窗口的编辑器主题（ gutter、光标、选中态、滚动条等 UI 元素）和代码窗口容器样式（背景色、标题栏背景色）必须实时统一更新。

#### 场景：主题选择器显示

- **当** 用户查看主题选择区域
- **那么** 必须显示 `theme` 标签文字（颜色 #3D3D3D，字号 11px）
- **且** 必须显示一个 Select 下拉选择器
- **且** 下拉选择器必须显示当前选中主题的名称
- **且** 下拉选项列表中每个选项必须包含主题名称
- **且** 下拉选择器宽度必须为 fill_container

#### 场景：主题切换生效

- **当** 用户通过下拉选择器选择某个主题
- **那么** 下拉选择器必须显示新选中主题的名称
- **且** 编辑器必须使用对应的 CodeMirror 原生主题（而非共用 vscodeDark/vscodeLight）
- **且** 代码窗口背景色必须从主题配置中读取（如 VS Code Dark+ 为 #1E1E1E、Light 为 #FFFFFF）
- **且** 代码窗口标题栏背景色必须从主题配置中读取（如 VS Code Dark+ 为 #252526、Light 为 #F0F0F0）
- **且** 编辑器 gutter（行号区域）背景色必须与编辑器背景色一致
- **且** 编辑器 gutter 前景色必须与主题配色方案一致
- **且** 编辑器光标、选中态、滚动条等 UI 元素必须使用主题对应的原生样式

### 需求：背景色选择区域

BgSection 必须提供代码窗口背景色选择功能。

#### 场景：背景色块显示

- **当** 用户查看背景色选择区域
- **那么** 必须显示 `background` 标签文字（颜色 #3D3D3D，字号 11px）
- **且** 必须显示 5 个背景色块（40×40px，圆角 8px）
- **且** 5 个色块颜色必须分别为：#6366F1（Indigo）、#8B5CF6（Violet）、#EC4899（Pink）、#0EA5E9（Sky）、#10B981（Emerald）
- **且** 当前选中项必须显示 check 图标（颜色 #FFFFFF，尺寸 16×16px）

### 需求：导出按钮

ExportBtn 区域必须提供两个操作入口：导出图片（主按钮）和复制到剪贴板（辅助按钮），两个按钮水平排列在 LeftPanel 底部。

#### 场景：导出按钮外观

- **当** 用户查看导出按钮区域
- **那么** 必须显示一个主按钮和一个辅助按钮，水平排列
- **且** 主按钮宽度必须自适应填充剩余空间，高度 44px，背景色 #00D4AA，圆角 12px
- **且** 主按钮文字必须为 `$ export_image`（颜色 #0D0D0D，字号 13px，font-weight 600）
- **且** 主按钮左侧必须显示 Image 图标（颜色 #0D0D0D，尺寸 16x16px）
- **且** 辅助按钮（复制按钮）宽度必须为 44px，高度 44px，背景色 #FFFFFF14，圆角 12px
- **且** 辅助按钮必须显示 ClipboardCopy 图标（颜色 #00D4AA，尺寸 16x16px）

#### 场景：导出按钮 loading 状态

- **当** 用户点击导出按钮且图片正在生成
- **那么** 主按钮必须变为禁用状态
- **且** 主按钮文字必须变为 `exporting...` 表示处理中

### 需求：代码预览区域

PreviewArea 必须在右侧展示 Shiki 语法高亮的代码窗口预览效果，代码窗口的整体视觉风格必须与左侧选中的主题同步。背景填充区域必须支持四方向独立边距值。代码窗口高度必须自适应代码内容行数。背景填充区域和代码窗口必须支持独立圆角设置。title_bar 切换时代码窗口高度必须立即同步更新。

#### 场景：预览区域背景

- **当** 用户查看预览区域
- **那么** 预览区域必须占据剩余空间（fill_container）
- **且** 背景色必须随用户选择的背景色变化
- **且** 内容必须垂直水平居中

#### 场景：代码窗口外观

- **当** 预览区域渲染
- **那么** 必须显示 CodeWindow（初始宽度 520px，内框圆角默认 12px）
- **且** CodeWindow 高度必须自适应代码内容行数，计算方式为 `headerHeight(40) + paddingTop(20) + paddingBottom(20) + codeLines × lineHeight(20)`
- **且** CodeWindow 最小高度必须为 `headerHeight(40) + paddingTop(20) + paddingBottom(20) + 1 × lineHeight(20)` = 100px（至少显示 1 行代码）
- **且** CodeWindow 最大高度不得超过 800px
- **且** CodeWindow 背景色必须随选中主题变化（深色主题为深色背景，浅色主题为浅色背景）
- **且** CodeWindow 必须有外阴影（颜色 #00000026，偏移 y=8，模糊 40px）
- **且** CodeWindow 顶部必须显示 WindowHeader（高度 40px，内框圆角顶部）
- **且** WindowHeader 背景色必须随选中主题变化
- **且** WindowHeader 必须包含红 (#FF5F56)、黄 (#FFBD2E)、绿 (#27C93F) 三个圆点（12×12px，圆形）
- **且** 圆点右侧必须显示文件名 `greet.js`（颜色 #777777，字号 12px）
- **且** CodeWindow 下方必须显示 WindowBody，包含 Shiki 语法高亮渲染的代码（内边距 20px，JetBrains Mono 字体）

#### 场景：title_bar 切换时高度同步

- **当** 用户切换 title_bar 显示/隐藏状态
- **那么** 代码窗口高度必须立即重新计算并更新，无需用户再次点击编辑器
- **且** 切换 title_bar 后代码内容不得被截断

#### 场景：非对称背景填充渲染

- **当** 用户设置了不同的上下左右边距值
- **那么** 代码窗口外围的背景填充区域必须使用对应的独立方向值渲染
- **且** 左侧填充宽度必须等于 `paddingLeft`
- **且** 右侧填充宽度必须等于 `paddingRight`
- **且** 上方填充高度必须等于 `paddingTop`
- **且** 下方填充高度必须等于 `paddingBottom`
- **且** 四方向边距均为 0 时，背景填充区域不得渲染
- **且** 背景填充区域的圆角必须使用外框圆角值（`outerBorderRadius`）

#### 场景：预览内容同步

- **当** 用户在代码窗口中编辑代码或切换主题
- **那么** WindowBody 必须实时显示 Shiki 语法高亮后的代码内容
- **且** 高亮渲染必须使用 `shiki/engine/javascript` 引擎（避免 WASM CSP 问题）
- **且** 高亮结果必须缓存，仅在代码内容或选中主题变更时重新渲染

### 需求：四方向独立边距设置
系统必须允许用户对代码预览区域的背景填充边距进行上、右、下、左四个方向的独立设置。

#### 场景：通过 Popover 设置独立边距
- **当** 用户点击 LeftPanel 中 padding 区域的"更多设置"按钮
- **那么** 必须在按钮上方弹出 Popover 浮层
- **且** Popover 内必须显示上、右、下、左四个方向的独立数值输入框
- **且** 每个方向输入框必须显示当前对应的边距数值（单位 px）
- **且** 用户修改任一方向的数值后，预览区域的背景填充必须实时更新为非对称布局

#### 场景：统一滑块与自定义模式切换
- **当** 用户拖动原有统一 padding 滑块
- **那么** 四个方向的边距必须同步更新为滑块当前值
- **且** 模式必须标记为"统一"
- **当** 用户在 Popover 中修改任一方向的数值
- **那么** 模式必须标记为"自定义"
- **且** 统一滑块的显示值可以隐藏或显示为"自定义"状态

### 需求：内外框独立圆角设置

系统必须允许用户分别设置代码窗口的外框（背景填充区域）和内框（代码窗口本身）的圆角，并提供统一/自定义两种模式切换。

#### 圆角控制区域标题显示

- **当** 用户查看 LeftPanel 中的圆角控制区域
- **那么** 必须显示 `border_radius` 标签文字（颜色 #3D3D3D，字号 11px），与 padding 等其他控制区域标签样式一致

#### 统一圆角模式

- **当** 用户处于统一圆角模式
- **那么** 必须显示单个滑块控制
- **且** 拖动滑块时，外框和内框圆角必须同步更新为相同值
- **且** 滑块值范围必须为 0px 到 30px

#### 自定义圆角模式

- **当** 用户点击圆角区域的"更多设置"按钮（类似 padding 的 Popover 触发按钮）
- **那么** 必须在按钮上方弹出 Popover 浮层
- **且** Popover 内必须显示两个独立滑块：外框（outer）和内框（inner）
- **且** 每个滑块必须显示当前对应的圆角数值（单位 px）
- **且** 每个滑块的值范围必须为 0px 到 30px
- **且** 用户修改任一滑块后，模式必须标记为"自定义"
- **且** 统一滑块的显示值必须切换为 `···` 状态

#### 外框圆角渲染

- **当** 用户设置了外框圆角值
- **那么** 背景填充区域（代码窗口外围的彩色区域）的圆角必须使用外框圆角值
- **且** 代码窗口本身的圆角不受外框圆角值影响

#### 内框圆角渲染

- **当** 用户设置了内框圆角值
- **那么** 代码窗口整体、标题栏顶部、窗口主体底部的圆角必须使用内框圆角值
- **且** 背景填充区域的圆角不受内框圆角值影响

#### 默认圆角值

- **当** 页面初始化或用户重置设置
- **那么** 外框圆角默认值必须为 16px
- **且** 内框圆角默认值必须为 12px
- **且** 模式必须为"自定义"（因为默认值不同）

### 需求：水印功能

CodeGen 必须支持在代码窗口右下角显示水印文字，水印使用纯 DOM 文本渲染，水平排列，编辑模式和预览模式下均可见。

#### 场景：开启水印

- **当** 用户开启水印开关
- **那么** 代码窗口右下角必须显示水印文字
- **且** 水印默认文字为 "CodeFrame"
- **且** 水印必须支持自定义文字输入
- **且** 水印必须水平排列（不旋转）

#### 场景：编辑模式下水印可见

- **当** 用户处于代码编辑模式且水印已开启
- **那么** 水印文字必须仍然可见

#### 场景：调节水印透明度

- **当** 用户拖动水印透明度滑块
- **那么** 水印透明度必须在 10% 到 90% 范围内变化

#### 场景：导出含水印图片

- **当** 用户导出图片且水印已开启
- **那么** 导出的图片必须包含水印

#### 场景：默认水印

- **当** 用户首次打开 CodeGen 页面
- **那么** 默认水印必须为关闭状态

#### 场景：水印字体跟随主题

- **当** 水印已开启且用户切换了代码字体
- **那么** 水印文字的字体必须与当前选中的代码字体一致

#### 场景：水印颜色适配主题

- **当** 水印已开启且当前为暗色主题
- **那么** 水印颜色必须为半透明白色，确保在深色背景上清晰可见
- **当** 水印已开启且当前为亮色主题
- **那么** 水印颜色必须为半透明黑色，确保在浅色背景上清晰可见

### 需求：导出图片功能

系统必须允许用户将代码预览区域（包含背景填充、代码窗口和水印）导出为 PNG 图片并下载到本地，并根据用户设置的截图质量进行缩放处理。

#### 场景：导出 PNG 图片

- **当** 用户点击导出图片主按钮
- **那么** 系统必须使用 `@zumer/snapdom` 库将背景填充区域容器渲染为 PNG 图片
- **且** 导出图片必须使用用户设置的像素比（scale: 1/2/3），由截图质量设置决定
- **且** 导出图片必须包含完整的背景色/渐变、代码窗口（含语法高亮）、水印（如已开启）
- **且** 导出图片文件名格式必须为 `codeframe-{timestamp}.png`
- **且** 浏览器必须自动触发文件下载

#### 场景：导出时隐藏编辑器光标

- **当** 用户点击导出且当前处于编辑模式
- **那么** 导出图片中不得包含编辑器光标

#### 场景：导出含水印图片

- **当** 用户导出图片且水印已开启
- **那么** 导出的图片必须包含水印文字

#### 场景：导出应用截图质量设置

- **当** 用户点击导出图片按钮
- **那么** 系统必须读取用户的截图质量设置（1x/2x/3x）
- **且** 若质量设置为 1x，导出 scale 必须为 1
- **且** 若质量设置为 2x，导出 scale 必须为 2
- **且** 若质量设置为 3x，导出 scale 必须为 3
- **且** 导出图片尺寸必须为屏幕显示尺寸 × scale

---

### 需求：复制到剪贴板功能

系统必须允许用户将代码预览区域截图直接复制到系统剪贴板，方便在其他应用中粘贴使用，并根据用户设置的截图质量进行缩放处理。

#### 场景：复制截图到剪贴板

- **当** 用户点击复制按钮
- **那么** 系统必须将代码预览区域渲染为 PNG 图片
- **且** 必须通过 `navigator.clipboard.write` 将 PNG 图片写入系统剪贴板
- **且** 用户可在任意支持粘贴图片的应用中粘贴该截图

#### 场景：复制成功反馈

- **当** 截图成功复制到剪贴板
- **那么** 复制按钮必须显示视觉反馈（如图标切换为对勾）
- **且** 反馈必须在 2 秒后自动恢复为原始状态

#### 场景：复制按钮 Tooltip

- **当** 用户鼠标悬停在复制按钮上
- **那么** 必须显示 Tooltip 提示文字 `复制到剪贴板`

#### 场景：剪贴板 API 不支持

- **当** 浏览器不支持 `navigator.clipboard.write` API
- **那么** 复制按钮必须显示错误提示信息

#### 场景：复制应用截图质量设置

- **当** 用户点击复制到剪贴板按钮
- **那么** 系统必须读取用户的截图质量设置（1x/2x/3x）
- **且** 若质量设置为 1x，生成图片 scale 必须为 1
- **且** 若质量设置为 2x，生成图片 scale 必须为 2
- **且** 若质量设置为 3x，生成图片 scale 必须为 3
