## 新增需求

### 需求:工具属性记忆
用户上次设置的工具属性（颜色、线宽、字号、马赛克块大小等）必须在下次使用同一工具时自动恢复。当"保存操作历史"设置开启时，属性必须持久化到 localStorage。

#### 场景:修改箭头颜色后再次使用
- **当** 用户将箭头颜色改为蓝色并绘制，然后切换到其他工具再切回箭头工具
- **那么** 新绘制的箭头默认使用蓝色

#### 场景:修改矩形线宽后再次使用
- **当** 用户将矩形线宽改为6px并绘制，然后切换到其他工具再切回矩形工具
- **那么** 新绘制的矩形默认使用6px线宽

#### 场景:属性持久化
- **当** 用户修改了工具属性且"保存操作历史"开启，然后关闭并重新打开编辑器
- **那么** 工具属性恢复为上次设置的值
