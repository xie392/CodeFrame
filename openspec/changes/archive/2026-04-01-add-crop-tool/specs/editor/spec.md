## 新增需求

### 需求：Editor 裁剪工具入口

Editor 左侧工具栏必须提供裁剪工具，允许用户进入裁剪模式对图片进行裁剪。

#### 场景：裁剪工具入口

- **当** 用户查看左侧工具栏
- **那么** 必须包含裁剪工具（Crop 图标），位于马赛克工具之后

#### 场景：裁剪工具选中状态

- **当** 用户点击裁剪工具
- **那么** 裁剪工具必须显示为激活状态
- **且** 画布必须显示覆盖全图的默认裁剪框
- **且** 其他工具必须处于非激活状态
- **且** 画布光标必须变为 crosshair 样式

#### 场景：裁剪框初始状态

- **当** 用户激活裁剪工具
- **那么** 裁剪框必须默认覆盖整个图片区域
- **且** 裁剪框必须显示为虚线边框
- **且** 裁剪框外的区域必须显示半透明暗色遮罩

### 需求：Editor 裁剪框交互

Editor 必须支持通过拖拽调整裁剪框的位置和大小。

#### 场景：拖拽创建新裁剪框

- **当** 裁剪工具激活且用户在裁剪框外按下鼠标左键拖拽
- **那么** 必须从按下位置开始创建新的裁剪框
- **且** 裁剪框必须跟随鼠标移动实时更新尺寸

#### 场景：拖拽移动裁剪框

- **当** 用户在裁剪框内部区域按下鼠标左键拖拽
- **那么** 裁剪框必须跟随鼠标移动
- **且** 裁剪框尺寸必须保持不变
- **且** 裁剪框不得超出图片边界

#### 场景：拖拽角控制点调整大小

- **当** 用户拖拽裁剪框四个角的控制点
- **那么** 必须同时改变裁剪框的宽度和高度
- **且** 对角位置必须保持不变
- **且** 裁剪框不得超出图片边界

#### 场景：拖拽边中点控制点调整大小

- **当** 用户拖拽裁剪框四条边中点的控制点
- **那么** 必须改变裁剪框在该方向的尺寸
- **且** 对边位置必须保持不变
- **且** 裁剪框不得超出图片边界

#### 场景：调整大小时光标变化

- **当** 用户将鼠标悬停在裁剪框控制点上
- **那么** 光标必须变为对应的调整大小样式（nwse-resize、nesw-resize、ns-resize、ew-resize）
- **当** 用户将鼠标悬停在裁剪框内部
- **那么** 光标必须变为 move 样式

#### 场景：最小裁剪尺寸限制

- **当** 用户调整裁剪框大小
- **那么** 裁剪框宽度和高度不得小于 10px

### 需求：Editor 裁剪确认与取消

Editor 必须提供明确的裁剪确认与取消机制。

#### 场景：键盘确认裁剪

- **当** 用户按下 Enter 键
- **那么** 必须执行裁剪操作
- **且** 图片必须更新为裁剪框内的区域
- **且** 所有标注必须被清除
- **且** 工具必须自动切换到选择工具
- **且** 视图必须重置为默认状态（缩放 1x，居中显示）

#### 场景：双击确认裁剪

- **当** 用户双击裁剪框内部区域
- **那么** 必须执行裁剪操作
- **且** 图片必须更新为裁剪框内的区域
- **且** 所有标注必须被清除
- **且** 工具必须自动切换到选择工具
- **且** 视图必须重置为默认状态

#### 场景：键盘取消裁剪

- **当** 用户按下 Escape 键
- **那么** 必须取消裁剪操作
- **且** 裁剪框必须消失
- **且** 工具必须自动切换到选择工具
- **且** 图片和标注必须保持不变

#### 场景：切换工具取消裁剪

- **当** 用户点击其他工具按钮
- **那么** 必须取消裁剪操作
- **且** 裁剪框必须消失
- **且** 图片和标注必须保持不变

### 需求：Editor 裁剪后状态处理

Editor 必须正确处理裁剪完成后的状态更新。

#### 场景：更新图片数据

- **当** 裁剪操作执行
- **那么** 必须使用 Canvas API 从原图截取指定区域
- **且** 必须更新图片数据源（imageData）
- **且** 新图片尺寸必须等于裁剪框尺寸

#### 场景：清除标注数据

- **当** 裁剪操作执行
- **那么** 所有箭头标注必须被清除
- **且** 所有矩形标注必须被清除
- **且** 所有文字标注必须被清除
- **且** 所有马赛克标注必须被清除

#### 场景：重置视图状态

- **当** 裁剪操作执行
- **那么** 缩放比例必须重置为 1x
- **且** 平移偏移必须重置为零
- **且** 新图片必须在画布中央显示
