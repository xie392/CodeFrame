## 新增需求

### 需求：水印功能

CodeGen 必须支持在代码窗口右下角显示水印文字，水印使用纯 DOM 文本渲染，水平排列，编辑模式和预览模式下均可见。

#### 场景：开启水印

- **当** 用户开启水印开关
- **那么** 代码窗口右下角必须显示水印文字
- **且** 水印默认文字为 "CodeFrame"
- **且** 水印必须支持自定义文字输入
- **且** 水印必须水平排列（不旋转）

#### 场景：编辑模式下水印可见

- **当** 用户处于代码编辑模式且水印已开启
- **那么** 水印文字必须仍然可见

#### 场景：调节水印透明度

- **当** 用户拖动水印透明度滑块
- **那么** 水印透明度必须在 10% 到 90% 范围内变化

#### 场景：导出含水印图片

- **当** 用户导出图片且水印已开启
- **那么** 导出的图片必须包含水印

#### 场景：默认水印

- **当** 用户首次打开 CodeGen 页面
- **那么** 默认水印必须为关闭状态

#### 场景：水印字体跟随主题

- **当** 水印已开启且用户切换了代码字体
- **那么** 水印文字的字体必须与当前选中的代码字体一致

#### 场景：水印颜色适配主题

- **当** 水印已开启且当前为暗色主题
- **那么** 水印颜色必须为半透明白色，确保在深色背景上清晰可见
- **当** 水印已开启且当前为亮色主题
- **那么** 水印颜色必须为半透明黑色，确保在浅色背景上清晰可见
