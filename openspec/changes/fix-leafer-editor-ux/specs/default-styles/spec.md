## 修改需求

### 需求:默认绘制样式
各工具的默认样式值必须如下：
- 矩形：颜色红色(#EF4444)、线宽4px、填充透明度0、边框样式实线
- 箭头：颜色红色(#EF4444)、线宽4px、箭头大小12px、样式单箭头
- 文字：颜色红色(#EF4444)、字号30px、字重normal、字体样式normal
- 马赛克：块大小30px、透明度100%

#### 场景:首次使用矩形工具
- **当** 用户首次选择矩形工具并绘制
- **那么** 矩形使用红色描边、4px线宽

#### 场景:首次使用箭头工具
- **当** 用户首次选择箭头工具并绘制
- **那么** 箭头使用红色描边、4px线宽

#### 场景:首次使用文字工具
- **当** 用户首次选择文字工具并点击创建
- **那么** 文字使用红色、30px字号

#### 场景:首次使用马赛克工具
- **当** 用户首次选择马赛克工具并绘制
- **那么** 马赛克使用30px块大小、100%透明度
