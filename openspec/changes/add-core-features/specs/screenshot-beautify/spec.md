# 截图美化功能规范

## 新增需求

### 需求：捕获当前标签页

系统必须提供捕获当前浏览器标签页的功能。

#### 场景：捕获可见区域

- **当** 用户点击"捕获当前页面"按钮
- **Then** 系统应捕获当前标签页的可见区域
- **And** 捕获的图片应显示在预览区域

#### 场景：捕获失败提示

- **当** 标签页包含受限内容（如 chrome:// 页面）
- **Then** 系统应显示错误提示
- **And** 提示用户该页面无法捕获

---

### 需求：上传本地图片

系统必须支持上传本地图片进行美化。

#### 场景：上传图片

- **当** 用户点击"上传图片"按钮并选择图片文件
- **Then** 系统应加载该图片
- **And** 图片应显示在预览区域

#### 场景：支持的图片格式

- **当** 用户上传 PNG、JPG 或 WebP 格式图片
- **Then** 系统应正确加载该图片

#### 场景：拖拽上传

- **当** 用户拖拽图片到扩展窗口
- **Then** 系统应加载该图片

---

### 需求：设备边框

系统必须提供设备边框添加功能。

#### 场景：选择 MacBook Pro 边框（免费）

- **当** 用户选择 "MacBook Pro" 设备边框
- **Then** 截图应显示在 MacBook Pro 边框内

#### 场景：选择 Browser 边框（免费）

- **当** 用户选择 "Browser Window" 边框
- **Then** 截图应显示在浏览器窗口边框内
- **And** 地址栏应可编辑

#### 场景：选择无边框

- **当** 用户选择 "无边框"
- **Then** 截图不添加任何设备边框

#### 场景：选择 iPhone 边框（Pro）

- **当** Pro 用户选择 "iPhone 15" 或 "iPhone 15 Pro" 边框
- **Then** 截图应显示在 iPhone 边框内

#### 场景：免费用户选择 Pro 边框

- **当** 免费用户点击 iPhone、iPad 或 iMac 边框
- **Then** 系统应弹出升级提示

---

### 需求：背景选择

系统必须提供背景选择功能。

#### 场景：选择纯色背景

- **当** 用户选择白色、浅灰或深灰背景
- **Then** 预览应使用该纯色背景

#### 场景：选择渐变背景（Pro）

- **当** Pro 用户选择渐变背景
- **Then** 预览应使用该渐变背景

#### 场景：透明背景

- **当** 用户选择透明背景
- **Then** 导出的图片应为透明 PNG

---

### 需求：圆角调整

系统必须提供圆角调整功能。

#### 场景：调整圆角大小

- **当** 用户调整圆角滑块（0 - 50px）
- **Then** 截图的圆角应实时变化

---

### 需求：阴影调整

系统必须提供阴影效果调整功能。

#### 场景：选择阴影强度

- **当** 用户选择阴影强度（无/小/中/大/超大）
- **Then** 截图的阴影应相应变化

---

### 需求：缩放调整

系统必须提供缩放调整功能。

#### 场景：调整缩放比例

- **当** 用户调整缩放滑块（50% - 200%）
- **Then** 截图在预览中的大小应相应变化

---

### 需求：尺寸预设

系统必须提供社交平台尺寸预设。

#### 场景：选择 Twitter Post 尺寸

- **当** 用户选择 "Twitter Post" 预设
- **Then** 画布尺寸应设置为 1200x675

#### 场景：选择 Instagram Story 尺寸

- **当** 用户选择 "Instagram Story" 预设
- **Then** 画布尺寸应设置为 1080x1920

#### 场景：自定义尺寸

- **当** 用户选择 "自定义尺寸"
- **And** 输入宽度和高度
- **Then** 画布应使用自定义尺寸

---

### 需求：截图美化次数限制

系统必须对免费用户实施每日截图美化次数限制。

#### 场景：免费用户未达限制

- **当** 免费用户当日截图美化次数 < 3 次
- **Then** 用户可以使用截图美化功能

#### 场景：免费用户达到限制

- **当** 免费用户当日截图美化次数 >= 3 次
- **Then** 系统应提示已达每日限制
- **And** 显示升级 Pro 的提示

#### 场景：Pro 用户无限制

- **当** Pro 用户使用截图美化功能
- **Then** 无次数限制
