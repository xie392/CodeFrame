# 变更：修复 Editor 导出/复制时标注位置计算错误

## 为什么

用户反馈在使用 Editor 编辑图片时，导出图片和复制到剪贴板的功能存在问题：当设置了非 `auto` 的容器比例（aspectRatio）时，文字标注在导出的图片中显示位置不正确，导致文字显示不全或完全不可见。

**问题复现步骤：**
1. 在 Editor 中加载一张图片
2. 在图片上添加文字标注（如"箭头测试"）
3. 设置容器比例为非 `auto`（如 1:1、16:9 等）
4. 点击"导出图片"或"复制到剪贴板"
5. 导出的图片中文字标注位置错误，显示不全

**根本原因：**
`prepareExport` 函数在计算标注绘制位置时，仅考虑了 padding 偏移，但忽略了：
1. 容器尺寸因 aspectRatio 约束而可能大于图片尺寸
2. 图片在容器中是居中显示的，存在额外的偏移量

当 aspectRatio 不是 `auto` 时：
- 容器尺寸 = `calculateAspectRatioSize()` 计算结果（可能大于图片尺寸）
- 图片在容器中居中，偏移量 = `(containerSize - imageDisplaySize) / 2`
- 标注坐标是相对于图片左上角的，但导出时需要相对于容器左上角

## 变更内容

- 修复 `prepareExport` 函数中的容器尺寸计算逻辑
- 添加图片在容器中居中偏移量的计算
- 调整标注绘制时的坐标偏移，确保标注位置正确

## 影响

- 受影响规范：`editor`（Editor 导出图片功能、Editor 复制到剪贴板功能）
- 受影响代码：`src/editor/App.tsx`（`prepareExport` 函数，约第 3468-3533 行）
- 受影响功能：图片导出、复制到剪贴板
