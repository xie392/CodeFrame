## 新增需求

### 需求：清除操作历史

系统**必须**提供清除操作历史功能，允许用户一键清除所有已保存的操作配置。

#### 场景：清除操作历史

- **当** 用户在设置页面点击「清除历史」按钮
- **那么** 显示确认弹窗，提示用户确认操作
- **且** 用户确认后，`operationHistory` 数据被清空
- **且** 清空后 Editor 和 CodeGen 页面将使用默认配置

#### 场景：取消清除操作

- **当** 用户在确认弹窗中点击取消
- **那么** 操作历史数据保持不变
- **且** 弹窗关闭

#### 场景：清除后恢复默认配置

- **当** 用户清除操作历史后重新进入 Editor 或 CodeGen 页面
- **那么** 系统使用默认配置，而非之前保存的配置
