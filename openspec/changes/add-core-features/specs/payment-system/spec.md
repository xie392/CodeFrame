# 付费系统规范

## 新增需求

### 需求：License 激活

系统必须提供 License Key 激活功能。

#### 场景：激活有效 License

- **当** 用户输入有效的 License Key
- **Then** 系统应验证 License 有效性
- **And** 激活成功后设置 isPro = true
- **And** 显示激活成功提示

#### 场景：激活无效 License

- **当** 用户输入无效或已过期的 License Key
- **Then** 系统应显示激活失败提示
- **And** 提示用户检查 License Key

#### 场景：激活已使用 License

- **当** 用户输入已在 3 台设备激活的 License Key
- **Then** 系统应显示设备数量已达上限提示

---

### 需求：License 验证

系统必须验证 License Key 的有效性。

#### 场景：在线验证

- **当** 系统有网络连接
- **Then** 应调用 Lemon Squeezy API 验证 License

#### 场景：离线缓存

- **当** 系统无网络连接
- **And** 上次验证时间在 24 小时内
- **Then** 应使用缓存的验证结果

#### 场景：验证过期

- **当** 缓存验证时间超过 24 小时
- **And** 系统无网络连接
- **Then** 应保持当前 Pro 状态
- **And** 在下次有网络时重新验证

---

### 需求：设备限制

系统必须限制单个 License 的激活设备数量。

#### 场景：设备计数

- **当** 用户在新设备激活 License
- **Then** 系统应将该设备添加到激活列表
- **And** 设备数量 +1

#### 场景：达到设备上限

- **当** License 已在 3 台设备激活
- **Then** 新设备激活应被拒绝

---

### 需求：Pro 状态管理

系统必须管理用户的 Pro 状态。

#### 场景：Pro 用户访问功能

- **当** isPro = true
- **Then** 用户可访问所有 Pro 功能

#### 场景：免费用户访问 Pro 功能

- **当** isPro = false
- **And** 用户尝试访问 Pro 功能
- **Then** 系统应显示升级弹窗

---

### 需求：升级弹窗

系统必须提供 Pro 升级弹窗。

#### 场景：显示升级弹窗

- **当** 用户点击 Pro 功能或点击"升级 Pro"
- **Then** 系统应显示升级弹窗
- **And** 弹窗应包含 Pro 功能列表和价格

#### 场景：跳转购买页面

- **当** 用户点击"立即升级"按钮
- **Then** 系统应打开 Lemon Squeezy 购买页面

#### 场景：已有 License 激活

- **当** 用户点击"点击激活"链接
- **Then** 系统应跳转到 License 激活页面

---

### 需求：配置预设保存（Pro）

Pro 用户必须能够保存配置预设。

#### 场景：保存预设

- **当** Pro 用户点击"保存预设"
- **Then** 当前配置应保存为预设
- **And** 预设名称可自定义

#### 场景：加载预设

- **当** Pro 用户选择已保存的预设
- **Then** 系统应应用该预设的配置

#### 场景：删除预设

- **当** Pro 用户删除预设
- **Then** 该预设应从列表中移除

---

### 需求：水印添加

系统必须为免费用户添加水印。

#### 场景：免费用户导出

- **当** 免费用户导出图片
- **Then** 图片右下角应添加 "CodeFrame" 水印

#### 场景：Pro 用户导出

- **当** Pro 用户导出图片
- **Then** 图片不应添加水印

---

### 需求：导出分辨率限制

系统必须限制免费用户的导出分辨率。

#### 场景：免费用户导出

- **当** 免费用户导出图片
- **Then** 最大分辨率应限制为 1920x1080

#### 场景：Pro 用户导出

- **当** Pro 用户导出图片
- **Then** 最大分辨率可达 4K (3840x2160)
