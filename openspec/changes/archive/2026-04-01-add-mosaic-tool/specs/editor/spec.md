## 新增需求

### 需求：Editor 马赛克标注绘制

Editor 必须提供马赛克标注工具，允许用户在图片上绘制马赛克区域进行隐私保护。

#### 场景：马赛克工具入口

- **当** 用户查看左侧工具栏
- **那么** 必须包含马赛克工具（Scan 图标），位于文字工具之后

#### 场景：马赛克工具选中状态

- **当** 用户点击马赛克工具
- **那么** 马赛克工具必须显示为激活状态
- **且** 画布光标必须变为 crosshair 样式
- **且** 其他工具必须处于非激活状态

#### 场景：绘制马赛克区域

- **当** 马赛克工具处于激活状态且用户按住鼠标左键拖拽
- **那么** 必须从按下位置开始绘制矩形区域
- **且** 矩形区域必须跟随鼠标移动实时更新尺寸
- **当** 用户释放鼠标左键
- **那么** 如果矩形宽度或高度大于等于 5px，必须创建马赛克标注对象
- **且** 工具必须自动切换到选择工具

#### 场景：绘制过小马赛克取消

- **当** 用户绘制的马赛克区域宽度或高度小于 5px
- **那么** 必须取消创建，不产生马赛克标注对象

### 需求：Editor 马赛克标注选择

Editor 必须支持选择已创建的马赛克标注，以便进行编辑或删除操作。

#### 场景：点击选择马赛克

- **当** 选择工具处于激活状态且用户点击马赛克区域
- **那么** 该马赛克必须被选中
- **且** 马赛克必须显示选中高亮状态（蓝色边框）
- **且** 马赛克必须显示 8 个控制点（四个角 + 四条边中点）

#### 场景：点击空白区域取消选择

- **当** 选择工具处于激活状态且用户点击马赛克外部空白区域
- **那么** 当前选中的马赛克必须取消选中状态

### 需求：Editor 马赛克标注移动

Editor 必须支持拖拽移动已创建的马赛克标注。

#### 场景：拖拽移动马赛克

- **当** 用户选中马赛克后在马赛克内部区域按住鼠标左键拖拽
- **那么** 马赛克必须跟随鼠标移动
- **且** 马赛克尺寸必须保持不变
- **且** 移动必须考虑当前缩放比例

### 需求：Editor 马赛克标注调整大小

Editor 必须支持通过控制点调整马赛克标注的尺寸。

#### 场景：拖拽角控制点调整大小

- **当** 用户选中马赛克后拖拽四个角的控制点
- **那么** 必须同时改变马赛克的宽度和高度
- **且** 对角位置必须保持不变

#### 场景：拖拽边中点控制点调整大小

- **当** 用户选中马赛克后拖拽四条边中点的控制点
- **那么** 必须改变马赛克在该方向的尺寸
- **且** 对边位置必须保持不变

#### 场景：调整大小时光标变化

- **当** 用户将鼠标悬停在控制点上
- **那么** 光标必须变为对应的调整大小样式（nwse-resize、nesw-resize、ns-resize、ew-resize）

### 需求：Editor 马赛克标注删除

Editor 必须支持删除已选中的马赛克标注。

#### 场景：键盘删除马赛克

- **当** 马赛克被选中且用户按下 Delete 或 Backspace 键
- **那么** 选中的马赛克必须被删除
- **且** 选择状态必须清除
- **且** 如果焦点在输入框中，禁止触发删除

### 需求：Editor 马赛克标注样式配置

Editor 必须提供马赛克标注的样式配置选项，允许用户自定义马赛克方块大小和透明度。

#### 场景：方块大小配置

- **当** 用户选中马赛克后查看右侧属性面板
- **那么** 必须显示方块大小滑块控件
- **且** 方块大小范围必须为 5-50px
- **且** 默认方块大小必须为 10px

#### 场景：透明度配置

- **当** 用户选中马赛克后查看右侧属性面板
- **那么** 必须显示透明度滑块控件
- **且** 透明度范围必须为 0-100%
- **且** 默认透明度必须为 100%（完全不透明）

#### 场景：样式实时预览

- **当** 用户修改马赛克方块大小或透明度配置
- **那么** 选中的马赛克必须实时更新显示效果
