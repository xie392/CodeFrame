## 新增需求

### 需求：Editor 文字标注绘制

Editor 必须提供文字标注工具，允许用户在图片上点击创建文字标注。

#### 场景：文字工具入口

- **当** 用户查看左侧工具栏
- **那么** 必须包含文字工具（Type 图标），位于矩形工具之后

#### 场景：文字工具选中状态

- **当** 用户点击文字工具
- **那么** 文字工具必须显示为激活状态
- **且** 画布光标必须变为 crosshair 样式
- **且** 其他工具必须处于非激活状态

#### 场景：点击创建文字标注

- **当** 文字工具处于激活状态且用户点击画布某个位置
- **那么** 必须在点击位置创建文字标注对象
- **且** 文字标注必须使用默认文本 "Text"
- **且** 文字标注必须使用默认样式（颜色 #FFFFFF，字号 16px，非粗体，非斜体）
- **且** 工具必须自动切换到选择工具
- **且** 新创建的文字标注必须处于选中状态
- **且** 新创建的文字标注必须进入编辑模式

### 需求：Editor 文字标注选择

Editor 必须支持选择已创建的文字标注，以便进行编辑或删除操作。

#### 场景：点击选择文字

- **当** 选择工具处于激活状态且用户点击文字区域
- **那么** 该文字标注必须被选中
- **且** 文字必须显示选中高亮状态（蓝色边框）
- **且** 文字必须显示 4 个控制点（四个角）

#### 场景：点击空白区域取消选择

- **当** 选择工具处于激活状态且用户点击文字外部空白区域
- **那么** 当前选中的文字标注必须取消选中状态

### 需求：Editor 文字标注移动

Editor 必须支持拖拽移动已创建的文字标注。

#### 场景：拖拽移动文字

- **当** 用户选中文字后在文字区域按住鼠标左键拖拽
- **那么** 文字必须跟随鼠标移动
- **且** 移动必须考虑当前缩放比例

### 需求：Editor 文字标注编辑

Editor 必须支持双击文字标注进入编辑模式，修改文字内容。

#### 场景：双击进入编辑模式

- **当** 用户双击文字标注
- **那么** 文字标注必须进入编辑模式
- **且** 必须隐藏输入框接收键盘输入

#### 场景：编辑文字内容

- **当** 文字标注处于编辑模式
- **那么** 用户可以在输入框中修改文字内容
- **且** 输入框内容必须实时同步到文字标注

#### 场景：确认编辑

- **当** 用户在编辑模式下按下 Enter 键或点击输入框外部
- **那么** 必须退出编辑模式
- **且** 文字标注内容必须更新为输入框内容
- **且** 如果内容为空，必须恢复为 "Text"

#### 场景：取消编辑

- **当** 用户在编辑模式下按下 Escape 键
- **那么** 必须退出编辑模式
- **且** 文字标注内容必须恢复为编辑前的内容

### 需求：Editor 文字标注字号调整

Editor 必须支持通过拖拽四角控制点调整文字标注的字号。

#### 场景：拖拽右下角调整字号

- **当** 用户选中文字后拖拽右下角控制点向右下方移动
- **那么** 文字字号必须增大
- **且** 字号范围必须限制在 12px - 72px

#### 场景：拖拽左上角调整字号

- **当** 用户选中文字后拖拽左上角控制点向左上方移动
- **那么** 文字字号必须增大
- **且** 字号范围必须限制在 12px - 72px

#### 场景：调整字号时光标变化

- **当** 用户将鼠标悬停在四角控制点上
- **那么** 光标必须变为对应的调整大小样式（nwse-resize 或 nesw-resize）

### 需求：Editor 文字标注删除

Editor 必须支持删除已选中的文字标注。

#### 场景：键盘删除文字

- **当** 文字被选中且用户按下 Delete 或 Backspace 键
- **那么** 选中的文字必须被删除
- **且** 选择状态必须清除
- **且** 如果焦点在输入框中或处于编辑模式，禁止触发删除

### 需求：Editor 文字标注样式配置

Editor 必须提供文字标注的样式配置选项，允许用户自定义文字外观。

#### 场景：颜色配置

- **当** 用户选中文字后查看右侧属性面板
- **那么** 必须显示颜色选择器
- **且** 必须提供预设颜色选项
- **且** 必须支持自定义颜色输入

#### 场景：字号配置

- **当** 用户选中文字后查看右侧属性面板
- **那么** 必须显示字号滑块控件
- **且** 字号范围必须为 12px - 72px
- **且** 默认字号必须为 16px

#### 场景：粗体配置

- **当** 用户选中文字后查看右侧属性面板
- **那么** 必须显示粗体切换按钮
- **且** 默认必须为非粗体

#### 场景：斜体配置

- **当** 用户选中文字后查看右侧属性面板
- **那么** 必须显示斜体切换按钮
- **且** 默认必须为非斜体

#### 场景：样式实时预览

- **当** 用户修改文字样式配置
- **那么** 选中的文字必须实时更新显示效果

### 需求：Editor 文字标注属性面板

Editor 必须在属性面板中显示文字标注的位置和内容信息。

#### 场景：位置信息显示

- **当** 用户选中文字后查看右侧属性面板
- **那么** 必须显示文字标注的 x、y 坐标
- **且** 坐标值必须可编辑

#### 场景：内容编辑

- **当** 用户选中文字后查看右侧属性面板
- **那么** 必须显示文字内容输入框
- **且** 用户可以在输入框中修改文字内容
