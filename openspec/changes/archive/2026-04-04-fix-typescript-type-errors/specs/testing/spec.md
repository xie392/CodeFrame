## 修改需求

### 需求：测试类型安全

测试文件必须通过 TypeScript 类型检查，确保类型定义正确且无未使用的导入。

#### 场景：jest-dom 匹配器类型可用

- **当** 测试文件使用 `toBeInTheDocument()`、`toHaveClass()` 等匹配器
- **那么** TypeScript 能正确识别这些匹配器的类型

#### 场景：测试 mock 数据类型完整

- **当** 测试文件创建 mock 数据
- **那么** mock 数据必须包含类型定义的所有必需属性

#### 场景：无未使用的导入

- **当** 测试文件声明导入
- **那么** 所有导入的变量必须在测试中使用
