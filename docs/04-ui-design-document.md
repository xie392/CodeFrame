## 六、响应式设计

### 6.1 断点定义

```
├── xs: < 576px   - 不适用 (扩展最小宽度)
├── sm: ≥ 576px   - Popup 尺寸
├── md: ≥ 768px   - 编辑器小窗口
├── lg: ≥ 992px   - 编辑器标准窗口
└── xl: ≥ 1200px  - 编辑器大窗口
```

### 6.2 编辑器响应式

```
lg 断点 (992px - 1199px):
├── 左侧面板: 240px
└── 右侧面板: 隐藏

xl 断点 (≥ 1200px):
├── 左侧面板: 280px
└── 右侧面板: 240px
```

--ease-in: cubic-bezier(0.4, 0, 1, 1);

--ease-bounce: cubic-bezier(0.68, -0.55, 0.265, 1.55);
