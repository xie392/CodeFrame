## 修改需求

### 需求：UI 设计系统

CodeFrame 必须使用玻璃拟态亮色主题（Glassmorphism Light），为开发者提供精致、现代的用户体验。

#### 场景：颜色系统

- **当** 用户查看任何界面
- **那么** 页面背景必须使用线性渐变：#e8eaf0（0%）→ #dfe2ec（50%）→ #d5d8e3（100%）
- **且** 主色调必须为 #FF6B35（橙色）和 #00b892（青色）双色强调
- **且** 文字色必须为 #1a1a1a（主文字）、#888888（次要文字）、#999999（辅助文字）
- **且** 边框色必须为 rgba(0, 0, 0, 0.08)（主边框）

#### 场景：字体系统

- **当** 用户查看标题、Logo 或按钮文字
- **那么** 字体必须为 Oswald
- **当** 用户查看正文、标签或描述
- **那么** 字体必须为 JetBrains Mono

#### 场景：卡片样式

- **当** 用户查看操作按钮卡片
- **那么** 圆角必须为 16px
- **且** 背景必须使用 rgba(255,255,255,0.6) → rgba(255,255,255,0.8) 渐变 + backdrop-blur(12px)
- **且** 边框为 1px rgba(0,0,0,0.08)
- **且** 必须有外阴影 rgba(0,0,0,0.1)，Y 偏移 4px，模糊 16px

#### 场景：功能列表项样式

- **当** 用户查看功能列表项
- **那么** 列表项圆角必须为 12px
- **且** 背景色必须为 rgba(255,255,255,0.6)
- **且** 右侧必须有 chevron-right 导航箭头（rgba(0,0,0,0.2)）

#### 场景：主题唯一性

- **当** 用户查看任何界面
- **那么** 必须仅显示亮色主题
- **且** 禁止存在暗色模式切换入口
