## 修改需求

### 需求：代码预览区域

PreviewArea 必须在右侧展示 Shiki 语法高亮的代码窗口预览效果，代码窗口的整体视觉风格必须与左侧选中的主题同步。背景填充区域必须支持四方向独立边距值。代码窗口高度必须自适应代码内容行数。背景填充区域和代码窗口必须支持独立圆角设置。

#### 场景：预览区域背景

- **当** 用户查看预览区域
- **那么** 预览区域必须占据剩余空间（fill_container）
- **且** 背景色必须随用户选择的背景色变化
- **且** 内容必须垂直水平居中

#### 场景：代码窗口外观

- **当** 预览区域渲染
- **那么** 必须显示 CodeWindow（初始宽度 520px，内框圆角默认 12px）
- **且** CodeWindow 高度必须自适应代码内容行数，计算方式为 `headerHeight(40) + paddingTop(20) + paddingBottom(20) + codeLines × lineHeight(20)`
- **且** CodeWindow 最小高度必须为 `headerHeight(40) + paddingTop(20) + paddingBottom(20) + 1 × lineHeight(20)` = 100px（至少显示 1 行代码）
- **且** CodeWindow 最大高度不得超过 800px
- **且** CodeWindow 背景色必须随选中主题变化（深色主题为深色背景，浅色主题为浅色背景）
- **且** CodeWindow 必须有外阴影（颜色 #00000026，偏移 y=8，模糊 40px）
- **且** CodeWindow 顶部必须显示 WindowHeader（高度 40px，内框圆角顶部）
- **且** WindowHeader 背景色必须随选中主题变化
- **且** WindowHeader 必须包含红 (#FF5F56)、黄 (#FFBD2E)、绿 (#27C93F) 三个圆点（12×12px，圆形）
- **且** 圆点右侧必须显示文件名 `greet.js`（颜色 #777777，字号 12px）
- **且** CodeWindow 下方必须显示 WindowBody，包含 Shiki 语法高亮渲染的代码（内边距 20px，JetBrains Mono 字体）

#### 场景：非对称背景填充渲染

- **当** 用户设置了不同的上下左右边距值
- **那么** 代码窗口外围的背景填充区域必须使用对应的独立方向值渲染
- **且** 左侧填充宽度必须等于 `paddingLeft`
- **且** 右侧填充宽度必须等于 `paddingRight`
- **且** 上方填充高度必须等于 `paddingTop`
- **且** 下方填充高度必须等于 `paddingBottom`
- **且** 四方向边距均为 0 时，背景填充区域不得渲染
- **且** 背景填充区域的圆角必须使用外框圆角值（`outerBorderRadius`）

#### 场景：预览内容同步

- **当** 用户在代码窗口中编辑代码或切换主题
- **那么** WindowBody 必须实时显示 Shiki 语法高亮后的代码内容
- **且** 高亮渲染必须使用 `shiki/engine/javascript` 引擎（避免 WASM CSP 问题）
- **且** 高亮结果必须缓存，仅在代码内容或选中主题变更时重新渲染

## 新增需求

### 需求：内外框独立圆角设置

系统必须允许用户分别设置代码窗口的外框（背景填充区域）和内框（代码窗口本身）的圆角，并提供统一/自定义两种模式切换。

#### 圆角控制区域标题显示

- **当** 用户查看 LeftPanel 中的圆角控制区域
- **那么** 必须显示 `border_radius` 标签文字（颜色 #3D3D3D，字号 11px），与 padding 等其他控制区域标签样式一致

#### 统一圆角模式

- **当** 用户处于统一圆角模式
- **那么** 必须显示单个滑块控制
- **且** 拖动滑块时，外框和内框圆角必须同步更新为相同值
- **且** 滑块值范围必须为 0px 到 30px

#### 自定义圆角模式

- **当** 用户点击圆角区域的"更多设置"按钮（类似 padding 的 Popover 触发按钮）
- **那么** 必须在按钮上方弹出 Popover 浮层
- **且** Popover 内必须显示两个独立滑块：外框（outer）和内框（inner）
- **且** 每个滑块必须显示当前对应的圆角数值（单位 px）
- **且** 每个滑块的值范围必须为 0px 到 30px
- **且** 用户修改任一滑块后，模式必须标记为"自定义"
- **且** 统一滑块的显示值必须切换为 `···` 状态

#### 外框圆角渲染

- **当** 用户设置了外框圆角值
- **那么** 背景填充区域（代码窗口外围的彩色区域）的圆角必须使用外框圆角值
- **且** 代码窗口本身的圆角不受外框圆角值影响

#### 内框圆角渲染

- **当** 用户设置了内框圆角值
- **那么** 代码窗口整体、标题栏顶部、窗口主体底部的圆角必须使用内框圆角值
- **且** 背景填充区域的圆角不受内框圆角值影响

#### 默认圆角值

- **当** 页面初始化或用户重置设置
- **那么** 外框圆角默认值必须为 16px
- **且** 内框圆角默认值必须为 12px
- **且** 模式必须为"自定义"（因为默认值不同）
