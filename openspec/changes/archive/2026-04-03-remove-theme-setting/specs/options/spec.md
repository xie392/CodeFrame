## 修改需求

### 需求：通用设置配置

系统**必须**提供通用设置配置功能，允许用户自定义默认行为。

#### 场景：切换默认导出格式

- **当** 用户点击"默认导出格式"下拉选择器
- **那么** 显示可选格式列表（PNG / JPG / WEBP / SVG）
- **且** 选择后自动保存到 `chrome.storage.local`

#### 场景：切换截图质量

- **当** 用户点击"截图质量"下拉选择器
- **那么** 显示可选质量列表（标准 / 高清 / 超高清）
- **且** 选择后自动保存到 `chrome.storage.local`

#### 场景：切换语言

- **当** 用户点击"界面语言"下拉选择器
- **那么** 显示可选语言列表（简体中文 / English）
- **且** 选择后自动保存到 `chrome.storage.local`
