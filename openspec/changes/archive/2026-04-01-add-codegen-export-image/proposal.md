# 变更：为 CodeGen 添加导出图片与复制到剪贴板功能

## 为什么

CodeGen 模块的核心功能（代码编辑、主题切换、背景色、水印等）已基本完善，但导出按钮（`App.tsx:910-921`）目前仅是 UI 占位，无任何功能实现。用户需要一个完整的工作流来将美化后的代码窗口导出为图片或直接复制到剪贴板。

## 变更内容

- 使用已安装的 `@zumer/snapdom` 库实现 DOM 转图片
- 将现有单一「导出按钮」改造为按钮组：导出图片（主按钮）+ 复制到剪贴板（小按钮）
- 实现导出为 PNG 图片下载功能
- 实现复制代码窗口截图到系统剪贴板功能
- 导出/复制时必须包含水印（如已开启）

## 影响

- 受影响规范：`codegen`（修改「导出按钮」需求，新增「导出图片」和「复制到剪贴板」需求）
- 受影响代码：
  - `src/codegen/App.tsx`（导出按钮 UI 改造 + 导出/复制逻辑）
