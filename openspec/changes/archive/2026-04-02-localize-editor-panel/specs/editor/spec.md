## 新增需求

### 需求：Editor 属性面板中文化

Editor 右侧属性面板必须使用中文显示所有文本，并移除终端风格符号，提升中文用户的阅读体验。

#### 场景：面板标题显示

- **当** 用户查看右侧属性面板
- **那么** 面板不得显示 `// properties` 注释风格标题
- **且** 面板应直接显示内容区块

#### 场景：区块标签中文化

- **当** 用户查看右侧属性面板的区块标签
- **那么** 所有区块标签必须使用中文
- **且** 区块标签不得包含 `[` 和 `]` 符号
- **且** 标签必须包含：位置、图片容器、箭头样式、矩形样式、文字样式、马赛克样式

#### 场景：折叠面板标题中文化

- **当** 用户查看图片容器设置面板
- **那么** 所有折叠面板标题必须使用中文
- **且** 标题必须包含：背景、边距、圆角、阴影、比例、窗口控件、水印

#### 场景：字段标签中文化

- **当** 用户查看标注属性字段
- **那么** 所有字段标签必须使用中文
- **且** 位置字段标签必须为：X、Y、宽、高
- **且** 箭头坐标字段标签必须为：起点 X、起点 Y、终点 X、终点 Y
- **且** 样式字段标签必须使用中文（线宽、透明度、字号等）

#### 场景：操作按钮中文化

- **当** 用户查看操作按钮
- **那么** 按钮文本必须使用中文
- **且** 按钮文本不得包含 `$` 符号
- **且** 按钮文本必须为：导出图片、复制到剪贴板

#### 场景：预设名称中文化

- **当** 用户查看预设选项列表
- **那么** 所有预设名称必须使用中文
- **且** 背景预设必须包含：透明、白色、黑色、日落、海洋、森林、紫色、蜜桃
- **且** 背景类型必须包含：纯色、线性渐变、径向渐变
- **且** 阴影预设必须包含：无、轻微、中等、强烈
- **且** 水印位置必须包含：右下、左下、右上、左上、居中
