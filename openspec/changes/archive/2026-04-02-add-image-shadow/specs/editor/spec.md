## 新增需求

### 需求：Editor 图片阴影设置

Editor 右侧属性面板必须提供图片本身的阴影设置功能，允许用户独立设置图片的阴影效果，与容器阴影互不影响。

#### 场景：图片阴影设置入口

- **当** 用户查看右侧属性面板的图片容器设置区域
- **那么** 必须显示「图片阴影」折叠面板
- **且** 面板必须位于「阴影」（容器阴影）区块之后
- **且** 面板默认展开

#### 场景：图片阴影启用/禁用

- **当** 用户点击「图片阴影」折叠面板的开关
- **那么** 图片阴影必须启用或禁用
- **且** 启用时图片必须显示阴影效果
- **且** 禁用时图片必须不显示阴影效果

#### 场景：图片阴影颜色设置

- **当** 图片阴影启用且用户修改颜色选择器
- **那么** 图片阴影颜色必须实时更新
- **且** 默认颜色必须为黑色（#000000）

#### 场景：图片阴影模糊度设置

- **当** 图片阴影启用且用户调整模糊度滑块
- **那么** 图片阴影模糊度必须实时更新
- **且** 模糊度范围必须为 0-100px
- **且** 默认模糊度必须为 20px

#### 场景：图片阴影偏移设置

- **当** 图片阴影启用且用户修改 X/Y 偏移值
- **那么** 图片阴影偏移必须实时更新
- **且** X 偏移默认值必须为 0
- **且** Y 偏移默认值必须为 10

#### 场景：图片阴影预设选择

- **当** 用户查看图片阴影设置
- **那么** 必须提供阴影预设快速选择器
- **且** 预设必须包含：无（禁用）、轻微（blur: 10, Y: 4）、中等（blur: 20, Y: 10）、强烈（blur: 40, Y: 20）
- **且** 选择预设后阴影参数必须自动更新

#### 场景：图片阴影默认值

- **当** 用户打开 Editor 加载图片
- **那么** 图片阴影默认必须禁用
- **且** 所有阴影参数必须使用默认值

#### 场景：图片阴影与容器阴影独立

- **当** 用户同时设置图片阴影和容器阴影
- **那么** 两种阴影必须独立生效
- **且** 图片阴影显示在图片上
- **且** 容器阴影显示在容器上
- **且** 两者视觉上叠加显示
