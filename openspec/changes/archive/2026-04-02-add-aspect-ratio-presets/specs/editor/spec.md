## 新增需求

### 需求：Editor 图片容器比例设置

Editor 右侧属性面板必须提供图片容器的比例设置功能，允许用户选择预设比例或自定义比例来调整容器尺寸。

#### 场景：比例设置入口

- **当** 用户查看右侧属性面板的图片容器设置区域
- **那么** 必须显示比例折叠面板，标题为"比例"
- **且** 面板默认展开

#### 场景：比例预设分类

- **当** 用户查看比例预设列表
- **那么** 预设必须按分类组织显示
- **且** 必须包含以下分类：

**自动比例**
- 自动 - 保持图片原始比例（默认选项）

**基础比例**
- 1:1 - 正方形
- 4:3 - 标准比例
- 3:2 - 摄影标准
- 2:3 - 竖版摄影
- 5:4 - 传统显示器
- 16:9 - 高清标准
- 16:10 - 宽屏显示器
- 21:9 - 超宽屏

**社交媒体**
- 9:16 - 短视频（抖音、TikTok、Stories）
- 4:5 - Instagram 动态
- 3:4 - 小红书封面
- 1.91:1 - Facebook 动态

**设备屏幕**
- iPhone (9:19.5) - iPhone 12/13/14/15/16 系列
- iPhone SE (16:9) - iPhone SE 系列
- 安卓旗舰 (9:21) - 三星 S 系列等
- iPad (4:3) - iPad 全系列
- 安卓平板 (16:10) - Android 平板

**自定义**
- 自定义 - 用户输入宽高比例

#### 场景：比例选择后容器尺寸变化

- **当** 用户从预设列表中选择一个比例
- **那么** 图片容器必须立即应用该比例约束
- **且** 容器尺寸必须根据比例重新计算
- **且** 图片必须在容器中居中显示
- **且** 超出比例区域的部分必须显示容器背景

#### 场景：自定义比例输入

- **当** 用户选择"自定义"比例选项
- **那么** 必须显示两个数值输入框（宽和高）
- **且** 用户可以输入自定义的宽高比例值
- **且** 输入后容器尺寸必须实时更新

#### 场景：比例实时预览

- **当** 用户修改比例设置或自定义比例值
- **那么** 图片容器必须实时更新显示效果
- **且** 必须显示比例约束后的容器边界

#### 场景：默认比例值

- **当** 用户打开 Editor 加载图片
- **那么** 默认比例必须为"自动"
- **且** 必须保持图片原始宽高比
- **且** 容器尺寸必须等于图片尺寸
