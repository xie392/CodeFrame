## 新增需求

### 需求：画布交互系统

系统必须提供类似 Figma 的画布交互系统，支持缩放、平移、拖动等操作，让用户能够自由调整代码截图的查看视角。

#### 场景：画布缩放

- **当** 用户在画布区域使用鼠标滚轮
- **那么** 画布必须根据滚轮方向进行放大或缩小
- **且** 缩放比例范围必须在 10% 到 200% 之间
- **且** 缩放中心点必须跟随鼠标位置

#### 场景：画布平移

- **当** 用户按住空格键并拖动鼠标
- **那么** 画布视图必须跟随鼠标移动方向平移
- **且** 鼠标光标必须变为抓手样式

#### 场景：画布拖动

- **当** 用户直接拖动代码窗口
- **那么** 代码窗口必须在画布内移动位置
- **且** 画布边界必须足够大以容纳拖动的窗口

#### 场景：重置视图

- **当** 用户双击画布空白区域
- **那么** 画布必须重置为 100% 缩放比例并居中显示代码窗口

## 修改需求

### 需求：预览区域布局

PreviewArea 必须改造为画布模式，背景不再占满整个区域，而是作为画布背景，代码窗口悬浮于画布中央，周围留有空白边距。

#### 场景：画布模式外观

- **当** 用户查看 PreviewArea
- **那么** 预览区域必须显示为画布模式，而非全屏填充模式
- **且** 画布背景色必须根据用户选择的背景色显示
- **且** 画布与代码窗口之间必须留有充足的空白边距（最小 200px）
- **且** 代码窗口必须默认居中显示

#### 场景：画布尺寸

- **当** 画布初始化时
- **那么** 画布内容区域尺寸必须为代码窗口尺寸的 3 倍以上（水平和垂直方向）
- **且** 画布必须支持无限滚动（内容溢出时显示滚动条）

#### 场景：画布背景样式

- **当** 用户选择不同背景色
- **那么** 画布背景必须使用选中的纯色填充
- **且** 画布背景与代码窗口之间必须有明显的视觉层次

---

### 需求：代码窗口交互

CodeWindow 必须支持在画布内直接拖动调整位置，并且可以选择是否与编辑区域融合，实现所见即所得的编辑体验。

#### 场景：代码窗口拖动

- **当** 用户在代码窗口标题栏按下鼠标并拖动
- **那么** 代码窗口必须跟随鼠标在画布内移动
- **且** 窗口移动必须有平滑的拖拽效果
- **且** 窗口边界不能超出画布可视区域

#### 场景：代码窗口选中状态

- **当** 用户点击代码窗口
- **那么** 代码窗口必须显示选中边框（2px #00D4AA）
- **且** 选中状态下窗口层级必须提升

#### 场景：编辑模式切换

- **当** 用户在代码窗口内双击代码内容区域
- **那么** 系统必须切换到编辑模式，显示 CodeMirror 编辑器覆盖层
- **且** 编辑器必须使用当前选中的主题样式
- **且** 用户输入的代码必须实时同步到预览窗口

---

### 需求：缩放控制组件

系统必须提供缩放控制 UI，让用户可以直观地查看和调整当前缩放比例。

#### 场景：缩放控制条显示

- **当** 用户查看画布区域
- **那么** 画布右下角必须显示缩放控制条
- **且** 控制条必须包含：缩小按钮、当前比例显示（如 "100%"）、放大按钮、重置按钮
- **且** 控制条背景必须为半透明深色（#1E1E1E80），圆角 8px

#### 场景：缩放按钮交互

- **当** 用户点击放大/缩小按钮
- **那么** 缩放比例必须以 10% 为步长进行调整
- **且** 缩放比例显示必须实时更新

---

### 需求：代码编辑器融合模式

系统必须提供选项将代码编辑区域与预览区域融合，实现类似 Carbon 的直接编辑体验。

#### 场景：融合模式切换

- **当** 用户在设置中开启"编辑融合模式"
- **那么** 左侧面板的代码输入区域必须隐藏
- **且** 代码窗口的内容区域必须变为可编辑状态
- **且** 编辑时使用与预览一致的主题样式

#### 场景：融合模式编辑

- **当** 用户在融合模式下编辑代码窗口中的内容
- **那么** 编辑区域必须支持基础的代码编辑功能（输入、删除、选择）
- **且** 语法高亮必须实时更新
- **且** 用户体验必须流畅，无明显延迟

---

## 移除需求

### 需求：预览区域全屏填充模式

**原因**：新设计采用画布模式，代码窗口悬浮于画布中央，不再使用全屏填充的布局方式。

**迁移**：PreviewArea 的布局逻辑需要完全重构，使用新的 CanvasContainer 组件替代原有的居中布局。
