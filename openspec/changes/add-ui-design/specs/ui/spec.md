## 新增需求

### 需求：UI 设计文件

系统**必须**提供完整的用户界面设计文件，包含三个核心页面的视觉设计。

#### 场景：Popup 主弹窗界面

- **当** 用户点击 Chrome 扩展图标
- **那么** 显示 360px × 500px 的主弹窗界面
- **并且** 包含 Header 区域显示 Logo 和操作按钮
- **并且** 包含 Tab 导航（截图/代码/本地）
- **并且** 包含截图操作按钮网格（区域截图、可视区域、整页截图、桌面截图、延迟截图）
- **并且** 包含底部快捷键提示

#### 场景：代码生成器界面

- **当** 用户切换到代码 Tab 或通过快捷键进入
- **那么** 显示代码生成器页面
- **并且** 左侧面板**必须**包含代码输入区、语言选择、主题选择、背景选择、选项设置
- **并且** 右侧显示代码预览区域，包含 macOS 风格窗口栏和代码高亮示例
- **并且** 底部包含导出按钮

#### 场景：图片编辑器界面

- **当** 用户完成截图后
- **那么** 显示图片编辑器页面
- **并且** 左侧工具栏**必须**包含选择、箭头、矩形、圆形、文字、马赛克工具
- **并且** 中央显示截图预览画布
- **并且** 右侧属性面板**必须**包含颜色、粗细、透明度设置和导出选项

### 需求：Terminal Minimal 设计风格

系统 UI **必须**遵循 Terminal Minimal Dashboard 设计风格。

#### 场景：暗色模式

- **当** 用户使用应用
- **那么** 界面**必须**使用纯暗色背景 (#0A0A0A)
- **并且** 所有页面保持统一的暗色调

#### 场景：等宽字体系统

- **当** 显示界面文字
- **那么** **必须**使用 JetBrains Mono 字体显示导航、标题、按钮
- **并且** **必须**使用 IBM Plex Mono 字体显示描述性文字

#### 场景：终端语法 UI

- **当** 显示交互元素
- **那么** **必须**使用终端语法元素作为视觉语言
- **并且** Logo 使用 `>` 前缀
- **并且** 操作按钮使用 `$` 前缀
- **并且** 标签使用 `//` 注释风格
- **并且** 状态使用 `[]` 括号标记

#### 场景：Emerald 主色调

- **当** 显示强调元素
- **那么** **必须**使用 Emerald 绿色 (#10B981) 作为主色调
- **并且** 用于激活状态、CTA 按钮、成功提示
