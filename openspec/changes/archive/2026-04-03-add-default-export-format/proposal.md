# 变更：实现默认导出格式设置功能

## 为什么

设置页已有"默认导出格式"选项（PNG / JPG / WEBP / SVG），设置也正确持久化存储到 `chrome.storage.local`。但编辑器和代码生成器的导出逻辑都硬编码使用 `snapdom.toPng`，没有读取用户的默认导出格式设置，导致设置页的配置无法生效。

用户期望在设置页配置默认导出格式后，导出功能能自动使用配置的格式。

## 变更内容

- 修改编辑器导出逻辑，读取并使用默认导出格式设置
- 修改代码生成器导出逻辑，读取并使用默认导出格式设置
- 为 JPG 格式添加背景色处理（JPG 不支持透明，需要白色背景）
- 导出文件扩展名根据格式动态生成

## 影响

- 受影响规范：options
- 受影响代码：
  - `src/editor/App.tsx` - 编辑器导出功能
  - `src/codegen/App.tsx` - 代码生成器导出功能
