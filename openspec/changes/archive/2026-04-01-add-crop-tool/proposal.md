# 变更：为 Editor 添加图片裁剪功能

## 为什么

当前 Editor 已支持多种标注工具（箭头、矩形、文字、马赛克），但缺少对图片本身的基础编辑能力。裁剪是图片编辑中最常用的功能之一，用户经常需要裁剪截图以聚焦关键区域或移除无关内容。添加裁剪功能可以提升 Editor 的实用性，使其成为更完整的图片编辑工具。

## 变更内容

- 新增裁剪工具入口，位于左侧工具栏
- 新增裁剪框绘制与交互功能（可拖拽调整）
- 新增裁剪确认与取消机制
- 裁剪操作将更新图片数据并重置所有标注的坐标系统

## 影响

- 受影响规范：`editor`（新增 4 个需求）
- 受影响代码：
  - `src/editor/App.tsx` - 添加裁剪工具状态与交互逻辑
  - `src/editor/components/Toolbar.tsx` - 添加裁剪工具按钮
  - `src/shared/utils/index.ts` - 可能添加图片裁剪工具函数
