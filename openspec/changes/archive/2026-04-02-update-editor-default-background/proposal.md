# 变更：Editor 默认背景改为渐变色

## 为什么

当前 Editor 的图片容器默认背景为纯白色（#FFFFFF），视觉上较为单调。改为渐变色作为默认背景可以：
- 提升视觉吸引力和专业感
- 与现有的渐变预设风格保持一致
- 让用户打开编辑器时即刻呈现美化效果

## 变更内容

- 将 `DEFAULT_FRAME_SETTINGS.background` 从纯色白色改为线性渐变色
- 选择「天空渐变」作为默认背景：浅青蓝 `#E0F7FA` 过渡到淡紫 `#E1BEE7`

## 影响

- 受影响规范：`specs/editor/spec.md`
- 受影响代码：`src/editor/App.tsx` 第 122-127 行
- **无破坏性变更**：用户仍可自由选择任意背景颜色或渐变
