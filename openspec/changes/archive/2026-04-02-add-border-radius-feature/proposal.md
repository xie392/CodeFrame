# 变更：Editor 圆角功能增强

## 为什么

当前 Editor 图片容器仅有基础的统一圆角设置（单一滑块控件），无法满足用户对精细圆角控制的需求。用户需要：四角独立设置、多单位支持（px/%）、快速预设选择，以实现更灵活的图片容器样式定制。

## 变更内容

- 支持四个角独立设置圆角值
- 支持像素(px)和百分比(%)两种单位切换
- 提供圆角预设快速选择（无圆角、小圆角、中等圆角、大圆角、胶囊形）
- 保持统一圆角模式的联动开关
- 实时预览圆角效果

## 影响

- 受影响规范：editor
- 受影响代码：
  - `src/editor/types.ts` - FrameSettings.borderRadius 类型定义
  - `src/editor/App.tsx` - 圆角设置 UI 控件、渲染逻辑
