## 新增需求

### 需求：UI 设计系统

CodeFrame 必须使用现代科技风格（Bento Grid + Glassmorphism），为开发者提供精致、现代的用户体验。

#### 场景：颜色系统

- **当** 用户查看任何界面
- **那么** 主色调必须为 #3B82F6（蓝色）
- **且** 背景色必须为 #0F172A（深蓝黑）
- **且** 文字色必须为 #F1F5F9（浅灰白）
- **且** 边框色必须为 #334155（深灰蓝）

#### 场景：字体系统

- **当** 用户查看标题或按钮
- **那么** 字体必须为 Space Grotesk
- **当** 用户查看正文或描述
- **那么** 字体必须为 DM Sans

#### 场景：卡片样式

- **当** 用户查看操作按钮卡片
- **那么** 圆角必须为 12px
- **且** 背景必须使用 rgba(255,255,255,0.05) + backdrop-blur
- **且** 必须有柔和阴影

#### 场景：交互动画

- **当** 用户悬停在可交互元素上
- **那么** 必须有 scale(1.02) 效果
- **且** 过渡时间必须为 200ms
- **且** 过渡曲线必须为 ease
