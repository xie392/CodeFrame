## 修改需求

### 需求：Popup 快捷操作区功能
Popup 页面的 ActionRow 区域仅提供截图相关快捷操作，不包含代码编辑器入口。

#### 场景：ActionRow 区域显示
- **当** 用户打开 CodeFrame 插件 Popup
- **那么** ActionRow 区域应显示以下快捷操作按钮：
  - 可视截图
  - 选择区域
  - 整页截图
- **并且** 不显示"代码编辑器"按钮

#### 场景：代码编辑器入口保留
- **当** 用户查看 FeatureList 区域
- **那么** 应看到"代码编辑器"列表项
- **并且** 点击后可访问代码编辑器功能
