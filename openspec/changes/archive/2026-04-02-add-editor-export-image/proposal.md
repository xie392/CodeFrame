# 变更：为 Editor 添加导出图片与复制到剪贴板功能

## 为什么

Editor 图片编辑器已完成核心功能（标注工具、选择工具、容器设置、水印等），但右侧属性面板中的「导出图片」和「复制到剪贴板」按钮仅为 UI 占位，无任何功能实现。用户需要一个完整的工作流来将编辑后的图片导出或复制到剪贴板。

## 变更内容

- 使用已安装的 `@zumer/snapdom` 库实现 DOM 转图片
- 实现导出图片下载功能（包含背景、标注、水印）
- 实现复制到剪贴板功能
- 导出时将 Canvas 标注图层渲染到图片中
- 添加导出状态反馈（loading 状态）

## 影响

- 受影响规范：`editor`（新增「导出图片功能」和「复制到剪贴板功能」需求）
- 受影响代码：
  - `src/editor/App.tsx`（导出/复制逻辑、标注图层合并）
