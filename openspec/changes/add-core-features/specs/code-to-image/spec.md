# 代码转图片功能规范

## 新增需求

### 需求：代码输入

系统必须提供代码输入区域，支持用户输入或粘贴代码。

#### 场景：用户输入代码

- **当** 用户在代码输入区域输入代码
- **那么** 系统应实时显示代码内容

#### 场景：用户粘贴代码

- **当** 用户粘贴代码到输入区域
- **那么** 系统应正确显示粘贴的代码内容

#### 场景：用户清空代码

- **当** 用户点击"清空"按钮
- **那么** 代码输入区域应被清空

---

### 需求：语言自动检测

系统必须自动检测输入代码的编程语言。

#### 场景：自动检测 JavaScript

- **当** 用户输入 JavaScript 代码
- **那么** 系统应自动将语言选择器设置为 "JavaScript"

#### 场景：自动检测 Python

- **当** 用户输入 Python 代码
- **那么** 系统应自动将语言选择器设置为 "Python"

#### 场景：手动选择语言

- **当** 用户手动选择语言
- **那么** 系统应使用用户选择的语言进行语法高亮

---

### 需求：语法高亮

系统必须使用 highlight.js 对代码进行语法高亮。

#### 场景：JavaScript 代码高亮

- **当** 用户输入 JavaScript 代码
- **那么** 关键字、字符串、注释等应显示不同颜色

#### 场景：支持的语言

- **当** 用户输入以下语言的代码时
- **那么** 系统应正确高亮：
  - JavaScript, TypeScript, Python, Java, Go, Rust
  - C, C++, C#, PHP, Ruby, Swift, Kotlin
  - HTML, CSS, SCSS, SQL, JSON, YAML, Markdown
  - Bash, Shell, Dockerfile, GraphQL, Vue, React

---

### 需求：主题选择

系统必须提供代码主题选择功能。

#### 场景：免费用户选择免费主题

- **当** 免费用户选择 "GitHub Light"、"GitHub Dark"、"One Dark Pro"、"Dracula"、"Monokai" 之一
- **那么** 代码预览应立即应用该主题

#### 场景：免费用户选择 Pro 主题

- **当** 免费用户点击 Pro 主题（如 "Nord"、"Tokyo Night"）
- **那么** 系统应弹出升级提示

#### 场景：Pro 用户选择任意主题

- **当** Pro 用户选择任意主题
- **Then** 代码预览应立即应用该主题

---

### 需求：背景设置

系统必须提供代码背景设置功能。

#### 场景：选择纯色背景

- **当** 用户选择白色、浅灰或深灰背景
- **那么** 代码预览应使用该纯色背景

#### 场景：选择渐变背景（Pro）

- **当** Pro 用户选择渐变背景（如 "Sunset"、"Ocean"）
- **Then** 代码预览应使用该渐变背景

#### 场景：上传自定义背景（Pro）

- **当** Pro 用户上传自定义背景图片
- **Then** 代码预览应使用该图片作为背景

---

### 需求：窗口样式

系统必须提供窗口样式选择。

#### 场景：选择 macOS 样式

- **当** 用户选择 macOS 窗口样式
- **Then** 代码预览应显示红黄绿按钮

#### 场景：选择 Windows 11 样式

- **当** 用户选择 Windows 11 窗口样式
- **Then** 代码预览应显示最小化、最大化、关闭按钮

#### 场景：选择无边框样式

- **当** 用户选择无边框样式
- **Then** 代码预览不显示任何窗口装饰

---

### 需求：显示行号

系统必须提供行号显示开关。

#### 场景：开启行号显示

- **当** 用户开启行号显示
- **Then** 每行代码前应显示行号

#### 场景：关闭行号显示

- **当** 用户关闭行号显示
- **Then** 代码不应显示行号

---

### 需求：字体大小调整

系统必须提供字体大小调整功能。

#### 场景：调整字体大小

- **当** 用户选择不同字体大小（12px - 24px）
- **Then** 代码预览应使用相应字体大小

---

### 需求：代码格式化

系统必须提供代码格式化功能。

#### 场景：格式化代码

- **当** 用户点击"格式化"按钮
- **Then** 系统应使用 Prettier 格式化代码
- **And** 格式化后的代码应显示在输入区域
