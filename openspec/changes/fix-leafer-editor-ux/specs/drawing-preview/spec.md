## 新增需求

### 需求:绘制实时预览路径
绘制箭头、矩形、马赛克时，鼠标移动过程中必须实时显示从起点到当前位置的预览图形（半透明），禁止仅在鼠标释放后显示最终图形。

#### 场景:绘制箭头预览
- **当** 用户按下鼠标开始绘制箭头并移动鼠标
- **那么** 实时显示从起点到当前鼠标位置的半透明箭头预览

#### 场景:绘制矩形预览
- **当** 用户按下鼠标开始绘制矩形并移动鼠标
- **那么** 实时显示从起点到当前鼠标位置的半透明矩形预览

#### 场景:绘制马赛克预览
- **当** 用户按下鼠标开始绘制马赛克并移动鼠标
- **那么** 实时显示从起点到当前鼠标位置的半透明灰色区域预览

#### 场景:取消绘制
- **当** 用户按下 Escape 取消绘制
- **那么** 预览图形消失，不创建最终图形
