## 新增需求

### 需求：延时截图入口行为

Popup 中「延时截取可视区域」入口必须提供延时时间选择交互，取代当前的占位行为。

#### 场景：点击延时截图入口

- **当** 用户点击 FeatureList 中的「延时截取可视区域」按钮（Timer 图标）
- **那么** 必须在当前入口下方展开延时选项子菜单
- **且** 子菜单必须包含 3 个选项：3 秒、5 秒、10 秒
- **且** 点击 Popup 其他区域必须关闭子菜单

#### 场景：选择延时时间

- **当** 用户在子菜单中选择一个延时时间
- **那么** 必须向 Background Service Worker 发送 `CAPTURE_REQUEST` 消息，payload 包含 `mode: 'delayed'` 和选定的 `delay` 值
- **且** Popup 必须在消息发送后关闭（`setTimeout(window.close, 100)`）

#### 场景：子菜单样式

- **当** 延时选项子菜单展开
- **那么** 子菜单背景色必须为 #171717
- **且** 子菜单边框必须为 1px #2a2a2a
- **且** 每个选项高度必须为 32px
- **且** 选项文字必须为 12px，颜色 #E5E5E5
- **且** 选项悬停时背景色必须变为 #1A1A1A
- **且** 当前选中项必须显示强调色（#10B981）指示器
