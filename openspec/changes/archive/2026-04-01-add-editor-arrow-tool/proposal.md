# 变更：Editor 箭头标注工具

## 为什么

Editor 工具栏已有箭头工具按钮，但箭头绘制功能尚未实现。用户需要在截图上进行方向指引标注，
箭头是最常用的标注工具之一。需要提供完整的箭头绘制、样式自定义功能。

## 变更内容

- 实现箭头绘制功能（起点拖拽到终点创建箭头）
- 支持颜色选择：预设颜色列表 + 自定义颜色选择器
- 支持大小控制：线条粗细 + 箭头头部大小
- 支持箭头样式：单箭头（箭头在终点）和双箭头
- 箭头属性在右侧属性面板中显示和编辑
- 支持选中已绘制的箭头进行修改

## 影响

- 受影响规范：`specs/editor/spec.md`
- 受影响代码：
  - `src/editor/App.tsx`（主要实现）
  - 可能需要新增状态管理（箭头数据结构）
