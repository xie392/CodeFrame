# 变更：Editor 水印功能实现

## 为什么

Editor 已有水印设置的 UI 控件（开关、文字、位置、透明度、大小），但水印渲染逻辑尚未实现。用户开启水印后，画布上不会显示任何水印效果。本次变更实现完整的水印渲染功能，支持文字水印和图片水印（Logo），在导出图片时可选是否包含水印。

## 变更内容

### 1. 文字水印渲染
- 在图片容器上渲染文字水印
- 支持自定义文字内容
- 支持四角位置（左上、右上、左下、右下）
- 支持透明度调节（0-100%）
- 支持字体大小调节（8-48px）
- 水印颜色自动适配背景（深色背景用白色，浅色背景用黑色）

### 2. 图片水印（Logo）渲染
- 新增图片水印支持
- 支持上传本地图片作为水印
- 支持调整图片水印大小
- 支持四角位置

### 3. 导出时水印处理
- 导出图片时可选择是否包含水印
- 默认包含水印

### 4. UI 控件更新
- 更新水印设置面板，新增图片水印上传入口
- 新增导出时是否包含水印的选项

## 影响

- 受影响规范：`editor`
- 受影响代码：
  - `src/editor/App.tsx` — 水印渲染逻辑、导出逻辑
  - `src/editor/types.ts` — 新增图片水印类型定义
- 无破坏性变更
