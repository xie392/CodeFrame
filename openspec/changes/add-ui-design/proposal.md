# 变更：CodeFrame UI 设计

## 为什么

CodeFrame 作为一个代码美化截图 Chrome 插件，需要一套完整的用户界面设计，以提供良好的用户体验。UI 设计需要涵盖三个核心页面：
1. Popup 主弹窗 - 快速截图入口
2. 代码生成器页面 - 代码美化截图核心功能
3. 图片编辑器页面 - 截图标注编辑功能

## 变更内容

- 创建 CodeFrame UI 设计文件 (codeframe-ui.pen)
- 设计 Popup 主弹窗界面（360px × 500px）
  - Header 区域：Logo、主题切换、设置入口
  - Tab 导航：截图、代码、本地
  - 截图操作按钮网格：区域截图、可视区域、整页截图、桌面截图、延迟截图
  - 底部快捷键提示
- 设计代码生成器页面（900px × 600px）
  - 左侧面板：代码输入、语言选择、主题选择、背景选择、选项设置
  - 右侧预览区：代码窗口预览、macOS 风格窗口栏
  - 导出按钮
- 设计图片编辑器页面（1000px × 600px）
  - 左侧工具栏：选择、箭头、矩形、圆形、文字、马赛克工具
  - 中央画布区：截图预览
  - 右侧属性面板：颜色、粗细、透明度设置、导出选项

## 影响

- 受影响规范：ui/spec.md（新增）
- 受影响文件：codeframe-ui.pen（新建）
- 设计风格：Terminal Minimal Dashboard 风格
  - 纯暗色模式 (#0A0A0A 背景)
  - 双等宽字体系统 (JetBrains Mono + IBM Plex Mono)
  - Emerald 绿色主色调 (#10B981)
  - 终端语法 UI 元素 (>, $, //, [], 等)
