## 新增需求

### 需求：模块化架构约束

CodeGen 模块必须遵循模块化架构，主组件 App.tsx 行数不得超过 200 行，功能逻辑必须拆分到独立的 components、hooks、stores 和 utils 模块中。

#### 场景：主组件职责边界

- **当** 开发者查看 App.tsx
- **那么** 文件必须仅包含组件组合和路由逻辑
- **且** 不得包含超过 50 行的业务逻辑代码
- **且** 必须通过导入使用子组件和 hooks

#### 场景：组件拆分规范

- **当** 开发者添加新功能
- **那么** UI 组件必须放在 `components/` 目录
- **且** 可复用逻辑必须放在 `hooks/` 目录
- **且** 状态管理必须放在 `stores/` 目录
- **且** 纯函数工具必须放在 `utils/` 目录

#### 场景：状态管理规范

- **当** 组件需要共享状态
- **那么** 必须使用 Zustand store 管理状态
- **且** 状态必须按功能域分组（theme、window、editor、watermark）
- **且** 每个分组必须提供独立的 setter action

### 需求：自定义 Hook 规范

所有可复用的状态逻辑必须封装为自定义 Hook，遵循单一职责原则，每个 Hook 必须有明确的输入输出接口。

#### 场景：useCurrent Hook

- **当** 组件需要在事件处理器中访问最新状态值
- **那么** 必须使用 `useCurrent` hook 而非 useEffect 同步 Ref
- **且** Hook 必须返回 `{ current: T }` 类型对象
- **且** 不允许在 useEffect 中同步 Ref 值

#### 场景：useCanvasTransform Hook

- **当** 组件需要画布缩放/平移功能
- **那么** 必须使用 `useCanvasTransform` hook
- **且** Hook 必须返回 `{ scale, offset, zoomAt, zoomIn, zoomOut, resetView }` 接口

#### 场景：useExport Hook

- **当** 组件需要导出图片功能
- **那么** 必须使用 `useExport` hook
- **且** Hook 必须正确处理组件卸载场景
- **且** 异步操作必须支持取消

### 需求：异步操作安全

所有异步操作必须正确处理组件卸载场景，防止内存泄漏和状态更新已卸载组件。

#### 场景：导出操作取消

- **当** 用户触发导出操作后组件卸载
- **那么** 异步操作必须被正确取消
- **且** 不得尝试更新已卸载组件的状态
- **且** 定时器必须被清理

#### 场景：Promise 超时处理

- **当** 代码中使用 `setTimeout` 包裹 Promise
- **那么** 必须提供清理机制
- **且** 组件卸载时必须清除定时器

### 需求：输入验证

用户输入必须进行安全验证，防止无效数据影响系统稳定性。

#### 场景：文件名验证

- **当** 用户修改文件名
- **那么** 系统必须限制长度不超过 50 字符
- **且** 必须过滤非法字符（<>:"/\|?*）
- **且** 空输入必须恢复为默认值

#### 场景：水印文本验证

- **当** 用户输入水印文本
- **那么** 系统必须限制长度不超过 30 字符
- **且** 必须过滤换行符

#### 场景：自定义颜色验证

- **当** 用户选择自定义背景色
- **那么** 系统必须验证颜色格式有效性
- **且** 无效颜色必须恢复为默认值

## 修改需求

### 需求：代码输入区域

CodeWindow 编辑模式必须使用 `@uiw/react-codemirror`（CodeMirror 6）提供代码编辑体验，编辑器必须具有语法高亮、行号、括号匹配和自动缩进功能。编辑器配置必须通过 `useCodeEditor` hook 管理。

#### 场景：编辑器主题同步

- **当** 用户在编辑模式下且选中了某个主题
- **那么** 编辑器必须使用对应的 CodeMirror 原生主题：
  - VS Code Dark+ → `@uiw/codemirror-theme-vscode` 的 `vscodeDark`
  - One Dark → `@uiw/codemirror-theme-one-dark` 的 `oneDark`
  - Dracula → `@uiw/codemirror-theme-dracula` 的 `draculaInit` 或对应导出
  - Nord → `@uiw/codemirror-theme-nord` 的对应导出
  - 其他主题 → 对应的 `@uiw/codemirror-theme-*` 包导出
- **且** 切换主题时编辑器必须立即更新
- **且** gutter 背景色必须与编辑器内容区背景色保持一致，不得出现色差

#### 场景：编辑器配置封装

- **当** 组件需要使用编辑器
- **那么** 必须通过 `useCodeEditor` hook 获取配置
- **且** 字体、字号、行高配置必须由 hook 统一管理

### 需求：导出图片功能

系统必须允许用户将代码预览区域（包含背景填充、代码窗口和水印）导出为 PNG 图片并下载到本地，并根据用户设置的截图质量进行缩放处理。导出功能必须通过 `useExport` hook 实现，必须正确处理组件卸载场景。

#### 场景：导出 PNG 图片

- **当** 用户点击导出图片主按钮
- **那么** 系统必须使用 `@zumer/snapdom` 库将背景填充区域容器渲染为 PNG 图片
- **且** 导出图片必须使用用户设置的像素比（scale: 1/2/3），由截图质量设置决定
- **且** 导出图片必须包含完整的背景色/渐变、代码窗口（含语法高亮）、水印（如已开启）
- **且** 导出图片文件名格式必须为 `codeframe-{timestamp}.png`
- **且** 浏览器必须自动触发文件下载

#### 场景：导出时隐藏编辑器光标

- **当** 用户点击导出且当前处于编辑模式
- **那么** 导出图片中不得包含编辑器光标

#### 场景：导出含水印图片

- **当** 用户导出图片且水印已开启
- **那么** 导出的图片必须包含水印文字

#### 场景：导出应用截图质量设置

- **当** 用户点击导出图片按钮
- **那么** 系统必须读取用户的截图质量设置（1x/2x/3x）
- **且** 若质量设置为 1x，导出 scale 必须为 1
- **且** 若质量设置为 2x，导出 scale 必须为 2
- **且** 若质量设置为 3x，导出 scale 必须为 3
- **且** 导出图片尺寸必须为屏幕显示尺寸 × scale

#### 场景：导出操作取消处理

- **当** 导出操作进行中组件被卸载
- **那么** 异步操作必须被取消
- **且** 不得更新已卸载组件的状态

### 需求：复制到剪贴板功能

系统必须允许用户将代码预览区域截图直接复制到系统剪贴板，方便在其他应用中粘贴使用，并根据用户设置的截图质量进行缩放处理。复制功能必须通过 `useExport` hook 实现。

#### 场景：复制截图到剪贴板

- **当** 用户点击复制按钮
- **那么** 系统必须将代码预览区域渲染为 PNG 图片
- **且** 必须通过 `navigator.clipboard.write` 将 PNG 图片写入系统剪贴板
- **且** 用户可在任意支持粘贴图片的应用中粘贴该截图

#### 场景：复制成功反馈

- **当** 截图成功复制到剪贴板
- **那么** 复制按钮必须显示视觉反馈（如图标切换为对勾）
- **且** 反馈必须在 2 秒后自动恢复为原始状态

#### 场景：复制按钮 Tooltip

- **当** 用户鼠标悬停在复制按钮上
- **那么** 必须显示 Tooltip 提示文字 `复制到剪贴板`

#### 场景：剪贴板 API 不支持

- **当** 浏览器不支持 `navigator.clipboard.write` API
- **那么** 复制按钮必须显示错误提示信息

#### 场景：复制应用截图质量设置

- **当** 用户点击复制到剪贴板按钮
- **那么** 系统必须读取用户的截图质量设置（1x/2x/3x）
- **且** 若质量设置为 1x，生成图片 scale 必须为 1
- **且** 若质量设置为 2x，生成图片 scale 必须为 2
- **且** 若质量设置为 3x，生成图片 scale 必须为 3
