## 需求
### 需求：Editor 画布布局

Editor 中央画布区域必须采用"固定尺寸 + 居中"模式显示图片，图片默认以中等大小呈现在画布中央，不得占满整个屏幕。

#### 场景：图片默认居中显示

- **当** 用户在 Editor 中加载一张图片
- **那么** 图片容器最大宽度必须为 800px、最大高度为 600px
- **且** 图片容器必须在画布区域中水平垂直居中
- **且** 图片必须保持原始宽高比（object-contain）
- **且** 当图片实际尺寸小于容器时，容器尺寸必须适配图片实际尺寸

#### 场景：图片小于容器尺寸

- **当** 用户加载的图片尺寸小于 800x600px
- **那么** 容器尺寸必须适配图片实际尺寸，不产生多余空白区域

#### 场景：画布布局结构

- **当** Editor 页面渲染
- **那么** 中央画布（main）必须使用 relative 定位
- **且** 图片容器必须使用 absolute 定位 + calc(50% - w/2) 居中
- **且** 三栏布局结构不变（工具栏 56px + 画布 flex-1 + 属性面板 350px）

### 需求：Editor 画布缩放

Editor 画布必须支持缩放功能，用户可以通过鼠标滚轮或控制按钮对图片进行缩放查看。

#### 场景：鼠标滚轮缩放

- **当** 用户在画布区域滚动鼠标滚轮
- **那么** 向上滚动必须放大（系数 1.08），向下滚动必须缩小（系数 0.92）
- **且** 缩放必须以画布中心点为锚点
- **且** 缩放范围必须限制在 0.25x 到 4x 之间

#### 场景：缩放按钮控制

- **当** 用户点击缩放控制条中的放大按钮
- **那么** 画布必须以当前视图中心为锚点放大（系数 1.2）
- **当** 用户点击缩小按钮
- **那么** 画布必须以当前视图中心为锚点缩小（系数 1/1.2）

#### 场景：重置缩放

- **当** 用户点击缩放控制条中的重置按钮
- **那么** 画布必须恢复到 1x 缩放比例且偏移归零

### 需求：Editor 画布平移

Editor 画布在拖动工具激活后必须支持拖拽平移，用户可以拖动查看图片的不同区域。

#### 场景：拖动工具激活后拖拽平移

- **当** 拖动工具处于激活状态且用户按住鼠标左键拖拽
- **那么** 画布内容必须跟随鼠标移动方向平移
- **且** 平移必须使用 CSS transform（translate + scale）

#### 场景：非拖动工具时禁止平移

- **当** 当前选中的工具不是拖动工具
- **那么** 拖拽操作不得产生平移效果

### 需求：Editor 缩放控制条

Editor 画布底部必须显示一个浮动缩放控制条，提供缩放操作的 UI 入口。

#### 场景：控制条外观

- **当** 用户查看画布区域
- **那么** 缩放控制条必须固定在画布底部中央
- **且** 控制条必须具有毛玻璃效果（background-color: rgba(255,255,255,0.85)，backdrop-filter: blur(8px)）
- **且** 控制条圆角必须为 8px

#### 场景：控制条内容

- **当** 用户查看缩放控制条
- **那么** 必须包含以下元素（从左到右）：
  - 缩小按钮（- 图标）
  - 当前缩放百分比文本（如 "100%"）
  - 缩放滑块（range input，步长 0.01，范围 25%–400%）
  - 放大按钮（+ 图标）
  - 分隔线
  - 重置按钮（重置图标）

#### 场景：重置视图

- **当** 用户点击重置按钮
- **那么** 画布必须恢复到 1x 缩放比例
- **且** 画布位置必须归零（居中显示）

### 需求：Editor 拖动工具

Editor 左侧工具栏必须提供拖动工具，允许用户选择后自由拖动画布内容。

#### 场景：拖动工具入口

- **当** 用户查看左侧工具栏
- **那么** 必须包含拖动工具（Move 图标），位于选择工具之后

#### 场景：拖动工具选中状态

- **当** 用户点击拖动工具
- **那么** 拖动工具必须显示为激活状态
- **且** 画布光标必须变为 grab 样式
- **且** 其他工具（箭头、矩形、文字、马赛克、裁剪）必须处于非激活状态

#### 场景：拖动工具使用

- **当** 拖动工具处于激活状态且用户按住鼠标左键拖拽
- **那么** 画布内容必须跟随鼠标移动方向平移
- **且** 拖动功能必须在任何缩放比例下都可使用（包括 1x）
- **且** 拖动时画布光标必须变为 grabbing 样式

#### 场景：非拖动工具时禁止拖动

- **当** 当前选中的工具不是拖动工具
- **那么** 拖拽画布不得产生平移效果

### 需求：Editor 矩形标注绘制

Editor 必须提供矩形标注工具，允许用户在图片上绘制矩形区域进行标注。

#### 场景：矩形工具入口

- **当** 用户查看左侧工具栏
- **那么** 必须包含矩形工具（Square 图标），位于箭头工具之后

#### 场景：矩形工具选中状态

- **当** 用户点击矩形工具
- **那么** 矩形工具必须显示为激活状态
- **且** 画布光标必须变为 crosshair 样式
- **且** 其他工具必须处于非激活状态

#### 场景：绘制矩形

- **当** 矩形工具处于激活状态且用户按住鼠标左键拖拽
- **那么** 必须从按下位置开始绘制矩形
- **且** 矩形必须跟随鼠标移动实时更新尺寸
- **当** 用户释放鼠标左键
- **那么** 如果矩形宽度或高度大于等于 5px，必须创建矩形标注对象
- **且** 工具必须自动切换到选择工具

#### 场景：绘制过小矩形取消

- **当** 用户绘制的矩形宽度或高度小于 5px
- **那么** 必须取消创建，不产生矩形标注对象

### 需求：Editor 矩形标注选择

Editor 必须支持选择已创建的矩形标注，以便进行编辑或删除操作。

#### 场景：点击选择矩形

- **当** 选择工具处于激活状态且用户点击矩形边框或内部区域
- **那么** 该矩形必须被选中
- **且** 矩形必须显示选中高亮状态（蓝色边框）
- **且** 矩形必须显示 8 个控制点（四个角 + 四条边中点）

#### 场景：点击空白区域取消选择

- **当** 选择工具处于激活状态且用户点击矩形外部空白区域
- **那么** 当前选中的矩形必须取消选中状态

### 需求：Editor 矩形标注移动

Editor 必须支持拖拽移动已创建的矩形标注。

#### 场景：拖拽移动矩形

- **当** 用户选中矩形后在矩形内部区域按住鼠标左键拖拽
- **那么** 矩形必须跟随鼠标移动
- **且** 矩形尺寸必须保持不变
- **且** 移动必须考虑当前缩放比例

### 需求：Editor 矩形标注调整大小

Editor 必须支持通过控制点调整矩形标注的尺寸。

#### 场景：拖拽角控制点调整大小

- **当** 用户选中矩形后拖拽四个角的控制点
- **那么** 必须同时改变矩形的宽度和高度
- **且** 对角位置必须保持不变

#### 场景：拖拽边中点控制点调整大小

- **当** 用户选中矩形后拖拽四条边中点的控制点
- **那么** 必须改变矩形在该方向的尺寸
- **且** 对边位置必须保持不变

#### 场景：调整大小时光标变化

- **当** 用户将鼠标悬停在控制点上
- **那么** 光标必须变为对应的调整大小样式（nwse-resize、nesw-resize、ns-resize、ew-resize）

### 需求：Editor 矩形标注删除

Editor 必须支持删除已选中的矩形标注。

#### 场景：键盘删除矩形

- **当** 矩形被选中且用户按下 Delete 或 Backspace 键
- **那么** 选中的矩形必须被删除
- **且** 选择状态必须清除
- **且** 如果焦点在输入框中，禁止触发删除

### 需求：Editor 矩形标注样式配置

Editor 必须提供矩形标注的样式配置选项，允许用户自定义矩形外观。

#### 场景：颜色配置

- **当** 用户选中矩形后查看右侧属性面板
- **那么** 必须显示颜色选择器
- **且** 必须提供预设颜色选项
- **且** 必须支持自定义颜色输入

#### 场景：线宽配置

- **当** 用户选中矩形后查看右侧属性面板
- **那么** 必须显示线宽滑块控件
- **且** 线宽范围必须为 1-10px
- **且** 默认线宽必须为 2px

#### 场景：填充透明度配置

- **当** 用户选中矩形后查看右侧属性面板
- **那么** 必须显示填充透明度滑块控件
- **且** 透明度范围必须为 0-100%
- **且** 默认透明度必须为 0%（完全透明）

#### 场景：边框样式配置

- **当** 用户选中矩形后查看右侧属性面板
- **那么** 必须显示边框样式切换控件
- **且** 必须支持实线和虚线两种样式
- **且** 默认样式必须为实线

#### 场景：样式实时预览

- **当** 用户修改矩形样式配置
- **那么** 选中的矩形必须实时更新显示效果

### 需求：Editor 马赛克标注绘制

Editor 必须提供马赛克标注工具，允许用户在图片上绘制马赛克区域进行隐私保护。
