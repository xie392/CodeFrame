## 新增需求

### 需求：Editor 矩形标注绘制

Editor 必须提供矩形标注工具，允许用户在图片上绘制矩形区域进行标注。

#### 场景：矩形工具入口

- **当** 用户查看左侧工具栏
- **那么** 必须包含矩形工具（Square 图标），位于箭头工具之后

#### 场景：矩形工具选中状态

- **当** 用户点击矩形工具
- **那么** 矩形工具必须显示为激活状态
- **且** 画布光标必须变为 crosshair 样式
- **且** 其他工具必须处于非激活状态

#### 场景：绘制矩形

- **当** 矩形工具处于激活状态且用户按住鼠标左键拖拽
- **那么** 必须从按下位置开始绘制矩形
- **且** 矩形必须跟随鼠标移动实时更新尺寸
- **当** 用户释放鼠标左键
- **那么** 如果矩形宽度或高度大于等于 5px，必须创建矩形标注对象
- **且** 工具必须自动切换到选择工具

#### 场景：绘制过小矩形取消

- **当** 用户绘制的矩形宽度或高度小于 5px
- **那么** 必须取消创建，不产生矩形标注对象

### 需求：Editor 矩形标注选择

Editor 必须支持选择已创建的矩形标注，以便进行编辑或删除操作。

#### 场景：点击选择矩形

- **当** 选择工具处于激活状态且用户点击矩形边框或内部区域
- **那么** 该矩形必须被选中
- **且** 矩形必须显示选中高亮状态（蓝色边框）
- **且** 矩形必须显示 8 个控制点（四个角 + 四条边中点）

#### 场景：点击空白区域取消选择

- **当** 选择工具处于激活状态且用户点击矩形外部空白区域
- **那么** 当前选中的矩形必须取消选中状态

### 需求：Editor 矩形标注移动

Editor 必须支持拖拽移动已创建的矩形标注。

#### 场景：拖拽移动矩形

- **当** 用户选中矩形后在矩形内部区域按住鼠标左键拖拽
- **那么** 矩形必须跟随鼠标移动
- **且** 矩形尺寸必须保持不变
- **且** 移动必须考虑当前缩放比例

### 需求：Editor 矩形标注调整大小

Editor 必须支持通过控制点调整矩形标注的尺寸。

#### 场景：拖拽角控制点调整大小

- **当** 用户选中矩形后拖拽四个角的控制点
- **那么** 必须同时改变矩形的宽度和高度
- **且** 对角位置必须保持不变

#### 场景：拖拽边中点控制点调整大小

- **当** 用户选中矩形后拖拽四条边中点的控制点
- **那么** 必须改变矩形在该方向的尺寸
- **且** 对边位置必须保持不变

#### 场景：调整大小时光标变化

- **当** 用户将鼠标悬停在控制点上
- **那么** 光标必须变为对应的调整大小样式（nwse-resize、nesw-resize、ns-resize、ew-resize）

### 需求：Editor 矩形标注删除

Editor 必须支持删除已选中的矩形标注。

#### 场景：键盘删除矩形

- **当** 矩形被选中且用户按下 Delete 或 Backspace 键
- **那么** 选中的矩形必须被删除
- **且** 选择状态必须清除
- **且** 如果焦点在输入框中，禁止触发删除

### 需求：Editor 矩形标注样式配置

Editor 必须提供矩形标注的样式配置选项，允许用户自定义矩形外观。

#### 场景：颜色配置

- **当** 用户选中矩形后查看右侧属性面板
- **那么** 必须显示颜色选择器
- **且** 必须提供预设颜色选项
- **且** 必须支持自定义颜色输入

#### 场景：线宽配置

- **当** 用户选中矩形后查看右侧属性面板
- **那么** 必须显示线宽滑块控件
- **且** 线宽范围必须为 1-10px
- **且** 默认线宽必须为 2px

#### 场景：填充透明度配置

- **当** 用户选中矩形后查看右侧属性面板
- **那么** 必须显示填充透明度滑块控件
- **且** 透明度范围必须为 0-100%
- **且** 默认透明度必须为 0%（完全透明）

#### 场景：边框样式配置

- **当** 用户选中矩形后查看右侧属性面板
- **那么** 必须显示边框样式切换控件
- **且** 必须支持实线和虚线两种样式
- **且** 默认样式必须为实线

#### 场景：样式实时预览

- **当** 用户修改矩形样式配置
- **那么** 选中的矩形必须实时更新显示效果
