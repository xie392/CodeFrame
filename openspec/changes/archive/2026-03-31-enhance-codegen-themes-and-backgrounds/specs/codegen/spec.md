## 新增需求

### 需求：扩展代码主题系统

CodeGen 必须提供 12+ 种代码主题供用户选择，覆盖主流暗色和亮色主题风格。每个主题必须定义窗口背景色、标题栏背景色、前景文字色以及核心语法高亮颜色（keyword、string、comment、number、function、variable）。主题切换时 CodeMirror 编辑器的语法高亮颜色必须同步更新。

#### 场景：查看主题选择区域

- **当** 用户查看 LeftPanel 的主题选择区域
- **那么** 必须显示主题标签和 12+ 个主题色块
- **且** 每个色块尺寸为 32×32px，圆角 6px
- **且** 当前选中项必须有 2px 橙色边框指示
- **且** 主题色块区域必须支持横向滚动（当主题数量超出可视区域时）

#### 场景：切换到暗色主题

- **当** 用户点击暗色主题色块（如 Dracula、Nord、Tokyo Night）
- **那么** 代码窗口背景色必须切换为该主题的窗口背景色
- **且** 代码窗口标题栏背景色必须切换为该主题的标题栏色
- **且** CodeMirror 编辑器的语法高亮颜色必须同步更新
- **且** 前景文字色必须切换为该主题的文字色

#### 场景：切换到亮色主题

- **当** 用户点击亮色主题色块（如 GitHub Light、One Light）
- **那么** 代码窗口必须切换为亮色风格
- **且** CodeMirror 编辑器必须切换为 `vscodeLight` 基础主题 + 自定义语法颜色覆盖

#### 场景：默认主题

- **当** 用户首次打开 CodeGen 页面
- **那么** 默认选中主题必须为 VS Code Dark+

### 需求：渐变背景系统

CodeGen 必须支持渐变背景和纯色背景两种类型，提供 15+ 种预设背景选项。背景应用于代码窗口外围的 padding 填充区域。

#### 场景：查看背景选择区域

- **当** 用户查看 LeftPanel 的背景选择区域
- **那么** 必须显示背景标签和背景选项列表
- **且** 背景选项必须包含纯色和渐变两种类型
- **且** 每个选项必须有视觉预览（纯色为色块，渐变为缩略渐变条）
- **且** 当前选中项必须有视觉指示

#### 场景：选择渐变背景

- **当** 用户选择一个渐变背景
- **那么** 代码窗口外围的 padding 填充区域必须显示对应的 CSS 渐变效果
- **且** 渐变方向、颜色必须与预览一致

#### 场景：选择纯色背景

- **当** 用户选择纯色背景
- **那么** 代码窗口外围区域必须显示对应的纯色填充
- **且** 纯色背景必须保留现有 5 种颜色选项

#### 场景：默认背景

- **当** 用户首次打开 CodeGen 页面
- **那么** 默认选中背景必须为 Indigo 纯色

### 需求：自定义背景颜色

CodeGen 必须提供背景颜色选择器，允许用户选择任意颜色作为纯色背景。

#### 场景：使用颜色选择器

- **当** 用户点击背景选择区域的"自定义"颜色按钮
- **那么** 必须弹出颜色选择器（Color Picker）
- **且** 用户选择颜色后，代码窗口外围区域必须立即更新为所选颜色

#### 场景：输入色值

- **当** 用户在颜色选择器中输入 HEX 色值
- **那么** 背景必须更新为对应的颜色

### 需求：窗口圆角调节

CodeGen 必须支持调节代码窗口的圆角大小。

#### 场景：调节圆角

- **当** 用户拖动圆角滑块
- **那么** 代码窗口的圆角必须在 0px 到 20px 范围内平滑变化
- **且** 窗口标题栏和窗口主体必须保持圆角一致

#### 场景：默认圆角

- **当** 用户首次打开 CodeGen 页面
- **那么** 默认圆角必须为 12px（当前 rounded-xl 的等效值）

### 需求：窗口阴影

CodeGen 必须支持代码窗口的阴影效果开关和强度调节。

#### 场景：开启阴影

- **当** 用户开启阴影开关
- **那么** 代码窗口必须显示 box-shadow 效果
- **且** 阴影强度可通过滑块调节（0-100%）

#### 场景：关闭阴影

- **当** 用户关闭阴影开关
- **那么** 代码窗口的阴影必须移除

#### 场景：默认阴影

- **当** 用户首次打开 CodeGen 页面
- **那么** 默认阴影必须为开启，强度 50%

### 需求：代码字体选择

CodeGen 必须支持多种代码字体选择，满足不同用户的字体偏好。

#### 场景：查看字体选项

- **当** 用户查看字体选择区域
- **那么** 必须显示字体下拉选择器
- **且** 字体列表必须包含：JetBrains Mono、Fira Code、Source Code Pro、IBM Plex Mono
- **且** 每个字体选项必须使用对应字体渲染预览文字

#### 场景：切换字体

- **当** 用户选择不同的代码字体
- **那么** CodeMirror 编辑器的字体必须立即切换
- **且** 字体必须通过 Google Fonts 或本地字体文件加载
- **且** 字体加载期间必须显示系统等宽字体作为回退

#### 场景：默认字体

- **当** 用户首次打开 CodeGen 页面
- **那么** 默认字体必须为 JetBrains Mono

### 需求：字号调节

CodeGen 必须支持调节代码编辑器的字号大小。

#### 场景：调节字号

- **当** 用户拖动字号滑块
- **那么** 代码字号必须在 12px 到 24px 范围内变化
- **且** 代码窗口高度必须根据字号变化自适应调整

#### 场景：默认字号

- **当** 用户首次打开 CodeGen 页面
- **那么** 默认字号必须为 13px（当前值）

### 需求：水印功能

CodeGen 必须支持在导出图片上添加水印。

#### 场景：开启水印

- **当** 用户开启水印开关
- **那么** 代码窗口上必须显示水印文字
- **且** 水印默认文字为 "CodeFrame"
- **且** 水印必须支持自定义文字输入

#### 场景：调节水印透明度

- **当** 用户拖动水印透明度滑块
- **那么** 水印透明度必须在 10% 到 90% 范围内变化

#### 场景：导出含水印图片

- **当** 用户导出图片且水印已开启
- **那么** 导出的图片必须包含水印
- **且** 编辑器光标等 UI 元素不得出现在导出图片中

#### 场景：默认水印

- **当** 用户首次打开 CodeGen 页面
- **那么** 默认水印必须为关闭状态

### 需求：窗口标题栏可见性

CodeGen 必须支持隐藏/显示代码窗口的 macOS 标题栏（三圆点 + 文件名）。

#### 场景：隐藏标题栏

- **当** 用户关闭"显示标题栏"开关
- **那么** 代码窗口的 macOS 三圆点和文件名必须隐藏
- **且** 代码编辑区域必须扩展到窗口顶部
- **且** 窗口高度必须相应缩减（减去 HEADER_HEIGHT）

#### 场景：显示标题栏

- **当** 用户开启"显示标题栏"开关
- **那么** macOS 三圆点和文件名必须重新显示

#### 场景：默认标题栏

- **当** 用户首次打开 CodeGen 页面
- **那么** 默认标题栏必须为显示状态

## 修改需求

### 需求：主题选择区域

ThemeSection 必须提供代码展示区域主题选择功能，用户切换主题后右侧整个代码展示区域（窗口样式 + 语法高亮配色）必须实时统一更新。

#### 场景：主题色块显示

- **当** 用户查看主题选择区域
- **那么** 必须显示 `theme` 标签文字（颜色 #3D3D3D，字号 11px）
- **且** 必须显示 12+ 个主题色块（32×32px，圆角 6px）
- **且** 主题列表必须包含至少以下主题：VS Code Dark+、One Dark、Solarized Dark、Light、Dracula、Nord、Tokyo Night、GitHub Dark、Catppuccin Mocha、Gruvbox Dark、Rose Pine、Kanagawa
- **且** 当前选中项必须有 2px #FF6B35 橙色边框指示

#### 场景：主题切换生效

- **当** 用户点击某个主题色块
- **那么** 该色块必须显示选中状态（2px #FF6B35 橙色边框）
- **且** 右侧 PreviewArea 的代码窗口整体视觉风格必须切换为对应主题
- **且** 代码窗口背景色必须从主题配置中读取
- **且** 代码窗口标题栏背景色必须从主题配置中读取
- **且** CodeMirror 编辑器的语法高亮颜色必须使用对应主题的自定义颜色覆盖

### 需求：背景色选择区域

BgSection 必须提供代码窗口背景色选择功能，支持纯色和渐变两种背景类型。

#### 场景：背景选项显示

- **当** 用户查看背景色选择区域
- **那么** 必须显示 `background` 标签文字（颜色 #3D3D3D，字号 11px）
- **且** 必须显示 15+ 个背景选项（纯色色块和渐变预览条混合排列）
- **且** 必须提供自定义颜色选择器入口
- **且** 当前选中项必须有视觉指示

#### 场景：背景切换生效

- **当** 用户选择某个背景选项
- **那么** 代码窗口外围的 padding 填充区域必须更新为对应的颜色或渐变效果
- **且** 预览必须实时更新
