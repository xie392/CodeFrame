# 变更：添加画布交互功能到 CodeGen 页面

## 为什么

当前 CodeGen 页面采用传统的左右分栏固定布局，右侧预览区域背景色占满整个区域，缺乏设计感和交互性。用户反馈希望参考 Figma 的画布交互体验，实现可缩放、可拖动的自由画布，同时参考 Carbon 的代码展示效果，使代码窗口成为画布中的焦点内容，而非铺满整个区域。

这种改造将带来以下价值：
- **更好的视觉层次**：画布背景与代码窗口分离，形成内外层次
- **类似设计工具的交互体验**：缩放、拖动操作符合设计师用户习惯
- **更大的创作自由度**：用户可以调整代码窗口在画布中的位置和大小
- **为未来扩展奠基**：图片编辑器也将使用相同的画布交互模式

## 变更内容

- **新增需求**：画布容器组件，支持无限画布、缩放控制、平移拖动
- **新增需求**：代码窗口与画布融合编辑，支持双击进入编辑模式
- **修改需求**：预览区域布局从固定居中改为画布模式
- **修改需求**：代码编辑器从左侧分离面板改为融合式编辑
- **修改需求**：背景色选择器从纯色填充改为画布背景色
- **移除需求**：删除左侧独立的 CodeMirror 编辑器区域
- **新增需求**：画布缩放控制 UI（缩放比例显示、重置按钮、缩放滑块）
- **新增需求**：画布拖拽手柄和视觉反馈

## 影响

- **受影响规范**：`codegen`
- **受影响代码**：
  - `src/codegen/App.tsx` - 页面主组件重构
  - `src/codegen/components/CanvasContainer.tsx` - 新增画布容器
  - `src/codegen/components/CodeWindow.tsx` - 代码窗口组件改造
  - `src/codegen/hooks/useCanvas.ts` - 画布交互状态管理
- **新增依赖**：
  - `@use-gesture/react` - 手势交互（拖拽、缩放）
  - `@react-spring/web` - 动画过渡
