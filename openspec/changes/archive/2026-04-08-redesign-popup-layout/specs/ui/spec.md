## 修改需求

### 需求：UI 设计系统

CodeFrame 必须使用玻璃拟态暗色主题（Glassmorphism Dark），为开发者提供精致、现代的用户体验。

#### 场景：颜色系统

- **当** 用户查看任何界面
- **那么** 页面背景必须使用线性渐变：#252535（0%）→ #1A1A2E（50%）→ #0F0F1A（100%）
- **且** 主色调必须为 #FF6B35（橙色）和 #00D4AA（青色）双色强调
- **且** 文字色必须为 #FFFFFF（主文字）、#777777（次要文字）、#3D3D3D（辅助文字）
- **且** 边框色必须为 #FFFFFF18（主边框）

#### 场景：字体系统

- **当** 用户查看标题、Logo 或按钮文字
- **那么** 字体必须为 Oswald
- **当** 用户查看正文、标签或描述
- **那么** 字体必须为 JetBrains Mono

#### 场景：卡片样式

- **当** 用户查看操作按钮卡片
- **那么** 圆角必须为 16px
- **且** 背景必须使用半透明渐变 rgba(255,255,255,0.125) → rgba(255,255,255,0.063)
- **且** 必须有 backdrop-blur(16px) 效果
- **且** 边框为 1px rgba(255,255,255,0.094)
- **且** 必须有外阴影 rgba(0,0,0,0.21)，Y 偏移 4px，模糊 16px

#### 场景：功能列表项样式

- **当** 用户查看功能列表项
- **那么** 列表项圆角必须为 12px
- **且** 背景色必须为 rgba(255,255,255,0.031)
- **且** 右侧必须有 chevron-right 导航箭头（#FFFFFF30）
