## 修改需求
### 需求：Editor 导出图片功能

系统必须允许用户将编辑后的图片（包含背景、图片、标注、水印）导出为 PNG 图片并下载到本地，并根据用户设置的截图质量进行缩放处理。

#### 场景：导出 PNG 图片

- **当** 用户点击「导出图片」按钮
- **那么** 系统必须使用 `@zumer/snapdom` 库将图片容器渲染为 PNG 图片
- **且** 导出图片必须使用用户设置的像素比（scale: 1/2/3），由截图质量设置决定
- **且** 导出图片必须包含完整的背景色/渐变、图片、所有标注（箭头、矩形、文字、马赛克）、水印（如已开启）
- **且** 导出图片文件名格式必须为 `codeframe-{timestamp}.png`
- **且** 浏览器必须自动触发文件下载

#### 场景：导出时合并标注图层

- **当** 用户点击导出且画布上有标注
- **那么** Canvas 标注图层必须先渲染为图片
- **且** 标注图片必须叠加到导出内容中
- **且** 标注位置必须与画布显示位置一致

#### 场景：导出时重置视图状态

- **当** 用户在缩放或偏移状态下点击导出
- **那么** 导出图片必须以原始尺寸（scale=1，offset=0,0）导出
- **且** 导出完成后必须恢复原有视图状态

#### 场景：导出中状态反馈

- **当** 用户点击导出后
- **那么** 导出按钮必须显示 loading 状态
- **且** 导出过程中按钮必须禁用
- **且** 导出完成后恢复正常状态

#### 场景：导出按钮始终可见

- **当** 用户查看右侧属性面板
- **那么** 「导出图片」和「复制到剪贴板」按钮必须固定显示在面板底部
- **且** 按钮不可随上方内容滚动而消失
- **且** 上方设置内容区域可独立滚动

#### 场景：导出应用截图质量设置

- **当** 用户点击导出图片按钮
- **那么** 系统必须读取用户的截图质量设置（1x/2x/3x）
- **且** 若质量设置为 1x，导出 scale 必须为 1
- **且** 若质量设置为 2x，导出 scale 必须为 2
- **且** 若质量设置为 3x，导出 scale 必须为 3
- **且** 导出图片尺寸必须为屏幕显示尺寸 × scale

### 需求：Editor 复制到剪贴板功能

系统必须允许用户将编辑后的图片复制到系统剪贴板，便于快速粘贴到其他应用，并根据用户设置的截图质量进行缩放处理。

#### 场景：复制图片到剪贴板

- **当** 用户点击「复制到剪贴板」按钮
- **那么** 系统必须使用 `@zumer/snapdom` 生成 PNG Blob
- **且** 必须通过 `navigator.clipboard.write` 写入剪贴板
- **且** 复制内容必须包含完整的背景、图片、标注、水印

#### 场景：复制成功反馈

- **当** 图片成功复制到剪贴板
- **那么** 必须显示成功提示（按钮文字变化或 Toast）
- **且** 提示必须在大约 2 秒后自动消失

#### 场景：浏览器兼容性检测

- **当** 用户点击复制但浏览器不支持 `navigator.clipboard.write`
- **那么** 必须显示错误提示「当前浏览器不支持复制图片到剪贴板」

#### 场景：复制中状态反馈

- **当** 用户点击复制后
- **那么** 复制按钮必须显示 loading 状态
- **且** 复制过程中按钮必须禁用
- **且** 复制完成后恢复正常状态

#### 场景：复制按钮始终可见

- **当** 用户查看右侧属性面板
- **那么** 「复制到剪贴板」按钮必须固定显示在面板底部
- **且** 按钮不可随上方内容滚动而消失

#### 场景：复制应用截图质量设置

- **当** 用户点击复制到剪贴板按钮
- **那么** 系统必须读取用户的截图质量设置（1x/2x/3x）
- **且** 若质量设置为 1x，生成图片 scale 必须为 1
- **且** 若质量设置为 2x，生成图片 scale 必须为 2
- **且** 若质量设置为 3x，生成图片 scale 必须为 3
