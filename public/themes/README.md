# Themes Directory

This directory contains preset themes for code beautification.

## Theme Structure

Each theme should be a JSON file with the following structure:

```json
{
  "id": "theme-id",
  "name": "Theme Name",
  "type": "dark",
  "colors": {
    "background": "#1E1E1E",
    "text": "#D4D4D4",
    "keyword": "#C586C0",
    "string": "#CE9178",
    "number": "#B5CEA8",
    "comment": "#6A9955",
    "function": "#DCDCAA",
    "variable": "#9CDCFE"
  }
}
```
