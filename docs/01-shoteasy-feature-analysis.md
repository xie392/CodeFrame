## 二、核心截图功能

### 2.1 截图模式

| 截图模式 | 功能描述 | 适用场景 |
|----------|----------|----------|
| **区域截图** | 用户可自由选择屏幕上的任意区域进行截图 | 精确截取特定区域 |
| **可视区域截图** | 截取当前浏览器窗口可视范围内的内容 | 快速截取当前屏幕 |
| **整页截图（滚动截图）** | 自动滚动并拼接，生成完整的长截图 | 截取长文章、完整网页 |
| **桌面窗口截图** | 截取桌面其他应用程序窗口 | 跨应用截图 |
| **延迟截图** | 设定延迟时间后自动截图（3-5秒） | 捕获悬停菜单、动态内容 |

### 2.2 各截图模式详细说明

#### 区域截图
- **触发方式**：点击插件图标 → 选择「区域截图」
- **操作流程**：
  1. 屏幕变暗，进入选择模式
  2. 用户按住鼠标左键拖动绘制矩形选区
  3. 释放鼠标后自动截图
  4. 进入编辑器界面
- **特点**：支持跨窗口选择，选区可实时调整

#### 整页截图（滚动截图）
- **触发方式**：点击插件图标 → 选择「整页截图」
- **技术实现**：自动滚动页面，分段截图后拼接
- **特点**：
  - 支持任意长度的网页
  - 自动处理固定定位元素
  - 生成单张完整图片

## 三、截图标注功能

ShotEasy 集成了 **Filerobot Image Editor** 作为核心编辑引擎。

### 3.1 标注工具列表

| 工具类别 | 工具名称 | 功能描述 |
|----------|----------|----------|
| **形状标注** | 矩形 | 绘制矩形框标记重点区域 |
| | 圆形/椭圆 | 绘制圆形标记 |
| | 多边形 | 自定义形状标注 |
| **线条标注** | 箭头 | 绘制带箭头的指向线 |
| | 直线 | 绘制普通直线 |
| **自由绘制** | 画笔 | 自由手绘标注 |
| | 马赛克 | 模糊敏感信息（规划中） |
| **文字标注** | 文本 | 添加文字说明 |
| | Emoji 表情 | 添加表情符号标注 |
| **图片标注** | 图片 | 插入本地图片作为标注 |
| **水印** | 文字水印 | 添加文字水印 |
| | 图片水印 | 添加 Logo 图片水印 |

### 3.2 标注属性设置

| 属性 | 类型 | 说明 |
|------|------|------|
| `fill` | 颜色值 | 填充颜色 |
| `stroke` | 颜色值 | 边框颜色 |
| `strokeWidth` | 数值 | 边框宽度 |
| `opacity` | 0-1 | 透明度 |
| `shadowOffsetX/Y` | 数值 | 阴影偏移 |
| `shadowBlur` | 数值 | 阴影模糊 |
| `shadowColor` | 颜色值 | 阴影颜色 |

### 3.3 标注操作

- **撤销/重做**：支持多步撤销和重做
- **删除**：选中标注后删除
- **移动**：拖拽调整位置
- **缩放**：拖拽控制点调整大小
- **旋转**：旋转标注角度

## 七、用户交互流程

### 7.1 标准使用流程

```
Step 1: 触发截图
┌─────────────────────────────────────┐
│  点击浏览器工具栏插件图标            │
│         ↓                           │
│  弹出操作菜单：                      │
│  ├── 整页截图                       │
│  ├── 区域截图                       │
│  ├── 可视区域截图                   │
│  ├── 桌面窗口截图                   │
│  ├── 延迟截图                       │
│  └── 编辑本地图片                   │
└─────────────────────────────────────┘
                ↓
Step 2: 执行截图
┌─────────────────────────────────────┐
│  根据选择的模式执行截图操作          │
│  - 区域截图：拖拽选区                │
│  - 整页截图：自动滚动拼接            │
│  - 可视区域：即时截图                │
└─────────────────────────────────────┘
                ↓
Step 3: 编辑处理
┌─────────────────────────────────────┐
│  进入编辑器                          │
│  ├── 调整：裁剪、调整尺寸、翻转、旋转 │
│  ├── 标注：文字、形状、箭头、画笔、水印│
│  └── 滤镜：各种滤镜效果              │
└─────────────────────────────────────┘
                ↓
Step 4: 保存导出
┌─────────────────────────────────────┐
│  选择导出格式 (PNG/JPG/WEBP)        │
│         ↓                           │
│  点击保存 → 下载到本地              │
└─────────────────────────────────────┘
```
