## 新增需求

### 需求：Editor 图片容器默认背景

Editor 图片容器必须有一个默认背景色，确保用户打开编辑器时图片有明确的视觉边界。

#### 场景：默认背景色

- **当** 用户打开 Editor 编辑器加载图片
- **那么** 图片容器必须显示白色背景（#FFFFFF）
- **且** 背景类型必须为纯色（solid）

#### 场景：背景显示在图片后方

- **当** 用户加载图片后查看画布
- **那么** 背景必须显示在图片的后方
- **且** 背景尺寸必须与图片显示尺寸一致
- **且** 背景必须跟随图片一起缩放和平移

#### 场景：背景可自定义

- **当** 用户在右侧属性面板中修改背景设置
- **那么** 背景必须实时更新为用户选择的颜色或渐变
- **且** 背景设置必须包含：纯色、线性渐变、径向渐变三种类型
- **且** 必须提供预设背景选项（透明、白色、黑色、日落、海洋、森林、紫色、蜜桃）

#### 场景：透明背景显示

- **当** 用户选择透明背景
- **那么** 必须显示棋盘格图案表示透明区域
- **且** 棋盘格必须在图片后方显示
