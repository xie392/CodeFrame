## 修改需求

### 需求：通用设置配置

系统**必须**提供通用设置配置功能，允许用户自定义默认行为。

#### 场景：切换默认导出格式

- **当** 用户点击"默认导出格式"下拉选择器
- **那么** 显示可选格式列表（PNG / JPG / WEBP）
- **且** 选择后自动保存到 `chrome.storage.local`

#### 场景：使用默认导出格式导出图片（编辑器）

- **当** 用户在编辑器点击导出按钮
- **那么** 系统读取 `defaultFormat` 设置
- **且** 使用对应格式（PNG / JPG / WEBP）导出图片
- **且** 导出文件扩展名与格式匹配

#### 场景：使用默认导出格式导出图片（代码生成器）

- **当** 用户在代码生成器点击导出按钮
- **那么** 系统读取 `defaultFormat` 设置
- **且** 使用对应格式（PNG / JPG / WEBP）导出图片
- **且** 导出文件扩展名与格式匹配

#### 场景：JPG 格式背景处理

- **当** 用户选择 JPG 格式导出
- **那么** 系统自动添加白色背景（JPG 不支持透明）

#### 场景：切换截图质量

- **当** 用户点击"截图质量"下拉选择器
- **那么** 显示可选质量列表（标准 / 高清 / 超高清）
- **且** 选择后自动保存到 `chrome.storage.local`

#### 场景：截图质量等级定义

- **当** 用户选择"标准"质量
- **那么** DPR 缩放倍数必须为 1x
- **且** 输出图片尺寸与屏幕显示尺寸一致
- **当** 用户选择"高清"质量
- **那么** DPR 缩放倍数必须为 2x
- **且** 输出图片尺寸为屏幕显示尺寸的 2 倍
- **当** 用户选择"超高清"质量
- **那么** DPR 缩放倍数必须为 3x
- **且** 输出图片尺寸为屏幕显示尺寸的 3 倍

#### 场景：截图质量生效范围

- **当** 用户修改截图质量设置
- **那么** 设置必须同时影响以下场景：
  - 可视区域截图捕获
  - 区域选择截图捕获
  - 整页截图捕获
  - Editor 导出图片
  - CodeGen 导出图片

#### 场景：切换语言

- **当** 用户点击"界面语言"下拉选择器
- **那么** 显示可选语言列表（简体中文 / English）
- **且** 选择后自动保存到 `chrome.storage.local`
- **且** 系统自动切换界面语言（见 i18n 规范）
- **且** 所有已打开页面的界面立即更新
