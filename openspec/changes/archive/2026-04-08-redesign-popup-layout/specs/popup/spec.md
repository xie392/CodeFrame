## 修改需求

### 需求：Popup 页面布局

Popup 页面必须按照玻璃拟态暗色主题实现，尺寸为 363px × 461px，包含三个主要区域：Header、内容区域（ActionRow + FeatureList）、Footer。

#### 场景：页面初始化

- **当** 用户打开 Popup 页面
- **那么** 页面必须显示完整的 Header、ActionRow、FeatureList、Footer
- **且** 页面背景必须使用 180 度线性渐变：#252535（0%）→ #1A1A2E（50%）→ #0F0F1A（100%）
- **且** 页面主容器圆角必须为 16px

### 需求：Header 区域

Header 区域必须包含 Logo 和操作按钮，高度 47px，水平 padding 16px。

#### 场景：Logo 显示

- **当** 用户查看 Header 左侧
- **那么** 必须显示 Logo 方块（28×28px，背景 #FF6B35，圆角 8px）内含 "CF" 文字
- **且** "CF" 文字必须使用 Oswald 字体，13px，font-weight 700，颜色 #0D0D0D
- **且** Logo 右侧必须显示 "CodeFrame" 文字，Oswald 16px，font-weight 600，颜色 #FFFFFF

#### 场景：操作按钮

- **当** 用户查看 Header 右侧
- **那么** 必须显示主题切换按钮（sun 图标）和设置按钮（settings 图标）
- **且** 按钮尺寸必须为 32×32px，背景 #2D2D2D，圆角 8px
- **且** 图标尺寸必须为 15×15px，颜色 #777777

### 需求：Footer 区域

Footer 区域必须显示快捷键提示，高度 35px，居中对齐。

#### 场景：快捷键提示

- **当** 用户查看 Footer 区域
- **那么** 必须显示 `// alt+shift+s capture . alt+shift+c code`
- **且** 文字颜色必须为 #3D3D3D
- **且** 字体必须为 JetBrains Mono，大小 9px

## 移除需求

### 需求：Tab 导航

**原因**：设计稿中不再包含 Tab 导航，取而代之的是 ActionRow + FeatureList 的单页面布局
**迁移**：无迁移需要，直接移除

### 需求：截图操作按钮

**原因**：操作按钮布局从 3+2 网格改为 4 列 ActionRow，样式完全不同（玻璃拟态 vs Terminal Minimal），整体需求重写
**迁移**：功能合并到新增的「操作按钮行」和「功能列表」需求中

## 新增需求

### 需求：操作按钮行（ActionRow）

内容区域顶部必须包含 4 个操作按钮横向排列，形成 ActionRow。

#### 场景：按钮布局

- **当** 用户查看 ActionRow 区域
- **那么** 必须显示 4 个等宽按钮横向排列：可视截图、选择区域、整页截图、代码编辑器
- **且** ActionRow 整体 padding 为 12px，按钮之间间距为 8px，水平居中对齐

#### 场景：按钮样式

- **当** 用户查看任意操作按钮
- **那么** 按钮尺寸必须为 78×96px，圆角 16px
- **且** 背景必须使用半透明渐变（180 度）：#FFFFFF20（0%）→ #FFFFFF10（100%）
- **且** 边框必须为 1px #FFFFFF18
- **且** 必须有 16px 背景模糊效果
- **且** 必须有外阴影：颜色 #00000035，Y 偏移 4px，模糊 16px

#### 场景：按钮图标和文字

- **当** 用户查看操作按钮内容
- **那么** 可视截图图标（eye）颜色必须为 #FF6B35，文字"可视截图"
- **且** 选择区域图标（scissors）颜色必须为 #00D4AA，文字"选择区域"
- **且** 整页截图图标（file-text）颜色必须为 #FF6B35，文字"整页截图"
- **且** 代码编辑器图标（code）颜色必须为 #00D4AA，文字"代码编辑器"
- **且** 图标尺寸必须为 26×26px
- **且** 文字必须使用 JetBrains Mono 12px，颜色 #FFFFFF

### 需求：功能列表（FeatureList）

内容区域底部必须包含一个功能列表容器，内含 4 个可点击的功能项。

#### 场景：容器样式

- **当** 用户查看 FeatureList 容器
- **那么** 容器圆角必须为 16px
- **且** 容器必须有 20px 背景模糊效果
- **且** 容器必须有外阴影：颜色 #00000030，Y 偏移 4px，模糊 16px
- **且** 容器 padding 必须为上下 8px、左右 20px
- **且** 列表项之间间距为 4px

#### 场景：列表项样式

- **当** 用户查看任意列表项
- **那么** 列表项高度必须为 48px，圆角 12px
- **且** 背景色必须为 #FFFFFF08
- **且** 水平 padding 为 12px
- **且** 左侧图标和文字水平排列，间距 12px
- **且** 右侧必须显示 chevron-right 箭头图标（16×16px，颜色 #FFFFFF30）

#### 场景：列表项内容

- **当** 用户查看功能列表
- **那么** 必须依次显示 4 个功能项：延时截取可视区域、全屏截图、编辑本地或粘贴图片、代码编辑器
- **且** 图标尺寸必须为 18×18px
- **且** 文字必须使用 JetBrains Mono 13px，颜色 #FFFFFF
- **且** 延时截取图标（timer）颜色为 #FF6B35
- **且** 全屏截图图标（monitor）颜色为 #00D4AA
- **且** 本地图片图标（image-plus）颜色为 #FF6B35
- **且** 代码编辑器图标（code）颜色为 #00D4AA
