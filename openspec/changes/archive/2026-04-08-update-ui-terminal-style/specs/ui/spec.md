## 修改需求

### 需求：UI 设计系统

CodeFrame 必须使用 Terminal Minimal Dashboard 设计风格，为开发者提供一致的终端美学体验。

#### 场景：颜色系统一致性

- **当** 用户查看任何界面
- **那么** 背景色必须使用 #0C0C0C (Page) / #171717 (Surface) / #1A1A1A (Highlight)
- **且** 文字色必须使用 #E5E5E5 (Primary) / #A3A3A3 (Secondary) / #737373 (Tertiary)
- **且** 强调色必须使用 #22C55E (Green Primary)

#### 场景：字体系统一致性

- **当** 用户查看任何文字内容
- **那么** 所有文字必须使用 JetBrains Mono 字体
- **且** 通过 weight 变化 (400/500/600) 建立层级
- **且** 所有文字必须使用 lowercase

#### 场景：终端风格元素

- **当** 用户查看 Logo
- **那么** Logo 必须使用 `~` 符号前缀
- **当** 用户查看导航
- **那么** 活动项必须使用 `>` 作为指示器
- **当** 用户查看描述文字
- **那么** 描述必须使用 `//` 前缀

#### 场景：命名约定

- **当** 用户查看标签
- **那么** 标签必须使用 snake_case 格式（如 `capture_area`, `code_generator`）

#### 场景：圆角系统

- **当** 用户查看页面容器或表格
- **那么** 圆角必须为 0px
- **当** 用户查看按钮或输入框
- **那么** 圆角必须为 4px
