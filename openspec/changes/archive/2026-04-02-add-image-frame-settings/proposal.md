# 变更：添加图片容器设置 UI 控件

## 为什么

Editor 页面目前支持图片标注操作，但缺少对图片容器本身的外观设置 UI。本次变更仅添加 UI 控件，为后续功能实现做准备。

## 变更内容

### 新增 UI 控件

在右侧属性面板 `[frame]` 区域添加以下设置控件：

1. **背景设置**
   - 背景类型选择（纯色/线性渐变/径向渐变）
   - 颜色选择器
   - 渐变角度控制
   - 预设背景模板

2. **边距设置**
   - 四向边距输入框（上、右、下、左）
   - 联动/独立模式切换按钮

3. **圆角设置**
   - 四角圆角输入框
   - 联动/独立模式切换按钮

4. **阴影设置**
   - 开关控件
   - 颜色选择器
   - 模糊度滑块
   - X/Y 偏移量输入
   - 预设阴影样式

5. **比例设置**
   - 比例选择下拉框
   - 预设比例选项（原始、1:1、4:3、16:9 等）

6. **窗口控件**
   - 开关控件
   - 样式选择（macOS/Windows）

7. **水印设置**
   - 开关控件
   - 文字输入框
   - 位置选择
   - 透明度滑块
   - 字体大小滑块

### UI 设计原则

- 保持与现有属性面板一致的 UI 风格
- 使用现有的 `SliderControl`、`ColorPicker` 等组件
- 采用折叠面板形式，避免占用过多空间

## 影响

- 受影响规范：`editor`
- 受影响代码：
  - `src/editor/App.tsx` - 添加 UI 控件
  - `src/editor/types.ts` - 添加类型定义
- 无破坏性变更
- **本次仅添加 UI，不实现功能逻辑**
