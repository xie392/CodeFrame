## 上下文

Editor 页面当前图片显示区域使用 flex 居中布局 + `max-w-full max-h-full`，导致图片占满整个可用空间。CodeGen 页面已有成熟的缩放/平移实现（`src/codegen/App.tsx:253-313`），采用 `scale` + `offset` 状态 + CSS `transform` 方案。需将类似的交互模式迁移到 Editor。

## 目标 / 非目标

- 目标：图片默认中等尺寸居中显示，不占满屏幕
- 目标：支持鼠标滚轮缩放和拖拽平移
- 目标：提供底部浮动缩放控制条
- 目标：标注工具在缩放后坐标映射正确
- 非目标：不修改标注工具的交互逻辑
- 非目标：不添加代码窗口的拖拽调整大小功能

## 决策

### 布局方案
- 决策：将 `<main>` 从 flex 居中改为 `relative` 定位，图片容器使用 `absolute` + `calc(50% - w/2)` 居中，通过 CSS `transform` 实现缩放平移
- 考虑的替代方案：保持 flex 布局但给图片设置 `max-width/max-height` 像素限制 → 放弃，因为无法同时支持缩放平移

### 缩放算法
- 决策：复用 CodeGen 的 `zoomAt` 锚点缩放算法（`scaleRef` + `offsetRef` + `requestAnimationFrame` 模式）
- 考虑的替代方案：使用 CSS `zoom` 属性 → 放弃，因为无法精确控制平移偏移

### 默认图片尺寸
- 决策：图片容器默认最大宽度 800px、最大高度 600px，图片在容器内 `object-contain` 保持宽高比
- 考虑的替代方案：固定百分比（60% 画布宽度）→ 放弃，因为在不同分辨率下表现不一致

### 缩放控制条
- 决策：浮动定位在画布底部中央，毛玻璃效果，包含 +/- 按钮、百分比文本、滑块和重置按钮
- 考虑的替代方案：放在工具栏中 → 放弃，因为工具栏已固定且空间有限

## 风险 / 权衡

- 标注坐标映射：缩放后 Canvas 上的鼠标事件坐标需要除以 `scale` 并减去 `offset` 偏移才能映射到图片实际像素坐标。现有标注逻辑基于 `Konva.js`，需确保坐标转换正确。
- 性能：大图片在缩放时可能产生渲染延迟，但 CSS transform 由 GPU 加速，风险较低。
